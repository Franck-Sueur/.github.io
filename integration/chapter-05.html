Chapter 5
Simple functions and their Lebesgue integral

Simple functions are the first class for which the integral can be defined directly and computed explicitly. We describe their decompositions, characterize when they are measurable, and establish the algebraic properties of their integral, which will be the starting point for the general construction.

5.1 Simple functions and their decompositions

We will see that defining the Lebesgue integral of an indicator function of a measurable part is straightforward. In order to define the integrals of positive measurable functions more generally, we therefore seek to approximate them by linear combinations of indicators of measurable parts. This point of view motivates the introduction of the following so-called simple functions.

Definition 5.1 (Simple functions). Let X be a set. A function s: X → ℝ is a simple function if s takes only a finite number of values, i.e. if s(X) is a finite part of ℝ. The empty image is allowed when X = ∅.

Proposition 5.2 (Canonical decomposition of a simple function). Let X be a set and let s: X → ℝ be a simple function. If X = ∅, then s admits the empty decomposition, and all sums below are understood as empty sums. If X≠∅, write

s(X) = {α1,…,αr}

and, for each 1 ≤ i ≤ r, let

Ai = s−1({α i}).

Then

s = ∑ i=1rα i1Ai. (5.1)

Moreover, the family (Ai)1≤i≤r satisfies the three following properties:

(i)
⋃ ⁡ i=1rA i = X,
(ii)
if i≠j, then Ai ∩ Aj = ∅,
(iii)
for every 1 ≤ i ≤ r, we have Ai≠∅.

This decomposition is called the canonical decomposition of s.

Proof. If X = ∅, the statement follows from the convention on the empty sum. Assume that X≠∅. Fix x in X. Since s(x) belongs to s(X), there exists i such that s(x) = αi, hence x is in Ai. This proves (i). If x is in Ai ∩ Aj, then s(x) = αi and s(x) = αj, so αi = αj, and therefore i = j. This proves (ii). Finally, since αi is a value taken by s, there exists x in X such that s(x) = αi, hence x is in Ai. This proves (iii). For every x in X, property (i) gives an index i such that x is in Ai, and property (ii) shows that this index is unique. Therefore

∑ i=1rα i1Ai(x) = αi = s(x),

which proves (5.1). □

Lemma 5.3 (Refinement of finite partitions). Let X be a set and let (Ai)1≤i≤r be subsets of X such that ⋃ ⁡ i=1rA i = X and Ai ∩ Aj = ∅ whenever i≠j. Then

1X = ∑ i=1r1 Ai.

Proof. Let x in X. Since the sets Ai cover X, there exists i such that x is in Ai. Since they are pairwise disjoint, this index is unique. Hence exactly one term in the sum is equal to 1, while all the others are equal to 0. Therefore

∑ i=1r1 Ai(x) = 1 = 1X(x).
□

Proposition 5.4 (Finite range of simple functions). Let X be a set. Let r ∈ ℕ≥1, let α1,…,αr be real numbers, and let (Ai)1≤i≤r be subsets of X such that ⋃ ⁡ i=1rA i = X and Ai ∩ Aj = ∅ whenever i≠j. If

s = ∑ i=1rα i1Ai,

then

s(X) ⊂{α1,…,αr}.

In particular, s is a simple function.

Proof. Let x in X. Since the sets Ai cover X and are pairwise disjoint, there exists a unique index i such that x is in Ai. Therefore

s(x) = ∑ j=1rα j1Aj(x) = αi,

which proves that s(x) belongs to {α1,…,αr}. □

Any simple function admits an expression of the type (5.1), and the canonical decomposition is uniquely determined by the values taken by s. Yet there can be other decompositions of s of the form (5.1). For example, if we consider the function s from ℝ to ℝ given by

s := 1[0,1],

then

s = 0 ⋅1[0,1]c + 1 ⋅1[0,1],

is its canonical decomposition. But we also have

s = 0 ⋅1[0,1]c + 1[0,1∕2[ + 1[1∕2,1],

which is another decomposition and also satisfies the three properties above.

Let us also recall that a finite collection of subsets (Ai)1≤i≤r of X is called a partition if it satisfies (i), (ii), and (iii). A finite family satisfying only the covering and pairwise-disjointness properties will be called a finite disjoint cover.

5.2 Stability properties

Proposition 5.5 (Stability of simple functions). Let X be a set, and let s,t: X → ℝ be two simple functions. Then s + t, st, sup ⁡(s,t), and inf ⁡(s,t) are also simple functions.

The following proof even gives explicit formulas.

Lemma 5.6 (Product of indicators). Let X be a set and let A,B ⊂ X. Then

1A1B = 1A∩B.

Proof. Let x in X. If x belongs to A ∩ B, then both sides are equal to 1. Otherwise at least one of the two indicators on the left-hand side vanishes, and both sides are equal to 0. □

Proof. If X = ∅, then all the functions under consideration have empty image, hence are simple. We therefore assume that X≠∅. For integers n,m ≥ 1, let

s = ∑ i=1nα i1Ai,t = ∑ j=1mβ j1Bj,

where (Ai)1≤i≤n and (Bj)1≤j≤m are partitions of X, and αi,βj are real numbers. By Lemma 5.3, we have

1X = ∑ j=1m1 Bj = ∑ i=1n1 Ai.

Hence

s = s1X = s∑ j=1m1 Bj = ∑ j=1ms1 Bj = ∑ i=1n ∑ j=1mα i1Ai1Bj, t = t1X = t∑ i=1n1 Ai = ∑ i=1nt1 Ai = ∑ i=1n ∑ j=1mβ j1Ai1Bj.

Using Lemma 5.6, we have 1Ai1Bj = 1Ai∩Bj, and therefore

s + t = ∑ i=1n ∑ j=1m(α i + βj)1Ai∩Bj, st = ∑ i=1n ∑ j=1mα iβj1Ai∩Bj, sup ⁡(s,t) = ∑ i=1n ∑ j=1m sup ⁡(α i,βj)1Ai∩Bj, inf ⁡(s,t) = ∑ i=1n ∑ j=1m inf ⁡(α i,βj)1Ai∩Bj.

Each of these functions therefore takes only finitely many values, hence is simple. □

Remark 5.7 (Refined decompositions of simple functions). In the notation of the preceding proof, the sets

(Ci,j := Ai ∩ Bj)1≤i≤n,1≤j≤m

satisfy

Ci,j ∩ Ci′,j′ = ∅

for (i,j)≠(i′,j′), and

⋃ 1≤i≤n,1≤j≤mCi,j = X.

Yet the decompositions in the proof above are not canonical in general.

Proposition 5.8 (Simple functions as finite combinations of indicators). Let X be a set. Let N ∈ ℕ≥1 and let s1,…,sN: X → ℝ be simple functions. Then

∑ ℓ=1Ns ℓ,∏ ℓ=1Ns ℓ, max ⁡(s1,… ⁡,sN), min ⁡(s1,… ⁡,sN)

are simple functions.

Proof. We proceed by induction on N and repeatedly apply Proposition 5.5. □

5.3 A characterization of the simple functions which are measurable

Proposition 5.9 (Measurability criterion for simple functions). Let (X,A) be a measurable space and let s: X → ℝ. Then s is a simple measurable function if and only if there exist r ∈ ℕ≥1, measurable sets Ai in A such that ⋃ ⁡ i=1rA i = X and Ai ∩ Aj = ∅ whenever i≠j, and real numbers αi (1 ≤ i ≤ r) such that

s = ∑ i=1rα i1Ai.

Proof. Suppose that s is a simple measurable function. If X = ∅, we may take r = 1, A1 = ∅, and α1 = 0. This gives the required representation. Assume now that X≠∅. Consider its canonical decomposition as in (5.1). Then, since the singletons of ℝ are closed and therefore Borel, we see that their preimages by s are measurable. Thus, for 1 ≤ i ≤ r, we have Ai = s−1({α i}) in A.

Conversely, assume that there exist r ∈ ℕ≥1, measurable sets Ai in A such that ⋃ ⁡ i=1rA i = X and Ai ∩ Aj = ∅ whenever i≠j, and real numbers αi such that

s = ∑ i=1rα i1Ai.

Proposition 5.4 shows that s is simple. Let B in B(ℝ). Then

s−1(B) = ⋃ {i: αi∈B}Ai,

which is in A. Hence s is measurable. □

Corollary 5.10 (Simple functions and algebraic stability). Let (X,A) be a measurable space and let s,t: X → ℝ be simple measurable functions. Then

s + t,st, sup ⁡(s,t), inf ⁡(s,t)

are simple measurable functions. More generally, finite sums, finite products, finite pointwise maxima, and finite pointwise minima of simple measurable functions are again simple measurable functions.

Proof. It is enough to combine Proposition 5.5, Proposition 5.8, and Theorem 4.10. □

5.4 Lebesgue integral of a simple measurable function

Definition 5.11 (Integral of a nonnegative simple function). Let (X,A,μ) be a measure space. Let E in A. Let s: X → ℝ be a nonnegative simple measurable function. If X = ∅, we define

∫ Esdμ := 0.

If X≠∅, let

s = ∑ i=1rα i1Ai

denote the canonical decomposition of s, with αi ∈ ℝ≥0 and Ai in A for all i. Then the Lebesgue integral of s on E is defined to be

∫ Esdμ := ∑ i=1rα iμ(Ai ∩ E).

We use the convention 0 ⋅∞ = 0.

The following property is quite important, as many decompositions similar to the canonical one may compete. Fortunately enough, they all give the same value.

Proposition 5.12 (Independence of the decomposition). Let (X,A,μ) be a measure space. Let E in A and let s be a nonnegative simple measurable function. Assume that

s = ∑ i=1rα i1Ai

with αi ≥ 0, Ai ∈A for every i, ⋃ ⁡ i=1rA i = X, and the sets (Ai)1≤i≤r pairwise disjoint. Then

∑ i=1rα iμ(Ai ∩ E) = ∫ Esdμ,

where the integral is defined using the canonical decomposition of s.

Proof. Step 1. Common refinement of the two decompositions. Let s be a nonnegative simple measurable function. Let

s = ∑ k=1mβ k1Bk

be the canonical decomposition, so that (Bk)1≤k≤m are pairwise disjoint, ⋃ ⁡ k=1mB k = X, and βk are the distinct values taken by s. By definition,

∫ Esdμ = ∑ k=1mβ kμ(Bk ∩ E).

Assume that we also have a decomposition

s = ∑ i=1rα i1Ai,

where αi ≥ 0, Ai ∈A for every i, ⋃ ⁡ i=1rA i = X, and the sets (Ai)1≤i≤r are pairwise disjoint.

For each pair (i,k), we set

Ci,k := Ai ∩ Bk.

Then each Ci,k is in A, the family (Ci,k)1≤i≤r,1≤k≤m is pairwise disjoint, and

X = ⋃ i=1r ⋃ k=1mC i,k.

Moreover, if Ci,k≠∅ and x is in Ci,k, then s(x) = αi (since x is in Ai) and also s(x) = βk (since x is in Bk), hence αi = βk. Therefore, on each Ci,k we have the identity

αi1Ci,k = βk1Ci,k.

Step 2. Comparison of the two sums. We now compute using additivity of μ on disjoint unions. For fixed i,

Ai ∩ E = ⋃ k=1m(A i ∩ Bk ∩ E) = ⋃ k=1m(C i,k ∩ E),

and the union is disjoint, hence

μ(Ai ∩ E) = ∑ k=1mμ(C i,k ∩ E).

Thus

∑ i=1rα iμ(Ai ∩ E) = ∑ i=1rα i ∑ k=1mμ(C i,k ∩ E) = ∑ i=1r ∑ k=1mα iμ(Ci,k ∩ E).

Similarly, for fixed k,

Bk ∩ E = ⋃ i=1r(A i ∩ Bk ∩ E) = ⋃ i=1r(C i,k ∩ E),

disjoint union, hence

μ(Bk ∩ E) = ∑ i=1rμ(C i,k ∩ E),

and therefore

∫ Esdμ = ∑ k=1mβ kμ(Bk ∩ E) = ∑ k=1mβ k ∑ i=1rμ(C i,k ∩ E) = ∑ i=1r ∑ k=1mβ kμ(Ci,k ∩ E).

Finally, for each pair (i,k) we have αi = βk whenever Ci,k≠∅, and if Ci,k = ∅ then μ(Ci,k ∩ E) = 0, so in all cases

αiμ(Ci,k ∩ E) = βkμ(Ci,k ∩ E).

Summing over (i,k) yields

∑ i=1rα iμ(Ai ∩ E) = ∫ Esdμ,

which proves the independence of the decomposition. □

5.5 Properties of the Lebesgue integral of a simple measurable function

The following proposition establishes that the integral of simple functions is additive not only with respect to the integrand, but also with respect to the domain of integration. For the latter, the Chasles-type decomposition can even be performed with a countable family of parts.

Proposition 5.13 (Linearity of the simple integral). Let (X,A,μ) be a measure space. We have the following properties.

1.
Let s,t: X → ℝ≥0 be measurable simple functions. For all E in A,
∫ E(s + t)dμ = ∫ Esdμ + ∫ Etdμ.
2.
Let s: X → ℝ≥0 be a measurable simple function. Let (En)n≥1 be a sequence of pairwise disjoint elements of A. Then
∫ Esdμ = ∑ n=1∞∫ Ensdμ,where E := ⋃ n=1∞E n.

Proof. If X = ∅, both assertions are immediate from the empty-domain convention. We therefore assume that X≠∅.

1.
Let
s = ∑ i=1rα i1Ai,t = ∑ j=1mβ j1Bj,

be the canonical decompositions of s and t. By Lemma 5.3, we have

1X = ∑ j=1m1 Bj = ∑ i=1r1 Ai.

Therefore

s = s1X = s∑ j=1m1 Bj = ∑ j=1ms1 Bj = ∑ i=1r ∑ j=1mα i1Ai1Bj, t = t1X = t∑ i=1r1 Ai = ∑ i=1rt1 Ai = ∑ i=1r ∑ j=1mβ j1Ai1Bj.

By Lemma 5.6, we have 1Ai1Bj = 1Ai∩Bj, hence

s + t = ∑ i=1r ∑ j=1m(α i + βj)1Ai∩Bj.

The family (Ai ∩ Bj)1≤i≤r,1≤j≤m is pairwise disjoint and its union is X. Proposition 5.12 therefore gives

∫ E(s + t)dμ = ∑ i=1r ∑ j=1m(α i + βj)μ(Ai ∩ Bj ∩ E) = ∑ i=1r ∑ j=1mα iμ(Ai ∩ Bj ∩ E) + ∑ i=1r ∑ j=1mβ jμ(Ai ∩ Bj ∩ E) = ∑ i=1rα i ∑ j=1mμ(A i ∩ Bj ∩ E) + ∑ j=1mβ j ∑ i=1rμ(A i ∩ Bj ∩ E) = ∑ i=1rα iμ (Ai ∩ (⋃ j=1mB j ) ∩ E ) + ∑ j=1mβ jμ ( (⋃ i=1rA i ) ∩ Bj ∩ E ) = ∑ i=1rα iμ(Ai ∩ E) + ∑ j=1mβ jμ(Bj ∩ E) = ∫ Esdμ + ∫ Etdμ.
2.
Let
s = ∑ i=1rα i1Ai

be the canonical decomposition of s. For each i, the family (Ai ∩ En)n≥1 is pairwise disjoint, because the (En)n≥1 are pairwise disjoint. Therefore

∫ Esdμ = ∑ i=1rα iμ(Ai ∩ E) = ∑ i=1rα iμ (Ai ∩⋃ n=1∞E n ) = ∑ i=1rα iμ (⋃ n=1∞(A i ∩ En) ) = ∑ i=1rα i ∑ n=1∞μ(A i ∩ En) = ∑ n=1∞∑ i=1rα iμ(Ai ∩ En) = ∑ n=1∞∫ Ensdμ.

The interchange between the finite sum over i and the nonnegative series over n is justified because only finitely many outer terms are involved and all summands are nonnegative.

□
