Chapter 11
Modes of convergence

We now compare the main notions of convergence for measurable functions and the logical relations between them. The first part of the chapter concerns implications which do not use equi-integrability. Equi-integrability is then introduced exactly at the point where it becomes the additional hypothesis in the two Vitali implications. We end the chapter by collecting the model counterexamples which explain why the hypotheses cannot simply be removed.

Let (X,A,μ) be a measure space.

11.1 Four modes of convergence

Definition 11.1 (Almost uniform convergence). Let fn and f be measurable real-valued functions on (X,A,μ). We say that

1.
(fn) converges to f almost everywhere if there exists a measurable set Z ⊂ X with μ(Z) = 0 such that
fn(x) → f(x)as n → +∞

for each x in X ∖ Z;

2.
(fn) converges to f almost uniformly if for every 𝜀 > 0, there exists a measurable set E𝜀 ⊂ X such that μ(X ∖ E𝜀) < 𝜀 and
sup ⁡ x∈E𝜀|fn(x) − f(x)|→ 0as n → +∞;
3.
(fn) converges to f in L1(X,μ) if fn and f belong to L1(X,μ) and
∫ X|fn − f|dμ → 0as n → +∞;
4.
(fn) converges to f in measure if for every δ > 0,
μ({|fn − f| > δ}) → 0as n → +∞.

For these four modes of convergence we will respectively use the short-cut notations a.e., a.u., L1 and μ.

11.2 Implications not involving equi-integrability

We first prove the implications which do not require any equi-integrability hypothesis. Some of them are unconditional, while others require either the finiteness of the measure or the extraction of a subsequence.

11.2.1 Almost uniform versus almost everywhere convergence

We start with implication (i), that is, almost uniform convergence implies almost everywhere convergence.

Proposition 11.2 (Almost uniform convergence implies almost everywhere convergence). Let fn and f be measurable functions. If (fn) converges to f almost uniformly, then it converges to f almost everywhere.

Proof. If (fn) converges to f almost uniformly, then, by definition, for every 𝜀 > 0, there exists a measurable set E𝜀 ⊂ X such that

μ(X ∖ E𝜀) < 𝜀and sup ⁡ x∈E𝜀|fn(x) − f(x)|→ 0as n → +∞. (11.1)

Take 𝜀 = 1∕k with k in ℕ∗, and define

Z := ⋂ k=1∞(X ∖ E 1∕k).

Then, for every k in ℕ∗, we have

μ(Z) ≤ μ(X ∖ E1∕k) < 1∕k.

Letting k → +∞, we obtain μ(Z) = 0. Moreover,

X ∖ Z = ⋃ k=1∞E 1∕k.

Thus, for each x in X ∖ Z, there exists k in ℕ∗ such that x belongs to E1∕k. For this k, we have

|fn(x) − f(x)|≤ sup ⁡ y∈E1∕k|fn(y) − f(y)|.

The right-hand side goes to 0 as n → +∞ by (11.1), applied with 𝜀 = 1∕k. Hence fn(x) → f(x) as n → +∞ for every x in X ∖ Z. □

The converse statement is true in the case of finite measures; this is Egoroff’s theorem and corresponds to arrow (ii) in Figure 11.1.

Theorem 11.3 (Egoroff theorem). Assume that μ(X) < ∞. Let fn and f be measurable functions. If (fn) converges almost everywhere to f, then (fn) converges almost uniformly to f.

Proof. We use a fixed summable budget. For every i,j in ℕ∗, define

Ei,j := ⋃ n=j∞{|f n − f| > 2−i}.

For each fixed i, the sequence (Ei,j)j≥1 is decreasing. Since μ(X) < ∞, Theorem 2.3, item 2), gives

lim ⁡ j→+∞μ(Ei,j) = μ (⋂ j=1∞E i,j) .

If x belongs to ∩j=1∞E i,j, then, for every j ≥ 1, there exists n ≥ j such that

|fn(x) − f(x)| > 2−i.

Thus the sequence (fn(x)) cannot converge to f(x). Since fn → f almost everywhere as n → +∞, this intersection is negligible. Consequently,

lim ⁡ j→+∞μ(Ei,j) = 0.

For each i ≥ 1, we can therefore choose an integer N(i) such that

μ(Ei,N(i)) < 2−i.

Let 𝜀 > 0. Choose i𝜀 in ℕ∗ such that

∑ i=i𝜀∞2−i < 𝜀.

Define

E𝜀 := X ∖⋃ i=i𝜀∞E i,N(i).

Then

μ(X ∖ E𝜀) ≤∑ i=i𝜀∞μ(E i,N(i)) < ∑ i=i𝜀∞2−i < 𝜀.

Moreover, for every i ≥ i𝜀, every n ≥ N(i), and every x in E𝜀, we have x∉Ei,N(i), hence

|fn(x) − f(x)|≤ 2−i.

Thus

sup ⁡ x∈E𝜀|fn(x) − f(x)|≤ 2−i

for every n ≥ N(i) and every i ≥ i𝜀. Since i can be chosen arbitrarily large, fn → f uniformly on E𝜀 as n → +∞. □

11.2.2 Almost uniform versus convergence in measure

We now compare almost uniform convergence and convergence in measure. We start with implication (iii): almost uniform convergence is stronger than convergence in measure.

Theorem 11.4 (Almost uniform convergence implies convergence in measure). Let fn and f be measurable functions. If (fn) converges to f almost uniformly, then it converges to f in measure.

Proof. Let δ > 0 and 𝜀 > 0. Since (fn) converges to f almost uniformly, there exists a measurable set E𝜀 ⊂ X such that

μ(X ∖ E𝜀) < 𝜀and sup ⁡ x∈E𝜀|fn(x) − f(x)|→ 0as n → +∞.

Thus there exists N in ℕ∗ such that, for every n ≥ N,

sup ⁡ x∈E𝜀|fn(x) − f(x)| < δ.

For every such n,

{|fn − f| > δ}∩ E𝜀 = ∅,

and therefore

μ({|fn − f| > δ}) ≤ μ(X ∖ E𝜀) < 𝜀.

Since 𝜀 > 0 is arbitrary, we get

μ({|fn − f| > δ}) → 0as n → +∞.

This proves convergence in measure. □

The converse statement, which is implication (iv), only holds after extraction of a subsequence.

Theorem 11.5 (Almost uniform subsequence theorem). Let fn and f be measurable functions. If (fn) converges to f in measure, then there exists a subsequence (fnk) which converges to f almost uniformly.

Proof. We use the same summable-budget device as in the proof of Egoroff’s theorem. Set ak := 2−k. Since (fn) converges in measure to f, we can choose, by induction, a strictly increasing sequence of integers (nk)k≥1 such that

μ ( {|fnk − f| > 1 k }) < ak

for every k in ℕ∗. Define

Ek := {|fnk − f|≤ 1 k }.

Let 𝜀 > 0, and choose k𝜀 in ℕ∗ such that

∑ k=k𝜀∞a k < 𝜀.

Set

E𝜀 := ⋂ k=k𝜀∞E k.

Then

X ∖ E𝜀 = ⋃ k=k𝜀∞(X ∖ E k),

so that

μ(X ∖ E𝜀) ≤∑ k=k𝜀∞μ(X ∖ E k) < ∑ k=k𝜀∞a k < 𝜀.

Moreover, for every x in E𝜀 and every k ≥ k𝜀, we have

|fnk(x) − f(x)|≤ 1 k.

Thus

sup ⁡ x∈E𝜀|fnk(x) − f(x)|≤ 1 k

for every k ≥ k𝜀. Therefore fnk → f uniformly on E𝜀 as k → +∞, and the subsequence (fnk) converges to f almost uniformly. □

11.2.3 One-way links from L1 convergence

We now record the two implications from L1 convergence which do not require equi-integrability. First, L1 convergence implies almost everywhere convergence after extraction of a subsequence.

Theorem 11.6 (Riesz–Fischer extraction theorem). Let fn and f be in L1(μ). If (fn)n≥1 converges to f in L1(μ) as n → +∞, then there exists a subsequence (fφ(n))n≥1 which converges to f μ-almost everywhere.

Proof. Since fn → f in L1(μ), the sequence (fn) is Cauchy in L1(μ). By the completeness theorem, Theorem 8.19, there exists a subsequence (fφ(n)) which converges almost everywhere to some representative g of the L1 limit of the sequence. The convergence in L1 also gives

∥g − f∥1 ≤∥g − fφ(n)∥1 + ∥fφ(n) − f∥1 → 0as n → +∞.

Thus g = f μ-almost everywhere. After changing g on a negligible set, the chosen subsequence converges to f μ-almost everywhere. □

Second, L1 convergence implies convergence in measure, by Markov’s inequality.

Theorem 11.7 (L1 convergence implies convergence in measure). Let (X,A,μ) be a measure space and let (fn) be a sequence of integrable functions converging in L1(X,μ) to an integrable function f as n → +∞. Then (fn) converges to f in measure.

Proof. Let δ > 0. Markov’s inequality gives

δμ({|fn − f| > δ}) ≤∫ X|fn − f|dμ → 0as n → +∞.

Hence μ({|fn − f| > δ}) → 0 for every δ > 0. □

11.3 Equi-integrability and the Vitali implications

We now introduce the additional hypothesis needed to reverse the two links toward L1 convergence. The condition rules out concentration of mass on sets of very small measure.

Definition 11.8 (Equi-integrability). A sequence of integrable functions (fn)n∈ℕ∗ is said to be equi-integrable if for every 𝜀 > 0, there exists δ > 0 such that

sup ⁡ n∈ℕ∗∫ E|fn|dμ ≤ 𝜀

for every measurable set E ⊂ X satisfying μ(E) ≤ δ.

Proposition 11.9 (Elementary examples of equi-integrability). The following properties hold.

1.
Let f be in L1(X,μ) and let (fn)n∈ℕ∗ be the sequence constant equal to f. Then (fn) is equi-integrable.
2.
Let k be in ℕ∗ and let f1,…,fk be in L1(X,μ). Then the sequence (f1,…,fk,fk,…,fk,…) is equi-integrable.
3.
Let (fn) be a sequence of functions converging to f in L1(X,μ) as n → +∞. Then (fn) is equi-integrable.

Proof. We prove the three items separately.

Proof of 1). Let 𝜀 > 0. By Corollary 8.13, applied to the integrable function f, there exists δ > 0 such that, for every measurable set E ⊂ X satisfying μ(E) ≤ δ, one has

∫ E|f|dμ ≤ 𝜀.

For the constant sequence fn = f, this gives

sup ⁡ n∈ℕ∗∫ E|fn|dμ = ∫ E|f|dμ ≤ 𝜀.

Thus the constant sequence is equi-integrable.

Proof of 2). Let 𝜀 > 0. By item 1), applied to each of the finitely many functions f1,…,fk, there exist δ1,…,δk > 0 such that

∫ E|fi|dμ ≤ 𝜀

whenever μ(E) ≤ δi. Taking δ := min ⁡ 1≤i≤kδi, we obtain, for every measurable set E ⊂ X satisfying μ(E) ≤ δ,

sup ⁡ n∈ℕ∗∫ E|fn|dμ = max ⁡ 1≤i≤k ∫ E|fi|dμ ≤ 𝜀.

This proves item 2).

Proof of 3). Let 𝜀 > 0. Since fn → f in L1(X,μ) as n → +∞, there exists n0 in ℕ∗ such that

∫ X|fn − f|dμ ≤ 𝜀 2

for every n ≥ n0. By item 1), applied to the constant sequence equal to f, there exists δ1 > 0 such that

∫ E|f|dμ ≤ 𝜀 2

for every measurable set E ⊂ X satisfying μ(E) ≤ δ1. Therefore, for every n ≥ n0 and every such set E,

∫ E|fn|dμ ≤∫ E|fn − f|dμ + ∫ E|f|dμ ≤ 𝜀.

If n0 = 1, this already proves the claim. If n0 ≥ 2, item 2), applied to the finite family f1,…,fn0−1, gives δ2 > 0 such that

sup ⁡ 1≤n<n0 ∫ E|fn|dμ ≤ 𝜀

whenever μ(E) ≤ δ2. Taking δ := min ⁡(δ1,δ2) in the case n0 ≥ 2, and δ := δ1 in the case n0 = 1, we get

sup ⁡ n∈ℕ∗∫ E|fn|dμ ≤ 𝜀

for every measurable set E ⊂ X satisfying μ(E) ≤ δ. Thus (fn) is equi-integrable. □

A useful practical criterion is the following tail criterion. It separates equi-integrability from the mere boundedness of the L1 norms.

Proposition 11.10 (Tail criterion for equi-integrability). Let (fn)n∈ℕ∗ be a bounded sequence in L1(X,μ). Then the sequence (fn) is equi-integrable if and only if

lim ⁡ R→+∞ sup ⁡ n∈ℕ∗∫ {|fn|>R}|fn|dμ = 0.

Proof. Let

M := sup ⁡ n∈ℕ∗∫ X|fn|dμ < ∞.

Step 1. Assume that (fn) is equi-integrable, and let 𝜀 > 0. Choose δ > 0 such that

sup ⁡ n∈ℕ∗∫ E|fn|dμ ≤ 𝜀

for every measurable set E ⊂ X with μ(E) ≤ δ. Choose R𝜀 > 0 such that

M R𝜀 ≤ δ.

Then, for every R ≥ R𝜀 and every n in ℕ∗, Markov’s inequality gives

μ({|fn| > R}) ≤ 1 R∫ X|fn|dμ ≤M R ≤ δ.

Therefore

sup ⁡ n∈ℕ∗∫ {|fn|>R}|fn|dμ ≤ 𝜀

for every R ≥ R𝜀.

Step 2. Conversely, suppose that

lim ⁡ R→+∞ sup ⁡ n∈ℕ∗∫ {|fn|>R}|fn|dμ = 0.

Fix 𝜀 > 0, and choose R𝜀 > 0 such that

sup ⁡ n∈ℕ∗∫ {|fn|>R𝜀}|fn|dμ ≤ 𝜀 2.

Then, for every measurable set E ⊂ X with

μ(E) ≤ 𝜀 2R𝜀 =: δ,

and for every n in ℕ∗, we have

∫ E|fn|dμ = ∫ E∩{|fn|>R𝜀}|fn|dμ + ∫ E∩{|fn|≤R𝜀}|fn|dμ ≤ 𝜀 2 + R𝜀μ(E) ≤ 𝜀.

This proves equi-integrability. □

11.3.1 The first Vitali theorem

The first Vitali theorem says that, on a finite-measure space, equi-integrability promotes almost everywhere convergence to L1 convergence.

Theorem 11.11 (First Vitali theorem). Let μ be a finite measure. Let (fn) be an equi-integrable sequence of integrable functions, and let f be a measurable function. Assume that fn → f almost everywhere as n → +∞. Then f belongs to L1(X,μ) and

∫ X|fn − f|dμ → 0as n → +∞.

Proof. Let 𝜀 > 0. Since (fn) is equi-integrable, there exists δ > 0 such that

sup ⁡ n∈ℕ∗∫ E|fn|dμ ≤ 𝜀 4

for every measurable set E ⊂ X with μ(E) ≤ δ. By Egoroff’s theorem, applied with the exceptional measure δ, there exists a measurable set Eδ ⊂ X such that μ(X ∖ Eδ) < δ and (fn) converges uniformly to f on Eδ. Choose n0 such that

sup ⁡ x∈Eδ|fn0(x) − f(x)|≤ 1.

Then |f|≤|fn0| + 1 on Eδ, and therefore f is integrable on Eδ because μ(Eδ) < ∞. By Fatou’s lemma, for every measurable set E ⊂ X with μ(E) ≤ δ,

∫ E|f|dμ ≤liminf ⁡n→+∞∫ E|fn|dμ ≤ 𝜀 4.

Applying this to X ∖ Eδ shows that f is also integrable on X ∖ Eδ. Hence f belongs to L1(X,μ). Moreover,

∫ X|fn − f|dμ = ∫ Eδ|fn − f|dμ + ∫ X∖Eδ|fn − f|dμ ≤ μ(X) sup ⁡ x∈Eδ|fn(x) − f(x)| + ∫ X∖Eδ|fn|dμ + ∫ X∖Eδ|f|dμ ≤ μ(X) sup ⁡ x∈Eδ|fn(x) − f(x)| + 𝜀 2.

Letting n → +∞, we get

limsup ⁡ n→+∞∫ X|fn − f|dμ ≤ 𝜀 2.

Since 𝜀 is arbitrary, fn → f in L1(X,μ) as n → +∞. □

11.3.2 The second Vitali theorem

The second Vitali theorem promotes convergence in measure to L1 convergence, again under the finite-measure and equi-integrability hypotheses. We first isolate the reduction which replaces the sequence (fn) by the sequence of differences gn := fn − f.

Lemma 11.12 (Vitali difference reduction). Let (fn) be an equi-integrable sequence in L1(X,μ), and let f be in L1(X,μ). Define

gn := fn − f.

Then (gn) is equi-integrable. If fn → f in measure, then gn → 0 in measure. If, moreover, (Xk)k≥1 is a finite-measure exhaustion of a σ-finite space and (fn) has uniformly small tails along (Xk), then (gn) has uniformly small tails along (Xk).

Proof. Let 𝜀 > 0. Since (fn) is equi-integrable, there exists δ1 > 0 such that

sup ⁡ n∈ℕ∗∫ E|fn|dμ ≤ 𝜀 2

whenever μ(E) ≤ δ1. Since f is integrable, Corollary 8.13 gives δ2 > 0 such that

∫ E|f|dμ ≤ 𝜀 2

whenever μ(E) ≤ δ2. With δ := min ⁡(δ1,δ2), we obtain

∫ E|gn|dμ ≤∫ E|fn|dμ + ∫ E|f|dμ ≤ 𝜀

for every measurable set E ⊂ X satisfying μ(E) ≤ δ and every n in ℕ∗. Thus (gn) is equi-integrable.

If fn → f in measure, then, for every δ > 0,

μ({|gn| > δ}) = μ({|fn − f| > δ}) → 0.

Hence gn → 0 in measure.

Assume finally that (Xk) is a finite-measure exhaustion and that (fn) has uniformly small tails along (Xk). Since f is integrable,

∫ X∖Xk|f|dμ → 0as k → +∞.

Therefore

sup ⁡ n≥1 ∫ X∖Xk|gn|dμ ≤ sup ⁡ n≥1 ∫ X∖Xk|fn|dμ + ∫ X∖Xk|f|dμ → 0.

This proves the last assertion. □

Theorem 11.13 (Second Vitali theorem). Let (X,A,μ) be a measure space with μ(X) < ∞. Let (fn) be an equi-integrable sequence of integrable functions, and let f be a measurable function. Assume that fn → f in measure as n → +∞. Then f belongs to L1(X,μ) and

∫ X|fn − f|dμ → 0as n → +∞.

Proof. By the subsequence theorem for convergence in measure, there exists a subsequence (fnk) which converges to f almost uniformly. Hence this subsequence converges to f almost everywhere. Since (fnk) is equi-integrable, the first Vitali theorem, Theorem 11.11, gives f in L1(X,μ).

Define gn := fn − f. By Lemma 11.12, the sequence (gn) is equi-integrable and converges to 0 in measure. Let 𝜀 > 0. Choose δ > 0 such that

∫ E|gn|dμ ≤ 𝜀 2 (11.2)

for every measurable set E ⊂ X with μ(E) ≤ δ and every n in ℕ∗. Choose c > 0 such that cμ(X) < 𝜀∕2. Since gn → 0 in measure, there exists N such that

μ({|gn|≥ c}) < δ

for every n ≥ N. For every n ≥ N, we have

∫ X|gn|dμ = ∫ {|gn|≥c}|gn|dμ + ∫ {|gn|<c}|gn|dμ ≤ 𝜀 2 + cμ(X) < 𝜀,

where (11.2) has been applied to {|gn|≥ c}. Thus fn → f in L1(X,μ). □

11.3.3 Vitali theorems on σ-finite spaces

The two Vitali implications above use the finite-measure assumption. On a σ-finite space, this assumption can be replaced by a uniform tail condition along a finite-measure exhaustion.

Definition 11.14 (Uniformly small tails). Let (X,A,μ) be σ-finite and let (Xk)k≥1 be an increasing sequence in A such that μ(Xk) < ∞ and ∪k≥1Xk = X. A family (fn) of integrable functions is said to have uniformly small tails along (Xk) if

lim ⁡ k→+∞ sup ⁡ n≥1 ∫ X∖Xk|fn|dμ = 0.

Of course, every finite measure space satisfies this assumption by taking Xk = X for every k. We first extend the first Vitali theorem.

Theorem 11.15 (First Vitali theorem on sigma-finite spaces). Let (X,A,μ) be σ-finite. Let (fn) be an equi-integrable sequence of integrable functions, and let f be a measurable function. Assume that fn → f almost everywhere as n → +∞. Assume moreover that there exists an increasing sequence (Xk)k≥1 in A such that μ(Xk) < ∞, ∪k≥1Xk = X, and (fn) has uniformly small tails along (Xk). Then f belongs to L1(X,μ) and

∫ X|fn − f|dμ → 0as n → +∞.

Proof. Let 𝜀 > 0. Choose k ≥ 1 such that

sup ⁡ n≥1 ∫ X∖Xk|fn|dμ ≤ 𝜀 3.

By Fatou’s lemma,

∫ X∖Xk|f|dμ ≤liminf ⁡n→+∞∫ X∖Xk|fn|dμ ≤ 𝜀 3.

On Xk the measure is finite, the restriction of (fn) is equi-integrable, and fn → f almost everywhere. The finite-measure first Vitali theorem gives f in L1(X k,μ) and an integer N such that, for every n ≥ N,

∫ Xk|fn − f|dμ ≤ 𝜀 3.

The two previous estimates show that f belongs to L1(X,μ). Finally, for every n ≥ N,

∫ X|fn − f|dμ = ∫ Xk|fn − f|dμ + ∫ X∖Xk|fn − f|dμ ≤ 𝜀 3 + ∫ X∖Xk|fn|dμ + ∫ X∖Xk|f|dμ ≤ 𝜀. □

The second σ-finite extension follows by first extracting an almost everywhere convergent subsequence, then applying the preceding theorem.

Theorem 11.16 (Second Vitali theorem on sigma-finite spaces). Let (X,A,μ) be σ-finite. Let (fn) be an equi-integrable sequence of integrable functions, and let f be a measurable function. Assume that fn → f in measure on X as n → +∞. Assume moreover that there exists an increasing sequence (Xk)k≥1 in A such that μ(Xk) < ∞, ∪k≥1Xk = X, and (fn) has uniformly small tails along (Xk). Then f belongs to L1(X,μ) and

∫ X|fn − f|dμ → 0as n → +∞.

Proof. The subsequence theorem for convergence in measure gives a subsequence (fnj) which converges almost uniformly, hence almost everywhere, to f. The subsequence is equi-integrable and has uniformly small tails along (Xk). Therefore Theorem 11.15 applied to (fnj) gives f in L1(X,μ).

Define gn := fn − f. By Lemma 11.12, the sequence (gn) is equi-integrable, converges to 0 in measure, and has uniformly small tails along (Xk). Let 𝜀 > 0. Choose k ≥ 1 such that

sup ⁡ n≥1 ∫ X∖Xk|gn|dμ ≤ 𝜀 2.

On Xk the measure is finite. The restriction of (gn) to Xk is equi-integrable and converges to 0 in measure. The finite-measure second Vitali theorem, applied with limit 0, gives an integer N such that, for every n ≥ N,

∫ Xk|gn|dμ ≤ 𝜀 2.

Consequently, for every n ≥ N,

∫ X|fn − f|dμ = ∫ X|gn|dμ ≤∫ Xk|gn|dμ + ∫ X∖Xk|gn|dμ ≤ 𝜀.
□

11.3.4 Three model counterexamples

The hypotheses in the comparison theorems are not cosmetic. Three elementary families explain the role of the finite-measure assumption, the equi-integrability assumption, and the uniform tail assumption. We use the following terminology.

Example 11.17 (Three model counterexamples). The following three sequences are the basic counterexample mechanisms.

1.
On ]0, 1[ with the Lebesgue measure, the focusing spikes are
un(x) := n1]0,1∕n[(x).

They converge to 0 almost everywhere and in measure, but

∫ 01|u n(x)|dx = 1

for every n. They are not equi-integrable. Indeed, if δ > 0, choose n such that 1∕n < δ and set En :=]0, 1∕n[. Then λ(En) < δ and

∫ En|un|dλ = 1.
2.
On ℝ with the Lebesgue measure, the defocusing spikes are
vn(x) := 1 n1[0,n](x).

They converge uniformly to 0, hence also almost uniformly, almost everywhere, and in measure. They are equi-integrable, because |vn|≤ 1 for every n, and therefore

∫ E|vn|dλ ≤ λ(E)

for every measurable set E. However,

∥vn∥L1(ℝ) = 1

for every n. Moreover, if A ⊂ ℝ is measurable and λ(A) < ∞, then

∫ ℝ∖Avndλ = 1 −λ(A ∩ [0,n]) n → 1as n → +∞.

Thus the tails are not uniformly small along any finite-measure exhaustion.

3.
On ℝ with the Lebesgue measure, the translated indicators are
wn(x) := 1[n,n+1](x).

They converge to 0 almost everywhere, but they do not converge to 0 in measure on the whole space, since

λ({|wn| > 1∕2}) = λ([n,n + 1]) = 1

for every n. In particular they do not converge to 0 almost uniformly.

These examples answer the natural questions about the assumptions in the preceding theorems.

11.3.5 Complement: de la Vallée Poussin criterion

We finish with a useful characterization of equi-integrability. It is not needed in the proof of the comparison diagram, but it is often an efficient way to verify equi-integrability in applications.

Theorem 11.18 (de la Vallee Poussin criterion). Let (fn)n∈ℕ∗ be a bounded sequence in L1(X,μ). Then the sequence (fn) is equi-integrable if and only if there exists an increasing function 𝜃 : [0,∞) → [0,∞] with 𝜃(t)∕t →∞ as t → +∞ and such that

sup ⁡ n∈ℕ∗∫ X𝜃(|fn|)dμ < ∞.

Proof. Step 1. Assume that the sequence (fn) is equi-integrable. By Proposition 11.10, there is an increasing sequence of positive integers (ki) such that

sup ⁡ n∈ℕ∗∫ {|fn|>ki}|fn|dμ ≤ 1 2i

for every i ≥ 1. Define b0 = 0 and, for each l in ℕ∗, let bl be the number of indices i ≥ 1 such that ki < l. Note that bl ↗∞ as l → +∞. Set 𝜃(t) = 0 for t in [0, 1), and define

𝜃(t) = tbl if t ∈ [l,l + 1) and l ≥ 1.

Then

𝜃(t) t ≥ b[t] →∞as t → +∞,

where [t] denotes the integer part of t. Moreover, for all n in ℕ∗,

∫ X𝜃(|fn|)dμ = ∑ l=1∞∫ {l≤|fn|<l+1}𝜃(|fn|)dμ = ∑ l=1∞b l ∫ {l≤|fn|<l+1}|fn|dμ = ∑ l=1∞∑ {i≥1:ki<l}∫ {l≤|fn|<l+1}|fn|dμ ≤∑ i=1∞∫ {|fn|>ki}|fn|dμ ≤∑ i=1∞1 2i ≤ 1.

Step 2. Conversely, assume that there exists an increasing function 𝜃 : [0,∞) → [0,∞] with 𝜃(t)∕t →∞ as t → +∞ and such that

C := sup ⁡ n∈ℕ∗∫ X𝜃(|fn|)dμ < ∞.

Since 𝜃(t)∕t →∞ as t → +∞, for every 𝜀 > 0, there exists t𝜀 > 0 such that

𝜃(t) ≥(C + 1)t 𝜀  for all t ≥ t𝜀.

Then, for all t ≥ t𝜀,

sup ⁡ n∈ℕ∗∫ {|fn|>t}|fn|dμ ≤ 𝜀 C + 1 sup ⁡ n∈ℕ∗∫ {|fn|>t}𝜃(|fn|)dμ ≤ 𝜀.

Hence, by Proposition 11.10, the sequence (fn) is equi-integrable. □
