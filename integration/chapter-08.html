Chapter 8
Dominated convergence, L1(μ) and L1(μ)

We now gather in a single chapter the material on integrable functions, dominated convergence, negligible sets, and the passage from L1(μ) to L1(μ). Since the notions of negligible set and of property holding μ-almost everywhere were introduced earlier in Section 2.3, the almost everywhere form of the dominated convergence theorem can now be proved directly from the pointwise form.

8.1 Definition of Lebesgue integrability

We fix a measure space (X,A,μ).

Definition 8.1 (Integrable functions). We say that a function f from X to ℝ is in L1(μ) if

1.
f is (A,B(ℝ))-measurable,
2.
∫ X|f|dμ < ∞.

We denote

L1(μ) := L1(X,A,μ) := {f : X → ℝ: f is μ-integrable}.

For E in A, we define for all f in L1(μ),

∫ Efdμ := ∫ Ef+dμ −∫ Ef−dμ,

where

f+(x) := max ⁡{f(x), 0},f−(x) := max ⁡{−f(x), 0}

for all x in X.

We observe that for any function f we have the decompositions

f = f+ − f−,|f| = f+ + f−, (8.1)

and the properties

f+ ≥ 0,f− ≥ 0,f+(x)f−(x) = 0 for all x in X. (8.2)

Remark. Using Theorem 6.3 and Theorem 6.4 from the previous chapter, we see that

∫ Ef+dμ ≤∫ X|f|dμ < ∞,∫ Ef−dμ ≤∫ X|f|dμ < ∞,

since f is in L1(μ). This shows that ∫ Efdμ is indeed defined as the difference of two finite quantities.

8.2 Properties of the Lebesgue integral

For the following results, we keep the notation above.

Theorem 8.2 (Vector space and linearity of the integral). The set L1(μ) is a ℝ-vector space and, for all E in A, the map

f ∈L1(μ)↦∫ Efdμ ∈ ℝ

is linear. In other words, for all f,g in L1(μ) and for all c in ℝ, we have

∫ E(f + g)dμ = ∫ Efdμ + ∫ Egdμ,∫ E(cf)dμ = c∫ Efdμ.

Proof. Let f,g in L1(μ) and let c in ℝ. The measurability of f + g and cf follows from Theorem 4.10. Since

|f + g|≤|f| + |g|,|cf| = |c||f|,

the functions f + g and cf belong to L1(μ).

For the additivity, we use the pointwise identity

(f + g)+ + f− + g− = (f + g)− + f+ + g+,

which follows from (8.1). All the functions involved are positive and measurable, so the finite-sum form of Corollary 7.3 gives

∫ E(f + g)+dμ + ∫ Ef−dμ + ∫ Eg−dμ = ∫ E ((f + g)+ + f− + g− )dμ = ∫ E ((f + g)− + f+ + g+ )dμ = ∫ E(f + g)−dμ + ∫ Ef+dμ + ∫ Eg+dμ.

After rearranging, we obtain

∫ E(f + g)dμ = ∫ Efdμ + ∫ Egdμ.

For the homogeneity, if c ≥ 0, then

(cf)+ = cf+,(cf)− = cf−,

hence item 4 of Theorem 6.4 yields

∫ Ecfdμ = c∫ Ef+dμ − c∫ Ef−dμ = c∫ Efdμ.

If c < 0, then

(cf)+ = (−c)f−,(cf)− = (−c)f+,

and therefore

∫ Ecfdμ = (−c) ∫ Ef−dμ − (−c) ∫ Ef+dμ = c∫ Efdμ.

This completes the proof. □

Theorem 8.3 (Order properties of the integral).

1.
For all f,g in L1(μ) and for all E in A,
(∀ ⁡x ∈ E,f(x) ≤ g(x)) ⇒∫ Efdμ ≤∫ Egdμ.
2.
For all f in L1(μ) and for all E in A,
|∫ Efdμ | ≤∫ E|f|dμ.

Proof.

1.
Let h := g − f. Then h is in L1(μ) and h(x) ≥ 0 for all x in E. Therefore
∫ Ehdμ = ∫ Eh+dμ ≥ 0,

because h− = 0 on E and item 3 of Theorem 6.4 gives ∫ Eh−dμ = 0. Using the linearity proved above, we obtain

0 ≤∫ Ehdμ = ∫ Egdμ −∫ Efdμ,

which gives the result.

2.
Since
−|f|≤ f ≤|f|

on E, item 1 gives

−∫ E|f|dμ ≤∫ Efdμ ≤∫ E|f|dμ,

hence

| ∫ Efdμ | ≤∫ E|f|dμ.
□

Theorem 8.4 (Countable additivity over domains). For any f in L1(μ) and for any sequence (Ek)k≥1 of pairwise disjoint elements of A, if

E = ⋃ k≥1Ek,

then the series ∑ ⁡ k≥1 ∫ Ekfdμ converges absolutely and

∫ Efdμ = ∑ k≥1 ∫ Ekfdμ.

Proof. The functions f+ and f− are positive, measurable, and integrable. By the generalized Chasles property for positive functions,

∫ Ef+dμ = ∑ k≥1 ∫ Ekf+dμ,∫ Ef−dμ = ∑ k≥1 ∫ Ekf−dμ.

Both positive series are convergent because their sums are finite. Moreover,

∑ k≥1 |∫ Ekfdμ| ≤∑ k≥1 ∫ Ek|f|dμ = ∫ E|f|dμ < ∞,

so the signed series is absolutely convergent. Hence

∫ Efdμ = ∫ Ef+dμ −∫ Ef−dμ = ∑ k≥1 ∫ Ekf+dμ −∑ k≥1 ∫ Ekf−dμ = ∑ k≥1 (∫ Ekf+dμ −∫ Ekf−dμ) = ∑ k≥1 ∫ Ekfdμ. □

Theorem 8.5 (Integration over measurable subsets). For all E in A and for all f in L1(μ),

∫ Efdμ = ∫ Xf1Edμ.

Proof. Since |f1E|≤|f|, the function f1E belongs to L1(μ). Moreover,

(f1E)+ = f+1 E,(f1E)− = f−1 E.

Applying item 1 of Theorem 6.4 to the positive functions f+ and f−, we obtain

∫ Xf1Edμ = ∫ X(f1E)+dμ −∫ X(f1E)−dμ = ∫ Xf+1 Edμ −∫ Xf−1 Edμ = ∫ Ef+dμ −∫ Ef−dμ = ∫ Efdμ. □

Lemma 8.6 (Markov’s inequality). Let f be in L1(μ), let E be in A, and let α > 0. Then

αμ(E ∩{|f| > α}) ≤∫ E|f|dμ.

In particular,

μ({|f| > α}) ≤ 1 α∫ X|f|dμ.

Proof. Since

α1E∩{|f|>α} ≤|f|1E

on X, the comparison theorem and the indicator formulation give

αμ(E ∩{|f| > α}) = α∫ X1E∩{|f|>α}dμ = ∫ Xα1E∩{|f|>α}dμ ≤∫ X|f|1Edμ = ∫ E|f|dμ.

The particular case corresponds to E = X. □

Theorem 8.7 (Integrals on negligible sets). Let E in A and let f in L1(μ). If one of the following two conditions holds:

(a)
μ(E) = 0,
(b)
there exists E0 ⊂ E and E1 in A such that E0 ⊂ E1, μ(E1) = 0, and f(x) = 0 for all x in E ∖ E0,

then

∫ Efdμ = 0.

Proof. If μ(E) = 0, item 2 of Theorem 6.4 applied to f+ and f− yields

∫ Ef+dμ = 0,∫ Ef−dμ = 0,

hence

∫ Efdμ = 0.

Assume now that item (b) holds. Since f+ and f− vanish on E ∖ E0, item 3 of Theorem 6.4 applied to f+ and f− gives

∫ Ef+dμ = 0,∫ Ef−dμ = 0.

Therefore

∫ Efdμ = 0.
□

8.3 Equality almost everywhere

The notions of negligible set and of property holding almost everywhere now become essential.

Lemma 8.8 (Positive integrable functions are finite almost everywhere). Let h: X → [0, +∞] be measurable. If

∫ Xhdμ < +∞,

then h < +∞ μ-almost everywhere.

Proof. For every n ≥ 1, set

An := {x ∈ X : h(x) > n}.

Since n1An ≤ h, comparison gives

nμ(An) ≤∫ Xhdμ.

In particular, μ(A1) < ∞. Let

N := {x ∈ X : h(x) = +∞}.

Then N = ⋂ ⁡ n≥1An, and (An)n≥1 is decreasing. By continuity from above,

μ(N) = lim ⁡ n→∞μ(An) ≤ lim ⁡ n→∞1 n∫ Xhdμ = 0.

Hence h < +∞ outside the null set N. □

Let us now observe that two functions which are equal μ-almost everywhere have the same integral.

Lemma 8.9 (Equality almost everywhere and integrals). Let f,g: X → [0,∞] be measurable functions, or let f,g be in L1(X,A,μ). We assume that f = g μ-almost everywhere on X. Then for all E in A,

∫ Efdμ = ∫ Egdμ.

Proof. By definition of μ-almost everywhere, there exists M in A such that

μ(M) = 0and{x ∈ X : f(x)≠g(x)}⊂ M.

Assume first that f and g are positive measurable. Since f = g on E ∖ M, the comparison theorem for positive functions gives

∫ E∖Mfdμ = ∫ E∖Mgdμ.

Moreover, μ(E ∩ M) = 0, so item 2 of Theorem 6.4 yields

∫ E∩Mfdμ = 0,∫ E∩Mgdμ = 0.

Since

E = (E ∖ M) ∪ (E ∩ M)

is a disjoint union, the generalized Chasles property for positive functions gives

∫ Efdμ = ∫ E∖Mfdμ + ∫ E∩Mfdμ = ∫ E∖Mgdμ + ∫ E∩Mgdμ = ∫ Egdμ.

Assume now that f and g are in L1(μ). Then f − g is in L1(μ) and vanishes on X ∖ M. By the previous theorem,

∫ E(f − g)dμ = 0.

Using linearity, we conclude that

∫ Efdμ = ∫ Egdμ.
□

! The converse is generally false for positive measurable functions. On the other hand, the case g = 0 already gives a very useful characterization.

Lemma 8.10 (Characterization of zero integral). If f : X → [0,∞] is a measurable function, or if f is in L1(X,A,μ), then the following assertions are equivalent.

1.
f(x) = 0, μ-almost everywhere on X,
2.
for all E in A,
∫ Efdμ = 0,
3.
∫ X|f|dμ = 0.

Proof. We prove the implications one after another.

1) ⇒2). If f is positive measurable, the conclusion follows from item 3 of Theorem 6.4. If f is in L1(μ), it follows from the theorem on vanishing on negligible sets proved above.

2) ⇒3). If f is positive measurable, then |f| = f, so it is enough to take E = X in item 2. Assume now that f is in L1(μ). We set

E+ := {x ∈ X : f(x) ≥ 0},E− := {x ∈ X : f(x) < 0}.

These sets belong to A, and on them we have

|f| = f on E+,|f| = −f on E−.

Therefore

0 = ∫ E+fdμ = ∫ E+|f|dμ

and

0 = ∫ E−fdμ = −∫ E−|f|dμ.

Since |f| is integrable and

X = E+ ∪ E−,E+ ∩ E− = ∅,

the Chasles property gives

∫ X|f|dμ = ∫ E+|f|dμ + ∫ E−|f|dμ = 0.

3) ⇒1). We set

g := f

in the positive measurable case and

g := |f|

in the integrable case. Then g is positive and measurable, and

∫ Xgdμ = 0.

For every n ≥ 1, we define

An := {x ∈ X : g(x) > 1∕n}.

Since (1∕n)1An ≤ g, comparison gives

1 nμ(An) ≤∫ Xgdμ = 0.

Hence μ(An) = 0 for every n ≥ 1. If

N := {x ∈ X : g(x)≠0},

then

N = ⋃ n≥1An,

so μ(N) = 0. Thus g = 0 almost everywhere, and therefore f = 0 almost everywhere as well. □

8.4 Lebesgue dominated convergence theorem

We can now state one of the central results of the theory.

Theorem 8.11 (Lebesgue dominated convergence theorem, pointwise form). Let (X,A,μ) be a measure space. Let g in L1(μ) satisfy g(x) ≥ 0 for all x in X, and let

fn: X → ℝ,n ≥ 1,

be measurable functions satisfying the following two hypotheses:

  • domination hypothesis: for all n ≥ 1 and for all x in X,

    |fn(x)|≤ g(x),
  • pointwise convergence hypothesis: for all x in X, the sequence (fn(x))n≥1 converges to a limit f(x).

Then

1.
the function f : X → ℝ is in L1(μ),
2.
∫ X|fn − f|dμ → 0as n → +∞,
3.
∫ Xfndμ →∫ Xfdμas n → +∞.

Proof.

1.
The function f, as a pointwise limit of measurable functions, is measurable. Moreover, passing to the limit in the domination hypothesis, we obtain
|f(x)|≤ g(x)for all x in X.

By integration, this gives

∫ X|f|dμ ≤∫ Xgdμ < ∞,

and therefore f is in L1(μ).

2.
We consider the sequence of auxiliary functions
hn := 2g −|fn − f|.

By the triangle inequality and the domination hypothesis,

|fn − f|≤|fn| + |f|≤ 2g,

so each hn is a positive measurable function. Fatou’s lemma therefore gives

∫ X liminf ⁡ n→∞hndμ ≤liminf ⁡n→∞∫ Xhndμ. (8.3)

Moreover, by the pointwise convergence hypothesis, we have

|fn − f|→ 0as n → +∞

pointwise on X, hence

liminf ⁡ n→∞hn = 2gpointwise on X, (8.4)

and therefore

∫ X liminf ⁡ n→∞hndμ = ∫ X2gdμ. (8.5)

On the other hand, for every n ≥ 1 we have

hn + |fn − f| = 2g.

Since ∫ X2gdμ < ∞, Corollary 7.3 gives

∫ Xhndμ = ∫ X2gdμ −∫ X|fn − f|dμ.

Consequently,

liminf ⁡ n→∞∫ Xhndμ = ∫ X2gdμ −limsup ⁡n→∞∫ X|fn − f|dμ. (8.6)

Combining (8.3), (8.5), and (8.6), we obtain

limsup ⁡ n→∞∫ X|fn − f|dμ ≤ 0.

Since the integrals are nonnegative, this implies

∫ X|fn − f|dμ → 0as n → +∞.
3.
By the linearity of the integral and by item 2 of the theorem on comparisons, we have
| ∫ Xfndμ −∫ Xfdμ | = | ∫ X(fn − f)dμ | ≤∫ X|fn − f|dμ,

which tends to 0 by item 2. This proves the convergence of the integrals.

□

The previous theorem is the pointwise form. Since we already know how to work with negligible sets, we can immediately pass to the almost everywhere form.

Theorem 8.12 (Lebesgue dominated convergence theorem, almost everywhere form). Let (X,A,μ) be a measure space. Let g in L1(μ) satisfy g(x) ≥ 0 for all x in X, and let

fn,f : X → ℝ,n ≥ 1,

be measurable functions such that

1.
for every n ≥ 1, we have
|fn(x)|≤ g(x)

for μ-almost all x in X,

2.
fn(x) → f(x)as n → +∞

for μ-almost all x in X.

Then f is in L1(μ) and, for every E in A,

∫ E|fn − f|dμ → 0as n → +∞,

and therefore

∫ Efndμ →∫ Efdμas n → +∞.

Proof. Step 1. Removing the exceptional null set. For each n ≥ 1, let Nn be a μ-negligible set such that

|fn(x)|≤ g(x)

for all x in X ∖ Nn. Let N∞ be a μ-negligible set such that

fn(x) → f(x)as n → +∞

for all x in X ∖ N∞. By the countable stability of negligible sets, there exists M in A such that

μ(M) = 0andN∞∪⋃ n≥1Nn ⊂ M.

Step 2. Reduction to the pointwise dominated convergence theorem. We define

f~n := fn1X∖M,f~ := f1X∖M,g~ := g1X∖M.

Then the functions f~n, f~, and g~ are measurable, g~ is in L1(μ), and for all x in X we have

|f~n(x)|≤g~(x),f~n(x) →f~(x)as n → +∞.

The pointwise dominated convergence theorem therefore yields

∫ X|f~n −f~|dμ → 0as n → +∞.

In particular, f~ is in L1(μ).

Step 3. Returning to the original representatives. Now

|f| = |f~|μ-almost everywhere,

so Lemma 8.9 applied to the positive measurable functions |f| and |f~| gives

∫ X|f|dμ = ∫ X|f~|dμ < ∞.

Hence f is in L1(μ).

For each n ≥ 1, the positive measurable functions |fn| and |f~n| are equal μ-almost everywhere. Lemma 8.9 therefore gives

∫ X|fn|dμ = ∫ X|f~n|dμ ≤∫ Xg~dμ < ∞.

Thus every fn belongs to L1(μ).

Finally, for every E in A, Lemma 8.9 gives

∫ E|fn − f|dμ = ∫ E|f~n −f~|dμ,

and hence

∫ E|fn − f|dμ ≤∫ X|f~n −f~|dμ → 0.

Also,

∫ Efndμ = ∫ Ef~ndμ,∫ Efdμ = ∫ Ef~dμ.

Therefore

| ∫ Efndμ −∫ Efdμ | = | ∫ E(f~n −f~)dμ | ≤∫ E|f~n −f~|dμ,

and the right-hand side tends to 0. □

A first important consequence of the dominated convergence theorem is the following absolute-continuity property of the integral. It says, first, that the integral of an integrable function over a moving tail tends to zero, and, second, that a set of sufficiently small measure carries only a small part of the integral.

Corollary 8.13 (Absolute continuity of the integral). Let (X,A,μ) be a measure space and let f be in L1(μ). Then the following two properties hold.

1.
If (An)n≥1 is a sequence of measurable subsets of X such that
1An(x) → 0as n → +∞

for μ-almost all x in X, then

∫ An|f|dμ → 0as n → +∞.

In particular, this applies when (An) is decreasing and μ(∩n≥1An) = 0.

2.
For every 𝜀 > 0, there exists δ > 0 such that, for every measurable set E ⊂ X satisfying μ(E) ≤ δ, one has
∫ E|f|dμ ≤ 𝜀.

Proof. We first prove item 1). The functions |f|1An converge to 0 μ-almost everywhere as n → +∞, and they are dominated by the integrable function |f|. The dominated convergence theorem gives

∫ X|f|1Andμ → 0as n → +∞,

which is the desired conclusion. If (An) is decreasing and μ(∩n≥1An) = 0, then 1An →1∩n≥1An = 0 μ-almost everywhere, so the previous argument applies.

We now prove item 2). By item 1), applied to the sets

Am := {|f| > m},m ≥ 1,

there exists M ≥ 1 such that

∫ {|f|>M}|f|dμ ≤ 𝜀 2.

Set δ := 𝜀∕(2M). If E is measurable and μ(E) ≤ δ, then

∫ E|f|dμ = ∫ E∩{|f|≤M}|f|dμ + ∫ E∩{|f|>M}|f|dμ ≤ Mμ(E) + ∫ {|f|>M}|f|dμ ≤ 𝜀.

This proves the absolute-continuity property. □

In the special case where X = ℕ is endowed with the discrete σ-algebra and the enumeration measure # introduced in Chapter 1, an integrable function is an absolutely summable sequence. If u = (uk)k∈ℕ and ∑ ⁡ k|uk| < ∞, applying item 1) to the tails AN := {k ∈ ℕ: k ≥ N} gives

∑ k≥N|uk|→ 0as N → +∞,

which is the familiar fact that the remainder of an absolutely convergent series tends to zero.

The following result is a partial converse of dominated convergence.

Theorem 8.14 (Characterization of L1 convergence). Let fn and f be functions in L1(X,A,μ) such that

∫ X|fn − f|dμ → 0as n → +∞.

Then there exists a subsequence (fnk)k≥1 and a function g in L1(X,A,μ) such that

|fnk(x)|≤ g(x)

and

fnk(x) → f(x)as k → +∞

for μ-almost all x in X.

Proof. Step 1. Choosing a rapidly convergent subsequence. We choose an increasing sequence of integers (nk)k≥1 such that

∫ X|fnk − f|dμ ≤ 1 2k

for every k ≥ 1.

Step 2. Construction of an integrable dominator. Let

u := ∑ k=1∞|f nk − f|.

By Corollary 7.4,

∫ Xudμ = ∑ k=1∞∫ X|fnk − f|dμ ≤ 1.

For every m ≥ 1, we therefore have

mμ({u ≥ m}) ≤∫ {u≥m}udμ ≤∫ Xudμ ≤ 1.

Hence

μ({u = +∞}) = 0.

We set

N := {u = +∞}

and define

g(x) := { |f(x)| + u(x),x ∈ X ∖ N, 0, x ∈ N.

Then g is measurable and finite everywhere. Moreover, for every x in X,

g(x) ≤|f(x)| + u(x).

By the comparison theorem for positive functions and by Corollary 7.3, we obtain

∫ Xgdμ ≤∫ X(|f| + u)dμ = ∫ X|f|dμ + ∫ Xudμ ≤∫ X|f|dμ + 1 < ∞,

so that g is in L1(X,A,μ).

Step 3. Almost everywhere convergence and domination. Now let x ∈ X ∖ N. Since u(x) < ∞, the numerical series

∑ k=1∞|f nk(x) − f(x)|

converges. In particular,

|fnk(x) − f(x)|→ 0as k → +∞,

hence

fnk(x) → f(x)as k → +∞.

Moreover, for every k ≥ 1,

|fnk(x)|≤|f(x)| + |fnk(x) − f(x)|≤|f(x)| + u(x) = g(x).

Therefore

|fnk(x)|≤ g(x)andfnk(x) → f(x)as k → +∞

for every x in X ∖ N, that is, for μ-almost all x in X. □

Example 8.15 (A dominated-convergence example). Let X =]0, 1[, let A = B(]0, 1[), and let μ = λ. For every n ≥ 1, define

fn(x) := n1]0,1∕n[(x).

Then fn(x) → 0 as n → +∞for every x in ]0, 1[. Moreover, for every 𝜀 > 0 and every n > 𝜀, we have

{|fn| > 𝜀} =]0, 1∕n[,

so

λ({|fn| > 𝜀}) = 1 n → 0as n → +∞.

Thus (fn) converges to 0 in measure. On the other hand,

∫ 01|f n(x)|dx = ∫ 01∕nndx = 1

for every n ≥ 1. Hence (fn) does not converge to 0 in L1(]0, 1[). In particular, no function g in L1(]0, 1[) can dominate all the fn, because the dominated convergence theorem would then imply

∫ 01|f n(x)|dx → 0as n → +∞.

8.5 The Lebesgue space L1(μ)

We now pass from L1(μ) to the quotient by almost everywhere equality. We define on L1(μ) the equivalence relation

f ∼μg⟺f = gμ-almost everywhere.

By Lemma 8.9, representatives which are equal μ-almost everywhere have the same integrals. Moreover,

V 0(μ) := {f ∈L1(μ): f ∼ μ0} = {f ∈L1(μ): f = 0μ-almost everywhere}

is a sub-ℝ-vector space of L1(μ).

Definition 8.16 (The space L1(μ)). Let (X,A,μ) be a measure space. We denote by L1(μ) the set of equivalence classes of L1(μ) for the relation ∼μ. Equivalently,

L1(μ) = L1(μ)∕V 0(μ).

If f is in L1(μ), we denote by f¯ its class in L1(μ):

f¯ := f + V 0(μ) = {f + h: h ∈ V 0(μ)}.

Proposition 8.17 (The L1 norm). The mapping

L1(μ) → ℝ ≥0,f¯↦∥f¯∥1 := ∫ X|f|dμ

is a norm on L1(μ).

Proof. We first check that the formula is well defined. If f¯ = ḡ, then f = g μ-almost everywhere, hence |f| = |g| μ-almost everywhere. Lemma 8.9 applied to the positive measurable functions |f| and |g| gives

∫ X|f|dμ = ∫ X|g|dμ.

Positivity is clear. If ∥f¯∥1 = 0, then

∫ X|f|dμ = 0,

so Lemma 8.10 yields f = 0 μ-almost everywhere. Therefore f¯ = 0 in L1(μ).

Let c in ℝ. Then

∥cf¯∥1 = ∫ X|cf|dμ = |c|∫ X|f|dμ = |c|∥f¯∥1.

Finally, if f¯,ḡ are in L1(μ), then

|f + g|≤|f| + |g|

pointwise. By comparison and linearity,

∥f¯+ḡ∥1 = ∫ X|f+g|dμ ≤∫ X(|f|+|g|)dμ = ∫ X|f|dμ+∫ X|g|dμ = ∥f¯∥1+∥ḡ∥1.

This proves the triangle inequality. □

As usual, when no confusion can arise, we identify an equivalence class with one of its representatives and we simply write ∥f∥1 instead of ∥f¯∥1.

8.6 Dominated convergence theorem for series

Proposition 8.18 (Normally convergent series in L1). Let (X,A,μ) be a measure space and let (fn)n≥1 be a sequence in L1(μ) such that

∑ n≥1 ∫ X|fn|dμ < ∞.

Then there exists a measurable set N and a function f in L1(μ) such that μ(N) = 0 and

1.
for all x in X ∖ N, the series ∑ ⁡ n≥1|fn(x)| converges and
f(x) = ∑ n≥1fn(x),
2.
for all A in A,
∫ Afdμ = ∑ n≥1 ∫ Afndμ,
3.
lim ⁡ n→∞∫ X |f −∑ k=1nf k |dμ = 0.

Proof. Step 1. Construction of an integrable dominator. For x in X, we define

ϕ(x) := ∑ k=1∞|f k(x)|.

The function ϕ is positive and measurable as the limit of the sequence of partial sums. Since each |fk| is positive and measurable, the monotone convergence theorem gives

∫ Xϕdμ = lim ⁡ n→∞∫ X ∑ k=1n|f k|dμ = lim ⁡ n→∞∑ k=1n ∫ X|fk|dμ = ∑ k=1∞∫ X|fk|dμ < ∞.

By Lemma 8.8, the set

N := {x ∈ X : ϕ(x) = +∞}

belongs to A and satisfies μ(N) = 0. We set

ϕ~ := ϕ1X∖N.

Then ϕ~ is real-valued, nonnegative, measurable, equal to ϕ μ-almost everywhere, and belongs to L1(μ).

Step 2. Pointwise construction of the sum. For n ≥ 1, set

sn := ∑ k=1nf k.

On X ∖ N, the numerical series ∑ ⁡ kfk(x) is absolutely convergent. We define

f(x) := { 0, x ∈ N, ∑ k=1∞f k(x),x ∈ X ∖ N.

The function f is measurable because it is the pointwise limit of the measurable functions sn1X∖N. Item 1 follows from the definition of N. Moreover,

|f|≤ϕ~

on X, so f belongs to L1(μ).

Step 3. Passage to the limit under the integral on arbitrary measurable sets. On X ∖ N, the sequence (sn) converges pointwise to f, and for every n ≥ 1 we have

|sn|≤ϕ~.

Theorem 8.12 therefore implies that, for every A in A,

∫ Asndμ →∫ Afdμas n → +∞.

Since

∫ Asndμ = ∑ k=1n ∫ Afkdμ

by linearity, item 2 follows.

Step 4. Convergence in L1. Finally, on X ∖ N we have

f − sn → 0as n → +∞

and

|f − sn|≤|f| + |sn|≤ 2ϕ~.

A second application of Theorem 8.12, now to the sequence f − sn with dominator 2ϕ~, yields

∫ X|f − sn|dμ → 0as n → +∞.

This is exactly item 3. □

8.7 Completeness of L1

We conclude by proving the completeness of L1(μ).

Theorem 8.19 (Riesz–Fischer theorem for L1). Let (fn)n≥1 be a sequence in L1(μ) such that

∥fn − fm∥1 = ∫ X|fn − fm|dμ → 0as n,m → +∞.

Then there exists f in L1(μ) such that

1.
a subsequence of (fn)n≥1 converges to f μ-almost everywhere on X,
2.
∥fn − f∥1 → 0as n → +∞.

In particular, the normed vector space (L1(μ),∥⋅∥ 1) is a Banach space.

Proof. Step 1. Extraction of a subsequence with summable increments. Since (fn)n≥1 is Cauchy for ∥⋅∥1, there exists a strictly increasing map

φ: ℕ≥1 → ℕ≥1

such that

∥fφ(i+1) − fφ(i)∥1 < 2−i

for every i ≥ 1.

Step 2. Construction of the candidate limit. For i ≥ 1, we set

gi := fφ(i+1) − fφ(i).

Then

∑ i=1∞∫ X|gi|dμ ≤∑ i=1∞2−i < ∞.

By Proposition 8.18, there exist g in L1(μ) and a measurable set N with μ(N) = 0 such that, for all x in X ∖ N,

g(x) = ∑ i=1∞g i(x).

We define

f := fφ(1) + g.

Then f is in L1(μ). Moreover, for every x in X ∖ N and every n ≥ 2,

∑ i=1n−1g i(x) = fφ(n)(x) − fφ(1)(x),

so the convergence of the series implies

fφ(n)(x) → f(x)as n → +∞.

This proves item 1.

Step 3. L1 convergence of the extracted subsequence. By item 3 of Proposition 8.18,

∥g −∑ i=1n−1g i ∥1 → 0as n → +∞.

Using again the identity

∑ i=1n−1g i = fφ(n) − fφ(1),

we deduce that

∥fφ(n) − f∥1 → 0as n → +∞.

Step 4. Convergence of the whole Cauchy sequence. Let 𝜀 > 0. Choose n0 such that

∥fφ(n0) − f∥1 ≤ 𝜀∕2.

Since (fn) is Cauchy in ∥⋅∥1, there exists N0 such that

∥fn − fm∥1 ≤ 𝜀∕2

for all n,m ≥ N0. Taking n0 larger if necessary, we may assume that

φ(n0) ≥ N0.

Then, for every n ≥ N0,

∥fn − f∥1 ≤∥fn − fφ(n0)∥1 + ∥fφ(n0) − f∥1 ≤ 𝜀.

Thus ∥fn − f∥1 → 0 as n → +∞, which proves item 2.

Finally, let (un)n≥1 be a Cauchy sequence in L1(μ). Choose representatives fn in L1(μ) such that

un = f¯n.

Then

∥fn − fm∥1 = ∥un − um∥1 → 0as m,n → +∞,

so the first part of the theorem provides f in L1(μ) with

∥fn − f∥1 → 0as n → +∞.

Equivalently,

∥un −f¯∥1 → 0as n → +∞.

Hence every Cauchy sequence in L1(μ) converges in L1(μ), and (L1(μ),∥⋅∥ 1) is a Banach space. □

Corollary 8.20 (Nikodym metric). Let (X,A,μ) be a finite measure space. We identify two measurable sets when their symmetric difference is μ-negligible, and we denote by A~ the quotient set. For [A] and [B] in A~, we define

ρ([A], [B]) := μ(A△B).

Then ρ is a metric on A~, and (A~,ρ) is complete.

Proof. The map

Φ: A~ → L1(X,μ),Φ([A]) := 1 A¯,

is well defined and satisfies

∥Φ([A]) − Φ([B])∥L1(X,μ) = ∫ X|1A −1B|dμ = μ(A△B) = ρ([A], [B]).

Hence Φ is an isometry.

It remains to prove that the image of Φ is closed in L1(X,μ). Let (1An¯)n≥1 be a sequence in the image of Φ and assume that

1An¯ →f¯as n → +∞

in L1(X,μ), with f in L1(X,μ). The sequence (1An) is Cauchy after choosing the displayed representatives in L1(X,μ). By Theorem 8.19, it has a subsequence converging almost everywhere to a function which is equal to f in L1(X,μ). After changing f on a negligible set, we may therefore assume that this subsequence converges pointwise to f. Since each 1An only takes the values 0 and 1, it follows that

f(x) ∈{0, 1}

for μ-almost every x in X. Let

A := {x ∈ X : f(x) = 1}.

Then A is measurable and f¯ = 1A¯ in L1(X,μ). Thus the image of Φ is closed. Since L1(X,μ) is complete, the closed subset Φ(A~) is complete, and therefore (A~,ρ) is complete. □

8.8 A first link with positive Radon measures

As an application of the integral developed so far, let Ω be an open subset of ℝN and let μ be a positive Radon measure on Ω, viewed as a Borel measure on (Ω,B(Ω)). We denote by Cc(Ω) the space of continuous functions with compact support in Ω. Since the support of such a function is compact and μ is finite on compact sets, every function in Cc(Ω) is integrable with respect to μ.

Lemma 8.21 (A Radon functional associated with an integrable function). If μ is a positive Radon measure on Ω, then the map L: Cc(Ω) → ℝ defined by

L(f) := ∫ Ωfdμ

is a positive linear functional on Cc(Ω). Moreover, if K = supp(f), then

|L(f)|≤ μ(K)∥f∥∞.

Proof. Let f be in Cc(Ω) and let K = supp(f). Since K is compact and μ is a positive Radon measure, μ(K) < ∞. Moreover,

|f|≤∥f∥∞1K.

Therefore

∫ Ω|f|dμ ≤ μ(K)∥f∥∞ < ∞,

so L(f) is well defined and the displayed estimate follows. The linearity and positivity of L are immediate consequences of the properties of the Lebesgue integral. □

The converse problem, namely to reconstruct a positive Radon measure from a positive linear functional on Cc(Ω), will be solved later by the Riesz representation theorem.
