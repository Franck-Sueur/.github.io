Chapter 16
Appendix. Topology and functional analysis reminders

In this appendix we recall a few definitions from general topology and functional analysis, including compactness, separability, completeness, duality, and weak∗ compactness. An important particular case is that of metric spaces, for which most of the definitions can be rephrased in terms of sequences. We also recall the Baire category theorem, the extension of uniformly continuous functions, the uniform boundedness principle, and several standard results from Banach space theory.

16.1 Basic definitions

16.1.1 General topology

We start by recalling a few basic definitions of general topology.

Definition 16.1 (Topological spaces). Given a set X, we say that a subset τ of P(X) is a topology on X if

1.
∅ and X are in τ.
2.
τ is stable by finite intersection.
3.
τ is stable under arbitrary unions.

Then we say that (X,τ) is a topological space. The elements of τ are called open sets, and their complementary sets are the closed sets.

Definition 16.2 (Interior and closure). Given a topological space (X,τ) and a set A ⊂ X, we define

1.
the interior of A by A∘ := {x ∈ A :  there exists U ∈ τ such that x ∈ U ⊂ A};
2.
the closure of A by A¯ := {x ∈ X :  for any U ∈ τ with x ∈ U, then U ∩ A≠∅}.

We say that x ∈A¯ is an adherent point and x ∈ A∘ an interior point.

Observe that

A∘ ⊂ A ⊂A¯

.

Definition 16.3 (Dense subsets). Given a topological space (X,τ) and a set A ⊂ X, we say that A is dense in X for the topology τ if A¯ = X.

Definition 16.4 (Sequential convergence). Given a topological space (X,τ), we say that a sequence (xn)n∈ℕ ⊂ X converges to x in X if for any open set U ∈ τ with x ∈ U, there exists n0 ∈ ℕ such that xn ∈ U for all n ≥ n0.

Definition 16.5 (Continuity). Given two topological spaces (X1,τ1) and (X2,τ2), we say that a map f : X1 → X2 is continuous at x1 ∈ X1 if for every open set U ∈ τ2 such that f(x1) ∈ U, there exists an open set V ∈ τ1 such that x1 ∈ V and f(V ) ⊂ U. We say that f is continuous if it is continuous at every point of X1.

For extended real-valued functions the following notion of lower semicontinuity is weaker than continuity.

Definition 16.6 (Lower semicontinuity). Given a topological space (X,τ) and x0 in X, we say that a function f : X → ℝ ∪{−∞, +∞} is lower semicontinuous at x0 if for every α < f(x0), there exists a neighborhood U ∈ τ of x0 such that f(x) > α for all x in U. We say that f is lower semicontinuous if it is lower semicontinuous at every point of X.

It is not difficult to check that a function is lower semicontinuous if and only if

{x ∈ X : f(x) > α}

is an open set for every

α ∈ ℝ

.

16.1.2 Metric spaces

An important case of topological spaces is given by metric spaces that we now introduce.

Definition 16.7 (Metric spaces). Given a set X, we say that a function d : X × X → ℝ+ is a distance on X if

1.
d(x,y) = 0 if and only if x = y;
2.
d(x,y) = d(y,x);
3.
For any x, y, z ∈ X, d(x,y) ≤ d(x,z) + d(y,z).

Then we say that (X,d) is a metric space.

For any

x

in

X

and any

r > 0

, we denote

B(x,r) := {y ∈ X : d(x,y) < r}(resp. B¯(x,r) := {y ∈ X : d(x,y) ≤ r})

the open (resp. closed) ball of center x and radius r. A subset is said to be bounded if it is contained in a ball of finite radius.

Proposition 16.8 (Topology induced by a metric). Given a metric space (X,d), the family τ of all subsets U ⊂ X such that for each x ∈ U, there exists r > 0 satisfying B(x,r) ⊂ U defines a topology on X.

The following propositions, whose proofs are left to the reader, highlight the role of the sequences in metric spaces.

Proposition 16.9 (Sequential characterization of metric topology). Given a metric space (X,d) and the topology τ given by Proposition 16.8. The following statements hold:

1.
A sequence (xn)n∈ℕ ⊂ X converges to x in X if and only if for every 𝜀 > 0, there exists n0 ∈ ℕ such that for all n ≥ n0, then d(x,xn) < 𝜀;
2.
A subset F of X is closed if and only if for every sequence (xn)n∈ℕ ⊂ F converging to x in X, then x ∈ F.

Proposition 16.10 (Continuity in metric spaces). Let (X1,d1) and (X2,d2) be two metric spaces, f : X1 → X2 and x1 ∈ X1. Then the following statements are equivalent:

1.
f is continuous at x1;
2.
For any 𝜀 > 0, there exists δ > 0 such that if x ∈ X1 is such that d1(x1,x) < δ, then d2(f(x1),f(x)) < 𝜀;
3.
For any sequence (xn)n∈ℕ ⊂ X1 converging to x1, the sequence (f(xn))n∈ℕ converges to f(x1) in X2.

Proposition 16.11 (Sequential lower semicontinuity). Given a metric space (X,d) and x0 in X. A function f : X → ℝ ∪{−∞, +∞} is lower semicontinuous at x0 if and only if for any sequence (xn)n∈ℕ ⊂ X converging to x0 in X, then

f(x0) ≤liminf ⁡n→∞f(xn).

Lemma 16.12 (Compact exhaustion of open Euclidean sets). Let d ≥ 1 and let Ω be an open subset of ℝd. Then there exists an increasing sequence (Kn)n≥1 of compact subsets of Ω such that

Ω = ⋃ n=1∞K n.

More precisely, with the convention dist(x,∅) = +∞, one may take

Kn := {x ∈Ω : |x|≤ n and dist(x, ℝd ∖Ω) ≥ 1 n }.

Proof. The function x↦dist(x, ℝd ∖Ω) is continuous when ℝd ∖Ω is nonempty, and the convention for the empty complement makes the case Ω = ℝd immediate. Thus each Kn is closed and bounded in ℝd, hence compact. The inclusion Kn ⊂Ω is clear, and (Kn)n≥1 is increasing. Let x be in Ω. Since Ω is open, there exists ρ > 0 such that B(x,ρ) ⊂Ω, hence dist(x, ℝd ∖Ω) ≥ ρ. Choosing n large enough so that n ≥|x| and 1∕n ≤ ρ gives x ∈ Kn. Therefore the union of the Kn is Ω. □

Definition 16.13 (Uniform continuity). Let (X1,d1) and (X2,d2) be two metric spaces. We say that a map f : X1 → X2 is uniformly continuous if for any 𝜀 > 0, there exists δ > 0 such that if x and y ∈ X1 satisfy d1(x,y) < δ, then d2(f(x),f(y)) < 𝜀.

It is clear from the definitions above that uniform continuity implies continuity. We will see in Theorem 16.33 that the converse statement holds true when the space

(X1,d1)

is compact.

16.2 Completeness

16.2.1 Definition

Completeness is an important notion in general topology and in functional analysis because it enables one to characterize converging sequences without the knowledge of their limit. We first define the Cauchy property.

Definition 16.14 (Cauchy sequences). Given a metric space (X,d), we say that a sequence (un)n∈ℕ ⊂ X is a Cauchy sequence if for any 𝜀 > 0, there exists n0 ∈ ℕ such that for all n, n′ ≥ n 0 then d(un,un′) < 𝜀.

Definition 16.15 (Complete metric spaces). A metric space (X,d) is complete if any Cauchy sequence converges in X.

Let us give as a first example the set

ℝ

endowed with the usual metric

d(x,y) := |x − y|

. It is also useful to notice that a closed subset of a complete metric space is complete.

16.2.2 Baire category theorem

The following theorem is used in the proof of Lemma 12.4 and in the proof of the Uniform Boundedness Principle below.

Definition 16.16 (Nowhere dense sets). Let (X,d) be a metric space. A subset A of X is called nowhere dense if (A¯)∘ = ∅.

Theorem 16.17 (Baire category theorem). Let (X,d) be a nonempty complete metric space. If (Fn)n≥1 is a sequence of closed subsets of X such that

X = ⋃ n≥1Fn,

then there exists n0 ≥ 1 such that Fn0 has nonempty interior. Equivalently, if (Un)n≥1 is a sequence of dense open subsets of X, then ⋂ ⁡ n≥1Un is dense in X.

Proof. We prove first the dense-open formulation. Let U be a nonempty open subset of X. Since U1 is dense and open, the set U ∩ U1 is nonempty and open. Hence there exist x1 in X and r1 > 0 such that

B¯(x1,r1) ⊂ U ∩ U1andr1 ≤1 2.

Assume that xn and rn have been constructed. Since Un+1 is dense and open, the set B(xn,rn∕2) ∩ Un+1 is nonempty and open. We can therefore choose xn+1 in X and rn+1 > 0 such that

B¯(xn+1,rn+1) ⊂ B(xn,rn∕2) ∩ Un+1andrn+1 ≤ 2−(n+1).

The sequence (xn)n≥1 is Cauchy. Indeed, for every p,q ≥ n, the points xp and xq belong to B(xn,rn), hence d(xp,xq) ≤ 2rn, and rn → 0. Since X is complete, xn converges to some x in X. For each fixed n, all the points xm with m ≥ n belong to the closed ball B¯(xn,rn). Passing to the limit gives x in B¯(xn,rn). Thus x belongs to U and to every Un. Therefore every nonempty open subset U of X meets ⋂ ⁡ n≥1Un, so this intersection is dense.

Now let (Fn)n≥1 be a sequence of closed subsets whose union is X. If every Fn had empty interior, then Un := X ∖ Fn would be dense and open for every n. The dense-open formulation would give that ⋂ ⁡ n≥1Un is dense, hence nonempty, which contradicts X = ⋃ ⁡ n≥1Fn. Therefore at least one Fn has nonempty interior. □

16.2.3 Banach fixed point theorem for contraction mapping

An important application of the notion of completeness is given by the following theorem.

Theorem 16.18 (Banach fixed point theorem). Given a complete metric space (X,d) and f : X → X. Assume that f is a contraction, i.e. that there exists a constant 𝜃 ∈ (0, 1) such that for all x and y ∈ X, then d(f(x),f(y)) ≤ 𝜃d(x,y). Then there exists a unique fixed point x∗ ∈ X such that f(x∗) = x∗.

Proof. Let x0 ∈ X and let (xn)n∈ℕ the associated sequence defined by the relation

xn+1 = f(xn). (16.1)

By iteration we have

d(xn+1,xn) ≤ 𝜃nd(x 1,x0).

For any n′ > n,

d(xn′,xn) ≤∑ k=1n′−nd(x n+k,xn+k−1) ≤ d(x1,x0) ∑ k=1n′−n𝜃n+k−1 ≤ 𝜃n 1 − 𝜃d(x1,x0).

Therefore (xn)n∈ℕ is a Cauchy sequence, and by completeness, it converges to an element x∗ ∈ X. Since f is continuous, we have f(x∗) = x∗ by passing to the limit in (16.1). The uniqueness follows from the contraction assumption. □

The previous theorem is useful in the proof of the Cauchy-Lipschitz theorem in the theory of ordinary differential equations, and also in proof the local inversion theorem.

16.2.4 Extension of uniformly continuous functions

Theorem 16.19 (Extension theorem for uniformly continuous maps). Given two metric spaces (X1,d1) and (X2,d2), the latter being complete, a dense subset Y of X1, and a map f : Y → X2 which is uniformly continuous. Then there exists a unique uniformly continuous extension g : X1 → X2 of f.

Proof. The uniqueness is straightforward: indeed for any x ∈ X1, since Y is dense in X1, there exists a sequence (xn)n∈ℕ ⊂ Y which converges to x. If g : X1 → X2 is a uniformly continuous extension of f, then g(x) must be the limit of the sequence (f(xn))n∈ℕ.

Now to prove the existence of such an extension, observe that the sequence (f(xn))n∈ℕ has the Cauchy property, since (xn)n∈ℕ has the Cauchy property (because it converges) and f is uniformly continuous. Since (X2,d2) is complete, it yields that the sequence (f(xn))n∈ℕ converges to an element z in X2. This z does not depend on the choice of the sequence (xn)n∈ℕ in X1. Indeed, if (xn′) n∈ℕ is another sequence converging to x, then d1(xn,xn′) → 0 as n → +∞, so that, since f is uniformly continuous, d2(f(xn),f(xn′)) → 0 as n → +∞. Hence the sequence (f(xn′)) n∈ℕ converges to z as well. Therefore, it makes sense to define g(x) := z.

Let us now prove that g is uniformly continuous. Let 𝜀 > 0. Since f is uniformly continuous there exists δ > 0 such that for any x, x′ ∈ Y with d1(x,x′) < δ, there holds d2(f(x),f(x′)) < 𝜀∕3. Let y and y′ ∈ X 1 with d1(y,y′) < δ∕3. There exists x, x′ ∈ Y such that

d1(x,y) < δ∕3,d1(x′,y′) < δ∕3,d 2(f(x),g(y)) < 𝜀∕3 and d2(f(x′),g(y′)) < 𝜀∕3.

Therefore, thanks to the triangle inequality, we have d1(x,x′) < δ and therefore d2(f(x),f(x′)) < 𝜀∕3. Using again the triangle inequality, we get d2(g(y),g(y′)) < 𝜀. Hence g is uniformly continuous. □

16.2.5 Banach spaces

Let us recall a few definitions:

Definition 16.20 (Normed vector spaces). A normed vector space over ℝ is a pair (V,∥⋅∥) where V is a real vector space and ∥⋅∥is a norm on V that is a function from V to ℝ+ satisfying

1.
∥u∥ = 0 if and only if u = 0 (positive definiteness),
2.
for any u in V , for any λ ∈ ℝ, ∥λu∥ = |λ|∥u∥ (positive homogeneity),
3.
for any u, v in V , ∥u + v∥≤∥u∥ + ∥v∥ (triangle inequality or subadditivity).

If the first item above is not satisfied then ∥⋅∥ is called a seminorm.

Remark 16.21 (Complex normed spaces). We define in a similar way a normed vector space over ℂ by considering a complex vector space and by extending the second property above to any λ ∈ ℂ.

Remark 16.22 (Distance induced by a norm). We can easily associate a distance to the norm of a normed vector space, through the formula d(u,v) := ∥u − v∥.

Definition 16.23 (Banach spaces). If the topology defined by this distance is complete then we say that (V,∥⋅∥) is a Banach space.

Next proposition proves that in a normed vector space, completeness can be characterized thanks to the series.

Proposition 16.24 (Normally convergent series in Banach spaces). Let (V,∥⋅∥) be a normed vector space. Then (V,∥⋅∥) is a Banach space if and only if the series normally converging actually converge in (V,∥⋅∥).

Let us recall that a for sequence

(un)n

in

V

, we say that the series

∑ ⁡ nun

is normally converging in

V

if

∑ ⁡ n∥un∥

converges in

ℝ

.

Proof. suppose that V is complete, and let (un)n be a sequence in V such that ∑ ⁡ n∥un∥ converges in ℝ. Let 𝜀 > 0 be given and put vn := ∑ ⁡ k=0nu k. Then for n > m,

∥vn − vm∥ = ∥∑ k=m+1nu k∥≤∑ k=m+1n∥u k∥ < 𝜀

for all sufficiently large m and n, since ∑ ⁡ k=0n∥u k∥ < ∞. Hence (vn)n is a Cauchy sequence and so converges since V is complete, by hypothesis.

Conversely, assume that ∑ ⁡ nun converges in V whenever ∑ ⁡ n∥un∥ < ∞. Let (vn)n be a Cauchy sequence in V . We will prove that (vn)n converges in V . By iteration there exists a subsequence (vnk)k of (vn)n such that for any k, ∥vnk+1 − vnk∥≤ 2−k. Therefore, setting uk := vnk+1 − vnk, we have:

∑ k=0N∥u k∥≤∑ k=0N∥v nk+1 − vnk∥≤∑ k=0N2−k < ∞.

We therefore get that ∑ ⁡ k=0Nu k converges to some u in V as N → +∞. But

∑ k=0Nu k = ∑ k=0Nv nk+1 − vnk = vnN+1 − vn0,

so that vnN → u + vn0 as N → +∞. Thus the Cauchy sequence (vn)n has a convergent subsequence and so must itself converge. □

Let us now give a result to quotient spaces defined as follows.

Definition 16.25 (Quotient normed spaces). Let X be a vector space, and let M be a vector subspace of X. We define an equivalence relation ∼ on X by setting x ∼ y if and only if x − y ∈ M. It is straightforward to check that this is an equivalence relation on X. For x in X we denote by [x] the equivalence class containing the element x and we denote the set of equivalence classes by X∕M, that is, we call X∕M the quotient space of X by M.

We define on X∕M a sum law and a scalar multiplication law by [x] + [y] := [x + y] and α[x] := [αx].

Let us stress that these definitions are meaningful since M is a linear subspace of X. For example, if x ∼ x′ and y ∼ y′ then x + y ∼ x′ + y′, so that the definition is independent of the particular representatives taken from the various equivalence classes. Then it is straightforward to get the following.

Proposition 16.26 (Linear structure of quotients). The quotient space X∕M is a linear space.

Let us now define

∥[x]∥ := inf ⁡{∥y∥∕y ∈ [x]}. (16.2)

Proposition 16.27 (Quotient seminorm). The equality 16.2 defines a seminorm on X∕M.

Proof. Let α ∈ ℝ∗ and [x] be in X∕M. Then

∥α[x]∥ := ∥[αx]∥ = inf ⁡{∥y∥∕y ∈ [αx]} = inf ⁡{∥αx + m∥∕m ∈ M} = inf ⁡{∥αx + αm∥∕m ∈ M},

since the mapping m↦αm is a bijection. Thus

∥α[x]∥ = |α| inf ⁡{∥x + m∥∕m ∈ M} = |α|∥[x]∥.

On the other hand, since [0] = M we have that ∥[0]∥ = 0. Next, we consider the triangle inequality:

∥[x] + [y]∥ := ∥[x + y]∥ = inf ⁡{∥x + y + m∥∕m ∈ M} = inf ⁡{∥x + y + m′ + m″ ⁡∥∕m′,m″ ⁡ ∈ M} ≤ inf ⁡{∥x + m∥ + ∥y + m″ ⁡∥∕m′,m″ ⁡ ∈ M} ≤∥[x]∥ + ∥[y]∥. □

To see whether or not it is a norm, all that remains is to see if ∥[x]∥ = 0 implies [x] = 0. This may be wrong in general but next proposition proves that it is true if M is closed.

Proposition 16.28 (Quotient norm). Assume that M is a closed linear subspace of the normed space X. Then 16.2 defines a norm on X∕M, called the quotient norm.

Proof. Assume that ∥[x]∥ = 0. Then for any n ∈ ℕ∗ there exists mn ∈ M such that ∥x + mn∥≤ 1∕n. Thus the sequence (mn)n is converging to − x. Since M is closed this yields that − x is in M, which is a linear space, so x is in M too. □

In the case where M is closed we also have the two following properties.

Proposition 16.29 (Continuity of the quotient projection). Let M is a closed linear subspace of a normed space X. Then the canonical projection π : x ∈ X↦[x] ∈ X∕M is continuous.

Proof. Assume that (xn)n is a sequence in X converging to x in X. Then

∥π(xn) − π(x)∥ = inf ⁡{∥xn − x + m∥∕m ∈ M}≤∥xn − x∥,

since 0 ∈ M. Therefore the sequence (π(xn))n is converging to π(x) in X∕M. □

Proposition 16.30 (Completeness of quotients). Let M is a closed linear subspace of a Banach space X. Then X∕M is a Banach space.

In order to prove Proposition 16.30 it only remains to prove that

X∕M

is complete. We are going to use the criterion of Proposition 16.24. Actually the method we will use is quite general and we therefore give first a general statement. Then we will go back to the proof of Proposition 16.30.

Proposition 16.31 (Quotient by the kernel). Let X be a Banach space and Y be a normed vector space. Let T be a linear continuous surjective mapping from X to Y . Assume there exists some constant C > 0 such that for any y in Y there exists x in X such that

T(x) = y and ∥x∥≤ C∥y∥. (16.3)

Then Y is a Banach space.

Proof. Assume that (yn)n is a sequence in Y such that ∑ ⁡ k≥0∥yk∥ < ∞. Define the sequence (wn)n by setting wn := ∑ ⁡ k=0ny k. We want to prove that the sequence (wn)n is converging in Y so that thanks to Proposition 16.24 we will get that Y is complete. Thanks to the assumption there exists a sequence (xn)n in X such that T(xn) = yn and ∥xn∥≤ C∥yn∥. As a consequence we get

∑ k≥0∥xk∥≤ C∑ k≥0∥yk∥ < ∞.

Using Proposition 16.24 for X which is assumed to be a Banach space we get that the sequence (zn)n defined by zn := ∑ ⁡ k=0nx k is convergent to some x in X. Since T is linear we have T(zn) = wn, and T is also continuous so that T(zn) is converging to T(z). This proves that the sequence (wn)n is converging in Y and therefore the proof of the proposition is done. □

Let us now go back to the proof of Proposition 16.30.

Proof. We are going to apply Proposition 16.31 with Y = X∕M and T = π. We know that π is linear, continuous, and surjective. Let us prove that the last assumption of Proposition 16.31 is satisfied with C = 2. Let y = [x] be in X∕M. If y = [x] = 0 then (16.3) holds true with x = 0. If y≠0 then ∥y∥ > 0 and since by definition, ∥y∥ = inf ⁡{∥x∥∕x ∈ y} we have that there exists x ∈ X such that ∥x∥≤ 2∥y∥. □

16.3 Compactness

Several notions of compactness are available. The following one can be formulated in a general setting.

Definition 16.32 (Compact metric spaces). We say that a topological space (X,τ) is compact if any open cover has a finite subcover, i.e. for every arbitrary collection {Ui}i∈I of open subsets of X such that X ⊂∪i∈IUi, there is a finite subset J ⊂ I such that X ⊂∪i∈JUi.

It is a good exercise to prove the following theorem in order to understand the power of the previous definition.

Theorem 16.33 (Compactness theorem for continuous maps and Heine–Cantor theorem). Every continuous image of a compact set is compact. Moreover a continuous function on a compact set is uniformly continuous.

In a metric space, compactness can be formulated in terms of sequences. Let us first recall a few facts about the notion of limit points. Let

S

be a subset of a topological space

X

. We say that a point

x ∈ X

is a limit point of

S

if every open set containing

x

also contains a point of

S

other than

x

itself. In a metric space, it is equivalent to requiring that every neighbourhood of

x

contains infinitely many points of

S

.

Let us also define what we mean by a totally bounded space.

Definition 16.34 (Totally bounded metric spaces). We say that a metric space (X,d) is totally bounded if for every 𝜀 > 0, there exists a finite cover of X by open balls of radius less than 𝜀.

Since for every

𝜀 > 0

,

∪x∈XB(x,𝜀)

is an open cover of

X

, it follows from Definitions 16.32 and 16.34 that a compact metric space is totally bounded.

Proposition 16.35 (Compactness and limit points). A metric space is compact if and only if every sequence admits a convergent subsequence.

Proof. We start by proving the necessary condition. Let (xn)n∈ℕ be a sequence in a compact metric space X. We argue by contradiction and assume that it does not admit any convergent subsequence. Then no point of X can occur infinitely many times in the sequence, otherwise a constant subsequence would converge. Moreover, the set {xn : n ∈ ℕ} has no limit point in the sense defined above: indeed, if y were a limit point of that set, we could choose inductively nk such that nk+1 > nk and xnk ∈ B(y, 1∕k), which would give a subsequence converging to y. Therefore, for every y in X, there exists r(y) > 0 such that the ball B(y,r(y)) contains only finitely many elements of the sequence. The collection of these balls is an open cover of X, from which we extract a finite subcover. This would imply that the sequence is contained in the union of finitely many balls, each of them containing only finitely many elements of the sequence, which is impossible.

Let us now prove the sufficient condition. We therefore consider a metric space X such that every sequence admits a convergent subsequence. We first prove that X is totally bounded. Proceeding by contradiction, this would yield the existence of some 𝜀 > 0 and some sequence (xn)n∈ℕ such that for any m,n ∈ ℕ with m≠n, d(xm,xn) > 𝜀. Such a sequence cannot have a convergent subsequence, which is a contradiction. Hence X is totally bounded.

Let us now prove that X is compact. We consider an open cover {Ui}i∈I of X. We define the mapping

R : x ∈ X↦R(x) := sup ⁡{r > 0 : ∃ ⁡i ∈ I with B(x,r) ⊂ Ui} > 0,

which is lower semicontinuous. Indeed, if not, there would exist a sequence (xn)n∈ℕ ⊂ X converging to x in X such that

R(x) > liminf ⁡n→∞R(xn),

and we could choose ρ and ρ′ such that R(x) > ρ′ > ρ > liminf ⁡ nR(xn). Let i ∈ I be such that B(x,ρ′) ⊂ U i. Since the sequence (xn)n∈ℕ converges to x, for n large enough one has B(xn,ρ) ⊂ B(x,ρ′) ⊂ U i, which contradicts the fact that ρ > liminf ⁡nR(xn).

Let us now consider 𝜀 := inf ⁡ x∈XR(x) and (xn)n∈ℕ a minimizing sequence for R, that is such that

lim ⁡ n→∞R(xn) = 𝜀.

By assumption, the sequence (xn)n∈ℕ admits a subsequence (xnk)k∈ℕ converging to some x in X. Since R is lower semicontinuous, we have

0 < R(x) ≤liminf ⁡k→∞R(xnk) = 𝜀.

Hence 𝜀 > 0. We already know that X is totally bounded. Thus there exist x1,…,xn such that

X ⊂⋃ i=1nB(x i,𝜀∕2).

By definition of 𝜀, for every i = 1,…,n one has 𝜀 ≤ R(xi). Therefore, for each i, we can choose ri and ji ∈ I such that

𝜀 2 < ri < R(xi)andB(xi,ri) ⊂ Uji.

In particular,

B(xi,𝜀∕2) ⊂ Uji

for every i = 1,…,n, and finally

X ⊂⋃ i=1nU ji,

which gives a finite subcover of X. □

Next proposition gives another criterion of compactness for metric spaces.

Proposition 16.36 (Compactness, completeness and total boundedness). A metric space is compact if and only if it is complete and totally bounded.

Proof. According to Proposition 16.35, in a compact metric space every sequence admits a convergent subsequence. In particular, every Cauchy sequence has a convergent subsequence, hence converges to the same limit. We deduce that a compact metric space is complete. Moreover, we have already seen that a compact metric space is totally bounded. Therefore, it only remains to prove the converse statement.

Let (xn)n∈ℕ be a sequence in a complete and totally bounded metric space X. We are going to prove that (xn)n∈ℕ admits a convergent subsequence by Cantor’s diagonal argument. Since X is totally bounded, there exists a ball B1 of radius 1 which contains infinitely many elements of the sequence. Extract from them a subsequence that we denote by (xn1) n. By iteration we obtain that for any k ≥ 2, there exists a ball Bk of radius 1∕k which contains infinitely many elements of the subsequence (xnk−1) n; extracting again, we obtain a subsequence (xnk) n of (xnk−1) n contained in Bk. Then the diagonal sequence (xnn) n has the Cauchy property, because for any k ≥ 1 and any m,n ≥ k, the points xmm and xnn both belong to Bk, hence their distance is at most 2∕k. Since X is complete, the sequence (xnn) n converges. Thus every sequence in X admits a convergent subsequence, and Proposition 16.35 shows that X is compact. □

16.4 Separability

Definition 16.37 (Separable metric spaces). We say that a topological space (X,τ) is separable if it contains a countable dense subset, i.e., there exists a sequence (xn)n∈ℕ of elements of X such that every nonempty open subset of the space contains at least one element of the sequence.

Any topological space which is itself finite or countable is separable. An important example of uncountable separable space is the real line (with its usual topology), in which the rational numbers form a countable dense subset.

Proposition 16.38 (Compact metric spaces are separable). Every compact metric space is separable.

Proof. Let (X,d) be a compact metric space. For any k ∈ ℕ∗, the family {B(x, 1∕k) : x ∈ X} is an open cover of X. By compactness, there exist x1k,…,x nkk in X such that

X = ⋃ j=1nk B(xjk, 1∕k).

Then the collection

⋃ k∈ℕ∗⋃ j=1nk {xjk}

is a countable dense subset of X. □

Proposition 16.39 (Separability of C(K)). Let (K,d) be a compact metric space. Then the space C(K), endowed with the uniform norm, is separable.

Proof. By Proposition 16.38, there exists a countable dense subset

D = {aj : j ∈ ℕ∗}⊂ K.

For every m,r in ℕ∗, every choice of indices j1,…,jr in ℕ∗, and every choice of rational numbers q1,…,qr in ℚ, define the function

g(x) := max ⁡ 1≤i≤r (qi − md(x,aji) ),x ∈ K.

Each such function is continuous, as a finite maximum of continuous functions. Let F be the collection of all functions obtained in this way. Since each function in F is determined by finitely many integers and rational numbers, the set F is countable.

We claim that F is dense in C(K) for the uniform norm. Let f ∈C(K) and let 𝜀 > 0. Since K is compact, the function f is bounded and uniformly continuous. Set

M := ∥f∥∞.

Choose η > 0 such that

d(x,y) < η⟹|f(x) − f(y)| < 𝜀 3.

Next choose m in ℕ∗ so large that

mη > 2M + 𝜀 3.

Since D is dense in K and K is compact, we can find finitely many points aj1,…,ajr in D such that

K ⊂⋃ i=1rB (a ji, 𝜀 3m ).

For each i = 1,…,r, choose a rational number qi such that

|qi − f(aji)| < 𝜀 3.

Define

g(x) := max ⁡ 1≤i≤r (qi − md(x,aji) ),x ∈ K.

Then g belongs to F.

Fix x ∈ K. Choose i0 in {1,…,r} such that d(x,aji 0) < 𝜀∕(3m). Then

g(x) ≥ qi0 − md(x,aji 0) > f(aji 0) −𝜀 3 −𝜀 3 > f(x) − 𝜀.

On the other hand, for every i = 1,…,r, if d(x,aji) < η, then

qi − md(x,aji) ≤ qi ≤ f(aji) + 𝜀 3 < f(x) + 2𝜀 3 ,

whereas if d(x,aji) ≥ η, then

qi − md(x,aji) ≤ M + 𝜀 3 − mη < −M ≤ f(x) < f(x) + 2𝜀 3 ,

because f(x) ≥−M. Hence

g(x) ≤ f(x) + 2𝜀 3 .

Since this holds for every x in K, we conclude that

∥f − g∥∞ ≤ 𝜀.

Thus F is dense in C(K), which proves that C(K) is separable. □

Let us finish with the following useful criterion for a metric space to be not separable.

Proposition 16.40 (Nonseparability of ℓ∞(ℕ)). If a metric space (X,d) contains a uncountable subset Y such that

δ := inf ⁡{d(y,y′) : y,y′ ∈ Y,y≠y′} > 0,

then X is not separable.

Proof. We argue by contradiction. Let us assume that (X,d) is separable and therefore contains a countable dense subset (xn)n∈ℕ. We can then define a map by associating to any y ∈ Y the smallest n ∈ ℕ such that d(y,xn) < δ∕3. This map turns out to be injective because if d(y,xn) < δ∕3 and d(y′,x n) < δ∕3, then d(y,y′) < 2δ∕3 which is possible (when y and y′ ∈ Y ) only if y = y′. We deduce that Y is countable which is absurd. □

For the rest of this section, Ω denotes an open subset of ℝN. The following lemma is the elementary Urysohn-type separation result that will be used below.

Lemma 16.41 (Urysohn lemma, compact-support form). Let K be a compact subset of Ω and let V be an open subset of Ω such that K ⊂ V . Then there exists a function f ∈Cc(V ; [0, 1]) such that f = 1 on K.

Proof. If K = ∅, the function f = 0 is suitable. We therefore assume that K is nonempty. For every x in K, since V is open and contains x, there exists rx > 0 such that

B(x, 2rx)¯ ⊂ V.

The family (B(x,rx))x∈K is an open covering of the compact set K, so we can extract a finite subcover

K ⊂⋃ j=1mB(x j,rxj).

We set

δ := min ⁡ 1≤j≤mrxj > 0.

Then

{y ∈Ω : dist(y,K) ≤ δ}⊂ V.

We define

W := {x ∈Ω : dist(x,K) < δ∕3}.

Since K is compact, the set W is open and bounded, and

K ⊂ W ⊂W¯ ⊂{y ∈Ω : dist(y,K) ≤ δ∕3}⊂ V.

Now set

f(x) := dist(x,Ω ∖ W) dist(x,Ω ∖ W) + dist(x,K).

The denominator is always positive, so f is continuous on Ω. Moreover 0 ≤ f ≤ 1, the equality f = 1 holds on K, and f = 0 on Ω ∖ W. Therefore

supp(f) ⊂W¯ ⊂ V,

and W¯ is compact. Hence f belongs to Cc(V ; [0, 1]). □

A consequence of the previous lemma is the existence of a partition of unity in a fairly general context.

Lemma 16.42 (Finite partition-of-unity lemma). Let V 1,…,V n be open subsets of Ω and let K be a compact set such that K ⊂⋃ ⁡ i=1nV i. Then, for each i = 1,…,n, there exist functions fi ∈Cc(V i; [0, 1]) such that ∑ ⁡ i=1nf i = 1 on K.

Proof. For each x ∈ K, there exists an open ball Bx centered at x and such that Bx¯ ⊂ V i for some i (depending on x). Hence K ⊂⋃ ⁡ x∈KBx, and since K is compact, one can extract a finite covering K ⊂⋃ ⁡ j=1pB xj. Define Ki as the union of those closed balls Bxj¯ which are contained in V i. Then Ki is a compact subset of V i and by Lemma 16.41, there exists a function gi ∈Cc(V i; [0, 1]) such that gi = 1 on Ki. Set

G := ∑ j=1ng jandW := {x ∈Ω : G(x) > 0}.

Then W is an open subset of Ω and K ⊂ W. By Lemma 16.41, there exists a function h ∈Cc(W; [0, 1]) such that h = 1 on K. For each i = 1,…,n, define

fi(x) := { h(x)gi(x) G(x)  if  x ∈ W, 0  if  x ∈Ω ∖ W.

Since supp(h) ⊂ W, each fi is continuous on Ω. Moreover, 0 ≤ fi ≤ 1 and

supp(fi) ⊂ supp(gi) ⊂ V i,

so fi ∈Cc(V i; [0, 1]). Finally, on K we have h = 1 and G > 0, hence

∑ i=1nf i = h∑ i=1ng i G = 1.

Therefore the functions fi fulfill the conclusion of the lemma. □

Another useful consequence of Lemma 16.41 is the following characterization of the functional space C0(Ω), defined for any open subset Ω ⊂ ℝN as the closure of the space Cc(Ω) for the uniform topology.

Proposition 16.43 (The space C0(X)). Let f ∈C(Ω). Then f belongs to C0(Ω) if and only if for any 𝜀 > 0, there exists a compact set K𝜀 ⊂Ω such that |f| < 𝜀 on Ω ∖ K𝜀.

Proof. First, consider f ∈C0(Ω). Then there exists a sequence (fn) ⊂Cc(Ω) such that fn → f uniformly in Ω as n → +∞. Let 𝜀 > 0 and choose n𝜀 ∈ ℕ such that ∥fn𝜀 − f∥∞ < 𝜀∕2. Define

K := {x ∈Ω : |fn𝜀(x)|≥ 𝜀∕2}.

Then K is a compact subset of Ω and for all x ∈Ω ∖ K,

|f(x)|≤|f(x) − fn𝜀(x)| + |fn𝜀(x)| < 𝜀.

Conversely, let 𝜀 > 0 and let K ⊂Ω be a compact set such that |f| < 𝜀 on Ω ∖ K. By Lemma 16.41 one can find g ∈Cc(Ω; [0, 1]) such that g = 1 on K. Set h := fg. Since f is continuous and g has compact support, we have h ∈Cc(Ω). Moreover, h = f on K and therefore

∥f − h∥∞ = sup ⁡ x∈Ω∖K|f(x)(1 − g(x))|≤ sup ⁡ x∈Ω∖K|f(x)| < 𝜀.

Thus f ∈C0(Ω). □

Proposition 16.44 (Separability of C0(X)). The space C0(Ω), endowed with the uniform norm, is separable.

Proof. For each n ∈ ℕ∗, let

Kn := {x ∈Ω : |x|≤ n and dist(x, ℝN ∖Ω) ≥ 1 n }.

Then Kn is a compact subset of Ω for every n, and ⋃ ⁡ n≥1Kn = Ω. We also introduce the open sets

V n := {x ∈Ω : |x| < n and dist(x, ℝN ∖Ω) > 1 n }.

For each n, define

Y n := {f ∈C0(Ω) : supp(f) ⊂ Kn}.

The restriction map f↦f|Kn is an isometric embedding of Y n into C(Kn). Since C(Kn) is separable by Proposition 16.39, the metric space Y n is also separable.

We now prove that ⋃ ⁡ n≥1Y n is dense in C0(Ω). Let f ∈C0(Ω) and let 𝜀 > 0. By Proposition 16.43, there exists a compact set K ⊂Ω such that |f| < 𝜀∕2 on Ω ∖ K. Since K is compact and contained in Ω, for n large enough we have K ⊂ V n. By Lemma 16.41, there exists g ∈Cc(V n; [0, 1]) such that g = 1 on K. Then supp(g) ⊂ Kn, so the function h := fg belongs to Y n. Moreover, h = f on K, and for x ∈Ω ∖ K we have

|f(x) − h(x)| = |f(x)|(1 − g(x)) ≤|f(x)| < 𝜀 2.

Hence ∥f − h∥∞ < 𝜀∕2 < 𝜀, which proves the density of ⋃ ⁡ n≥1Y n.

Since C0(Ω) is the closure of a countable union of separable subsets of a metric space, it is separable. □

16.5 Space of continuous linear maps

This section is devoted to Lc(X,Y ), the space of bounded linear operators from a normed linear space X to a normed linear space Y . Let us recall that a linear operator T is bounded if one of the following assertions is satisfied:

1.
T is bounded on every ball,
2.
T is bounded on some ball,
3.
T is continuous at every point,
4.
T is continuous at some point,
5.
T is uniformly continuous,
6.
T is Lipschitz.

Theorem 16.45 (Banach space of continuous linear maps). If X and Y are some normed linear spaces, then Lc(X,Y ) is a normed linear space with the norm

∥T∥Lc(X,Y ) := sup ⁡ x≠x′∈X∥Tx − Tx′∥ Y ∥x − x′∥X = sup ⁡ x∈X∖0∥Tx∥Y ∥x∥X , = sup ⁡ ∥x∥X≤1∥Tx∥Y , = sup ⁡ ∥x∥X=1∥Tx∥Y .

If moreover Y is a Banach space then Lc(X,Y ) is a Banach space.

Proof. It is easy to check that Lc(X,Y ) is a normed linear space, so we only have to prove completeness. When no confusion is possible, we simply denote by ∥⋅∥ the operator norm on Lc(X,Y ).

Let (Tn) be a Cauchy sequence in Lc(X,Y ). For every x in X, the sequence (Tnx) is Cauchy in the Banach space Y , hence converges to some element that we denote by Tx. The map T : X → Y is clearly linear. Since (∥Tn∥)n is a Cauchy sequence in ℝ, it is bounded: there exists K ≥ 0 such that ∥Tn∥≤ K for every n. Passing to the limit in

∥Tnx∥Y ≤ K∥x∥X

gives

∥Tx∥Y ≤ K∥x∥X

for every x in X. Thus T belongs to Lc(X,Y ).

It remains to prove that Tn → T in operator norm as n → +∞. For every n ≥ 1, we have

∥Tn − T∥ = sup ⁡ ∥x∥X≤1∥Tnx − Tx∥Y ≤limsup ⁡m→∞ sup ⁡ ∥x∥X≤1∥Tnx − Tmx∥Y ≤limsup ⁡m→∞∥Tn − Tm∥Lc(X,Y ).

Since (Tn) is Cauchy in Lc(X,Y ), the right-hand side tends to 0 as n →∞. Therefore ∥Tn − T∥→ 0 as n → +∞. □

If T ∈Lc(X,Y ) and U ∈Lc(Y,Z), then UT = U ∘ T ∈Lc(X,Z) and

∥UT∥Lc(X,Z) ≤∥U∥Lc(Y,Z)∥T∥Lc(X,Y ).

In particular, Lc(X) := Lc(X,X) is an algebra, i.e., it has an additional “multiplication” operation which makes it a non-commutative algebra, and this operation is continuous.

The dual space of X is X′ := L c(X, ℝ) (or Lc(X, ℂ) for complex vector spaces). According to the previous proposition it is a Banach space (whether X is or not).

Theorem 16.46 (Uniform Boundedness Principle, or Banach–Steinhaus theorem). Let X be a Banach space and let Y be a normed vector space. Let (Ti)i∈I be a family in Lc(X,Y ). Assume that for every x in X,

sup ⁡ i∈I∥Tix∥Y < +∞.

Then

sup ⁡ i∈I∥Ti∥Lc(X,Y ) < +∞.

Proof. For every m ≥ 1, define

Em := {x ∈ X : sup ⁡ i∈I∥Tix∥Y ≤ m}.

Each Em is closed. Indeed, if (xn)n is a sequence in Em which converges to x in X, then for every i in I,

∥Tix∥Y = lim ⁡ n→∞∥Tixn∥Y ≤ m,

and therefore x belongs to Em. The pointwise boundedness assumption gives

X = ⋃ m≥1Em.

By the Baire category theorem, Theorem 16.17, there exist m0 ≥ 1, x0 in X, and r > 0 such that

B(x0,r) ⊂ Em0.

Let h in X with ∥h∥X < r. Then x0 + h and x0 belong to Em0, and for every i in I,

∥Tih∥Y ≤∥Ti(x0 + h)∥Y + ∥Tix0∥Y ≤ 2m0.

Let x in X with ∥x∥X ≤ 1. Applying the previous estimate to h = (r∕2)x gives, for every i in I,

∥Tix∥Y ≤4m0 r .

Hence ∥Ti∥Lc(X,Y ) ≤ 4m0∕r for every i in I. □

Definition 16.47 (Weak-* topology). Given some normed linear spaces X and Y , and a sequence (un)n in Lc(X,Y ), we say that

1.
(un)n converges strongly to u in Lc(X,Y ) if ∥un − u∥Lc(X,Y ) → 0 as n →∞,
2.
(un)n converges pointwise to u in Lc(X,Y ) if for any x ∈ X, (un(x))n converges to u(x) in Y .

16.6 Geometry of Banach spaces and identification of their dual

We will slightly restrict our attention to spaces which enjoy two properties described in the definitions below.

Definition 16.48 (Uniform convergence on compact sets). We say that a normed vector space X is uniformly convex if for every 𝜀 > 0 there exists δ > 0 such that for any x, y ∈ X with ∥x∥X ≤ 1, ∥y∥X ≤ 1 and ∥x+y 2 ∥ X > 1 − δ, then ∥x−y 2 ∥ X < 𝜀.

In particular the unit sphere of a uniformly convex normed vector space contains no segments. As a first application, let us give the following proposition.

Proposition 16.49 (Metrization of weak-* convergence on bounded sets). Let X be a uniformly convex Banach space, and let f in X′∖{0}. Then there exists a unique u in X such that ∥u∥X = 1 and f(u) = ∥f∥X′.

Proof. Let (un)n be a maximizing sequence. We assume without loss of generality that f(un) ≥ 0. Let 𝜀 > 0 and δ be given as in Definition 16.48. Since the sequence (un)n maximizes |f(v)| over {v ∈ X : ∥v∥X = 1}, there exists N ∈ ℕ such that for any n ≥ N, f(un) > (1 − δ)∥f∥X′. Therefore for any n,m ≥ N, we have

1 2(f(un) + f(um)) > (1 − δ)∥f∥X′.

But since

1 2(f(un) + f(um)) = f (1 2(un + um)) ≤∥f∥X′ ∥1 2(un + um)∥ ,

it follows, by combining both previous inequalities and dividing by ∥f∥X′, that

∥1 2(un + um)∥ > 1 − δ. (16.4)

Moreover, since ∥un∥X = 1, then f(un) ∥f∥X′ ≤ 1, and using the uniform convexity of X, we can infer from (16.4) that ∥un − um∥X < 2𝜀, that is the sequence (un)n satisfies the Cauchy property. Since X is complete, there exists u ∈ X such that un → u as n → +∞. Using the continuity of the norm and of the function f we get that f(u) = ∥f∥X′.

Uniqueness is proved by proceeding in the same way. □

Definition 16.50 (Smooth normed spaces). We say that a normed vector space X is smooth if for any linearly independent elements x and y, the function t ∈ ℝ↦∥x + ty∥X is differentiable for all t ∈ ℝ.

Let us stress that this is equivalent to the fact that for any

u ∈ X ∖{0}

, then the limit

lim ⁡ 𝜀→0∥u + 𝜀v∥X −∥u∥X 𝜀

exists for any v ∈ X.

Proposition 16.51 (Gateaux differentiability of the norm). Let X be a smooth normed vector space over ℝ. Then the norm is Gateaux-differentiable outside 0, in the following sense: for any u in X ∖{0}, there exists L in X′, that we denote D∥⋅∥X(u), such that for any v in X,

lim ⁡ 𝜀→0∥u + 𝜀v∥X −∥u∥X 𝜀 = L(v).

Moreover

∥D∥⋅∥X(u)∥X′∥u∥X = D∥⋅∥X(u)(u) = ∥u∥X. (16.5)

Proof. Since X is a smooth normed vector space, for any u ∈ X ∖{0}, for any v ∈ X,

D∥⋅∥X(u)(v) := lim ⁡ 𝜀→0∥u + 𝜀v∥X −∥u∥X 𝜀

exists. We first prove that D∥⋅∥X(u) is linear. For any λ ∈ ℝ ∖{0} and any u, v ∈ X,

∥u + 𝜀λv∥X −∥u∥X 𝜀 = λ∥u + 𝜀λv∥X −∥u∥X λ𝜀

so that

D∥⋅∥X(u)(λv) = λD∥⋅∥X(u)(v).

Now, using the triangle inequality, we have for any v1,v2 in X, that

∥u + 𝜀(v1 + v2)∥X −∥u∥X 𝜀 ≤ ∥u + 2𝜀v1∥X −∥u∥X 2𝜀 + ∥u + 2𝜀v2∥X −∥u∥X 2𝜀

so that, passing to the limit 𝜀 → 0,

D∥⋅∥X(u)(v1 + v2) ≤ D∥⋅∥X(u)(v1) + D∥⋅∥X(u)(v2). (16.6)

Applying now (16.6) to − v1 and − v2 implies that the previous inequality is actually an equality. Hence the map D∥⋅∥X(u) is linear from X to ℝ.

We next prove that it is continuous. Indeed using the triangle inequality we have that for any v ∈ X,

|∥u + 𝜀v∥X −∥u∥X 𝜀 | ≤∥v∥X,

so that

|D∥⋅∥X(u)(v)|≤∥v∥X.

Therefore D∥⋅∥X(u) is a continuous linear map from X to ℝ with norm ∥D∥⋅∥X(u)∥X′ ≤ 1. Moreover since D∥⋅∥X(u)(u) = ∥u∥, then ∥D∥⋅∥X(u)∥X′ = 1 which yields (16.5). □

Theorem 16.52 (Factorization theorem for smooth uniformly convex Banach spaces). Let X be a smooth and uniformly convex Banach space, and let f in X′∖{0}. Then there exists a unique u ∈ X such that ∥u∥X = 1 and f = ∥f∥X′D∥⋅∥X(u).

Proof. Let u be given by Proposition 16.49, and let v ∈ X. The function

g : 𝜀↦f(u + 𝜀v) −∥f∥X′∥u + 𝜀v∥X

is nonpositive, vanishes for 𝜀 = 0, and has a derivative at 𝜀 = 0, since f is linear continuous and X is smooth. Therefore g′(0) = 0, i.e.

f(v) −∥f∥X′D∥⋅∥X(u)(v) = 0.

Let us now prove the uniqueness part of Theorem 16.52. If u ∈ X is such that ∥u∥X = 1 and f = ∥f∥X′D∥⋅∥X(u), then in particular f(u) = ∥f∥X′D∥⋅∥X(u)(u) = ∥f∥X′, according to (16.5). It then suffices to recall the uniqueness part of Proposition 16.49. □

An important corollary is the following constructive version of Hahn-Banach theorem which allows the extension of continuous linear forms defined on a subspace of a smooth uniformly convex Banach space to the whole space without increasing the norm.

Corollary 16.53 (Constructive Hahn–Banach theorem in the smooth uniformly convex case). Let X be a smooth uniformly convex Banach space, Y be a subspace of X and f ∈ Y ′. There exists a unique extension f~ of f to X such that ∥f~∥X′ = ∥f∥Y ′.

Proof. Let f in Y ′. Only the case f≠0 deserves a proof. According to Theorem 16.19 there exists a unique extension f¯ of f to the closure Y ¯ of Y in X and ∥f¯∥Y ¯′ = ∥f∥Y ′. Since Y ¯ is a closed subspace of the Banach space X, the space Y ¯ is a smooth uniformly convex Banach space. Thanks to Theorem 16.52 there exists a unique u ∈Y ¯ such that ∥u∥Y ¯ = 1 and f¯ = ∥f¯∥Y ¯′D∥⋅∥Y ¯(u). Let us now consider

f~ := ∥f∥Y ′D∥⋅∥X(u),

which is in X′. Then f~ is an extension of f¯ and ∥f~∥X′ = ∥f∥Y ′, according to (16.5).

It remains to prove the uniqueness part. Let fˇ be an extension of f to X such that ∥fˇ∥X′ = ∥f∥Y ′. Then evaluating fˇ at the vector u above yields

fˇ(u) = f¯(u) = ∥f∥Y ′ = ∥fˇ∥X′.

According to (the proof of) Theorem 16.52, fˇ = ∥fˇ∥X′D∥⋅∥X(u) = f~. □

The previous result can actually be extended to a more general setting with a non-constructive proof using Zorn’s lemma.

Theorem 16.54 (Hahn–Banach theorem, norm-preserving form). If f is a bounded linear functional on a subspace of a normed linear space, then f extends to the whole space with preservation of norm.

Note that, unlike the previous result, Theorem 16.54 does not contain any uniqueness part. It is named for Hans Hahn and Stefan Banach who proved this theorem independently in the late

1920

s, though it was proved earlier (in

1912

) by Eduard Helly. A key consequence is that the dual space of a nontrivial normed linear space is itself nontrivial. (Note: the norm is important for this. There exist topological vector spaces, e.g.,

Lp

for

0 < p < 1

, with no non-zero continuous linear functionals.) Note that there are virtually no hypotheses beyond linearity and existence of a norm. In fact for some purposes a weaker version is useful. For

X

a vector space, we say that

p : X → ℝ

is sublinear if

p(x + y) ≤ p(x) + p(y)

and

p(αx) = αp(x)

for

x,y ∈ X

,

α ≥ 0

.

Theorem 16.55 (Analytic Hahn–Banach theorem). Let X be a vector space, p : X → ℝ a sublinear functional, S a subspace of X, and f : S → ℝ a linear function satisfying f(x) ≤ p(x) for all x ∈ S, then f can be extended to X so that the same inequality holds for all x ∈ X.

Proof. It suffices to extend f to the space spanned by S and one element x0 ∈ X ∖ S, preserving the inequality, since if we can do that we can complete the proof with Zorn’s lemma.

We need to define f(x0) such that f(tx0 + s) ≤ p(tx0 + s) for all t ∈ ℝ, s ∈ S. The case t = 0 is known and it is easy to use homogeneity to restrict to t = ±1. Thus we need to find a value f(x0) ∈ ℝ such that

f(s) − p(−x0 + s) ≤ f(x0) ≤ p(x0 + s) − f(s)   for all s ∈ S.

Now it is easy to check that for any s1, s2 ∈ S, f(s1) − p(−x0 + s1) ≤ p(x0 + s2) − f(s2), and so such an x0 exists. □

16.7 Pointwise convergence under a uniform bound and a sequential Banach–Alaoglu theorem

We start this section with the following result.

Proposition 16.56 (Extension of pointwise convergence from a dense set). Let X be a normed vector space and Y be a Banach space. Consider a dense subset A of X and (un)n a sequence in Lc(X,Y ) such that

1.
sup ⁡ n∥un∥Lc(X,Y ) < ∞,
2.
for any x in A, (un(x))n converges in Y .

Then there exists a unique u in Lc(X,Y ) such that

un(x) → u(x)as n → +∞

in Y for every x ∈ X. Moreover

∥u∥Lc(X,Y ) ≤liminf ⁡n→∞∥un∥Lc(X,Y ). (16.7)

Proof. We can assume without loss of generality that sup ⁡ n∥un∥ > 0, otherwise the proof is straightforward. Let x in X and 𝜀 > 0. Since A is a dense subset of X, there exists x′ ∈ A such that

∥x − x′∥ X ≤ δ := 𝜀 3 sup ⁡ n∥un∥Lc(X,Y ).

Since (un(x′)) n converges, it has the Cauchy property and there exists n𝜀 ∈ ℕ such that

∥un(x′) − u m(x′)∥ Y ≤ 𝜀 3,

for any n,m ≥ n𝜀. For any n,m ≥ n𝜀, we have

∥un(x) − um(x)∥Y ≤∥un(x) − un(x′)∥ Y + ∥un(x′) − u m(x′)∥ Y + ∥um(x′) − u m(x)∥Y , ≤ (∥un∥Lc(X,Y ) + ∥um∥Lc(X,Y ))∥x − x′∥ X + 𝜀 3, ≤ 2δ sup ⁡ n∥un∥Lc(X,Y ) + 𝜀 3 ≤ 𝜀.

Therefore the sequence (un(x))n has the Cauchy property. Since Y is a Banach space, it converges. We denote by u(x) its limit. It is straightforward that u is linear. Moreover for any x ∈ X,

∥u(x)∥Y = lim ⁡ n→∞∥un(x)∥Y ≤liminf ⁡n→∞∥un∥Lc(X,Y )∥x∥X,

which yields (16.7). The uniqueness follows from the pointwise convergence on X. □

In the particular case where Y is ℝ or ℂ, we denote by X′ := L c(X,Y ), and we call X′ the topological dual space of X. In that case, pointwise convergence on X is exactly weak∗ convergence in X′.

Corollary 16.57 (Boundedness of weak-star convergent sequences). Let X be a Banach space. Then any weak∗ converging sequence in X′ is bounded.

Proof. If (un)n converges weak∗ in X′, then for every x in X the sequence (un(x))n converges, hence is bounded. Applying the Uniform Boundedness Principle, Theorem 16.46, to the family (un)n gives

sup ⁡ n∥un∥X′ < ∞.
□

One advantage of the weak∗ convergence is that the following partial converse is available:

Theorem 16.58 (Sequential Banach–Alaoglu theorem). Let X be a separable Banach space. Then any bounded sequence in X′ admits a weak∗ converging subsequence.

Proof. Let (un)n be a bounded sequence in X′. Let (xk)k∈ℕ be a dense sequence in X. Using Cantor’s diagonal argument, there exists a subsequence (unj)j≥1 of (un)n such that

(unj(xk))j≥1

converges for every k in ℕ. We then apply Proposition 16.56. □
