Chapter 13
Fundamental theorem of calculus and change of variables

This chapter studies the two main links between integration and differential calculus. We first recover antiderivatives from integrable functions through a differentiation theorem, then prove the converse statement using the Radon–Nikodym theorem, and finally explain how integrals transform under smooth changes of variables, first in dimension 1 and then in higher dimension. Unless explicitly stated otherwise, all measures in this chapter are Lebesgue measures: λ on ℝ in the one-dimensional parts and λd on ℝd in the multidimensional parts.

13.1 Integration and antiderivatives

The following results make the link between integration and antiderivatives.

13.1.1 The Hardy–Littlewood maximal inequality

The proof of the differentiation theorem rests on the centered Hardy–Littlewood maximal operator on ℝ. We isolate it first.

Definition 13.1 (Centered Hardy–Littlewood maximal operator). Let h: ℝ → ℝ be an integrable function. For every r > 0 and every x in ℝ, we define

(Mh)r(x) := 1 2r∫ x−rx+r|h(t)|dt.

The centered Hardy–Littlewood maximal function of h is

Mh(x) := sup ⁡ r>0(Mh)r(x).

Lemma 13.2 (Continuity of fixed-radius averages). Let h: ℝ → ℝ be an integrable function. For every fixed r > 0, the function

x↦(Mh)r(x) = 1 2r∫ x−rx+r|h(t)|dt

is continuous on ℝ.

Proof. Let x0 be in ℝ. For x in ℝ, write

(Mh)r(x) = 1 2r∫ ℝ1[x−r,x+r](t)|h(t)|dt.

As x → x0, the integrands

t↦1[x−r,x+r](t)|h(t)|

converge pointwise for every t different from x0 − r and x0 + r, hence for λ-almost every t, to

t↦1[x0−r,x0+r](t)|h(t)|.

They are dominated by the integrable function |h|. The continuity under the integral sign theorem, Theorem 9.1, gives the desired continuity. □

Lemma 13.3 (Finite Vitali covering lemma in dimension one). Let I1,…,IN be bounded open intervals of ℝ. Then there exist pairwise disjoint intervals J1,…,Jm among I1,…,IN such that

⋃ i=1NI i ⊂⋃ j=1m3J j,

where, if J = (c − r,c + r), we write 3J = (c − 3r,c + 3r).

Proof. Among the intervals I1,…,IN, we choose one of maximal length and call it J1. We then discard all the intervals which intersect J1. Among the remaining intervals, if there are any, we choose one of maximal length and call it J2, and we continue in the same way. The process stops after finitely many steps and yields pairwise disjoint intervals J1,…,Jm.

Let Ii be one of the initial intervals. If Ii is itself one of the selected intervals, there is nothing to prove. Otherwise, Ii was discarded when some Jj was selected. Hence Ii ∩ Jj≠∅ and, by construction, the length of Ii is not larger than the length of Jj. Therefore Ii ⊂ 3Jj. This proves the claim. □

Theorem 13.4 (Weak Hardy–Littlewood maximal inequality). Let h: ℝ → ℝ be an integrable function. Then, for every α > 0,

λ ({Mh > α} )≤ 3 α∫ ℝ|h(t)|dt.

Proof. Let α > 0 and set

Eα := {x ∈ ℝ: Mh(x) > α}.

Step 1: openness of the superlevel set. For every r > 0, define

Eα,r := {x ∈ ℝ: (Mh)r(x) > α}.

By Lemma 13.2, the function (Mh)r is continuous. Since ]α, +∞[ is open, the set Eα,r is open. Moreover,

Eα = ⋃ r>0Eα,r,

because the condition Mh(x) > α means, by definition of the supremum in Definition 13.1, that at least one radius r > 0 satisfies (Mh)r(x) > α. Thus Eα is open.

Step 2: estimate on compact subsets of Eα. Let K be a compact subset of Eα. For every x in K, by definition of Mh(x) we can choose rx > 0 such that, with Ix = (x − rx,x + rx),

1 |Ix|∫ Ix|h(t)|dt > α.

The family (Ix)x∈K is an open covering of the compact set K, so we can extract a finite subcover Ix1,…,IxN. By Lemma 13.3, there exist pairwise disjoint intervals J1,…,Jm among them such that

K ⊂⋃ j=1m3J j.

Therefore

λ(K) ≤∑ j=1mλ(3J j) = 3 ∑ j=1m|J j| < 3 α∑ j=1m ∫ Jj|h(t)|dt ≤ 3 α∫ ℝ|h(t)|dt,

because the intervals Jj are pairwise disjoint.

Step 3: passage from compact subsets to Eα. By Lemma 16.12, the open set Eα is the union of an increasing sequence of compact sets (Kn)n≥1. The estimate of Step 2 gives, for every n ≥ 1,

λ(Kn) ≤ 3 α∫ ℝ|h(t)|dt.

Since Kn ↑ Eα, the continuity from below of measures, Theorem 2.3, gives

λ(Eα) = lim ⁡ n→∞λ(Kn) ≤ 3 α∫ ℝ|h(t)|dt.

This proves the desired estimate. □

13.1.2 Lebesgue points and differentiation

We now use Theorem 13.4 to prove the Lebesgue differentiation theorem on the real line.

Definition 13.5 (Lebesgue points). Let f : ℝ → ℝ be a measurable function that is integrable on every compact interval. A point x in ℝ is called a Lebesgue point of f if

lim ⁡ r→0+ 1 2r∫ x−rx+r|f(t) − f(x)|dt = 0.

Theorem 13.6 (Lebesgue differentiation theorem). Let f : ℝ → ℝ be a measurable function that is integrable on every compact interval. Then λ-almost every point x in ℝ is a Lebesgue point of f.

Proof. For every x in ℝ, set

Df(x) := limsup ⁡ r→0+ 1 2r∫ x−rx+r|f(t) − f(x)|dt.

Step 1: the uniformly continuous case. Assume first that g is uniformly continuous on ℝ. Let x be in ℝ and let 𝜀 > 0. There exists ρ > 0 such that

|s − x| < ρ⟹|g(s) − g(x)| < 𝜀.

If 0 < r < ρ, then

1 2r∫ x−rx+r|g(t) − g(x)|dt ≤ 𝜀.

Thus Dg(x) = 0 for every x in ℝ. In particular, this applies to every function g in Cc(ℝ). Indeed, if supp(g) ⊂ [−R,R], then g is uniformly continuous on the compact interval [−R − 1,R + 1] by the Heine–Cantor theorem, Theorem 16.33, and g is identically zero outside [−R,R].

Step 2: the integrable case. Assume that f is integrable on ℝ. We fix α > 0 and 𝜀 > 0. At this point we use the density of Cc(ℝ) in L1(ℝ,λ). This result will be proved later in the more general form of Theorem 15.10, independently of the present differentiation theorem. Hence there exists g in Cc(ℝ) such that

∫ ℝ|f − g|dt < 𝜀.

For every x in ℝ and every r > 0, we have

1 2r∫ x−rx+r|f(t) − f(x)|dt ≤ 1 2r∫ x−rx+r|g(t) − g(x)|dt + 1 2r∫ x−rx+r|f(t) − g(t)|dt + |f(x) − g(x)|.

Taking the limit superior as r → 0+, and using Step 1, gives

Df(x) ≤ M(f − g)(x) + |f(x) − g(x)|.

Hence

{Df > 2α}⊂{M(f − g) > α}∪{|f − g| > α}.

By the weak Hardy–Littlewood maximal inequality, Theorem 13.4, and by Markov’s inequality, Lemma 8.6, applied to f − g, we obtain

λ({Df > 2α}) ≤ λ({M(f − g) > α}) + λ({|f − g| > α}) ≤ 3 α∫ ℝ|f − g|dt + 1 α∫ ℝ|f − g|dt ≤4𝜀 α .

Letting 𝜀 → 0, we conclude that

λ({Df > 2α}) = 0

for every α > 0. Since

{Df > 0} = ⋃ m=1∞ {Df > 1 m },

it follows that Df(x) = 0 for λ-almost every x in ℝ. This proves the theorem when f is integrable on ℝ.

Step 3: the locally integrable case. We now return to the general case f ∈ Lloc1(ℝ). For every integer N ≥ 1, we define

fN := f1[−N−1,N+1].

The function fN is integrable on ℝ, so almost every point of [−N,N] is a Lebesgue point of fN by Step 2. If x belongs to [−N,N] and 0 < r ≤ 1, then

[x − r,x + r] ⊂ [−N − 1,N + 1],

so

1 2r∫ x−rx+r|f N(t) − fN(x)|dt = 1 2r∫ x−rx+r|f(t) − f(x)|dt.

Hence every Lebesgue point of fN in [−N,N] is also a Lebesgue point of f. Since this holds for every N ≥ 1, we conclude that λ-almost every point of ℝ is a Lebesgue point of f. □

13.1.3 Fundamental theorem of calculus

We use the notion of absolute continuity of functions introduced in Definition 3.15. This should be distinguished from absolute continuity of measures, introduced in Definition 2.13. For increasing functions on a compact interval, Proposition 3.18 explains the link: absolute continuity of the function is equivalent to absolute continuity, with respect to the Lebesgue measure, of the associated Stieltjes measure.

Theorem 13.7 (Fundamental theorem of calculus for Lebesgue integrals, direct part). Let f : [a,b] → ℝ be a measurable function such that

∫ ab|f(t)|dt < ∞.

We define F : [a,b] → ℝ by

F(x) = ∫ axf(t)dt.

Then

1.
F is absolutely continuous on [a,b],
2.
F is differentiable λ-almost everywhere on (a,b),
3.
for λ-almost every x in (a,b), we have F′(x) = f(x).

Proof. Step 1: absolute continuity. Let 𝜀 > 0. Since |f| is integrable on [a,b], we can choose M ≥ 1 such that

∫ {|f|>M}|f(t)|dt ≤ 𝜀∕2.

We set

δ := 𝜀 2M.

Let E be a measurable subset of [a,b] such that λ(E) ≤ δ. Then

∫ E|f(t)|dt = ∫ E∩{|f|≤M}|f(t)|dt + ∫ E∩{|f|>M}|f(t)|dt ≤ Mλ(E) + ∫ {|f|>M}|f(t)|dt ≤ Mδ + 𝜀∕2 ≤ 𝜀.

Let {(αk,βk)}1≤k≤m be a finite family of pairwise disjoint intervals included in [a,b] such that

∑ k=1m(β k − αk) < δ.

Setting

E := ⋃ k=1m(α k,βk),

we obtain

∑ k=1m|F(β k) − F(αk)| = ∑ k=1m |∫ αkβk f(t)dt| ≤∑ k=1m ∫ αkβk |f(t)|dt = ∫ E|f(t)|dt ≤ 𝜀.

This is the definition of absolute continuity of F.

Step 2: identification of the derivative. Let f~ be the extension of f by 0 outside [a,b]. Then f~ is locally integrable on ℝ. Let x be a Lebesgue point of f~ in (a,b). For h≠0 small enough so that x + h belongs to [a,b], we write

F(x + h) − F(x) h − f(x) = 1 h∫ xx+h (f(t) − f(x) )dt.

Let

Ih := { [x,x + h],h > 0, [x + h, x], h < 0.

Then

|F(x + h) − F(x) h − f(x)| ≤ 1 |h|∫ Ih|f(t) − f(x)|dt ≤ 1 |h|∫ x−|h|x+|h||f(t) − f(x)|dt = 2 1 2|h|∫ x−|h|x+|h||f(t) − f(x)|dt.

The right-hand side tends to 0 as h → 0 because x is a Lebesgue point of f~ and because, for h small enough, the interval [x −|h|,x + |h|] is contained in [a,b]. Therefore F is differentiable at x and F′(x) = f(x). Since λ-almost every point is a Lebesgue point of f~ by Theorem 13.6, the conclusion follows on (a,b). □

Conversely, if F is absolutely continuous, then F is an antiderivative of an L1 function.

Theorem 13.8 (Fundamental theorem of calculus for Lebesgue integrals, converse part). If F is absolutely continuous on [a,b], then F′ exists λ-almost everywhere, F′ is Lebesgue integrable on [a,b], and for every x in [a,b] we have

F(x) = F(a) + ∫ axF′(t)dt.

The proof of the converse direction will be split into two independent lemmas. The first lemma is purely about functions of one real variable. It shows that an absolutely continuous function can be written as a difference of two increasing absolutely continuous functions. The second lemma treats the increasing case by using the Stieltjes measure constructed in Theorem 3.17, the absolute-continuity criterion of Proposition 3.18, and the Radon–Nikodym theorem.

Lemma 13.9 (Decomposition into increasing absolutely continuous functions). Let F be absolutely continuous on [a,b]. Then there exist two increasing absolutely continuous functions F1 and F2 on [a,b] such that

F = F1 − F2.

Proof. Step 1. The variation function. For a ≤ s < t ≤ b, define the variation of F on [s,t] by

V ar[s,t](F) := sup ⁡ {∑ i=1m|F(x i) − F(xi−1)| : s = x0 < x1 < ⋯ < xm = t}.

We also set V F (a) := 0 and

V F (x) := V ar[a,x](F)

for x in ]a,b].

We first prove that V F (b) is finite. Apply the absolute continuity of F with 𝜀 = 1 and choose δ > 0 accordingly. Choose a partition

a = x0 < x1 < ⋯ < xN = b

such that xj − xj−1 < δ for every j. If a = t0 < ⋯ < tm = b is any partition of [a,b], we refine it by adding the points x0,…,xN. On each interval [xj−1,xj], the pieces of the refined partition form a finite family of pairwise disjoint intervals whose total length is smaller than δ. The sum of the corresponding oscillations of F is therefore at most 1. Adding the contributions of the N intervals gives

∑ i=1m|F(t i) − F(ti−1)|≤ N.

Taking the supremum over all partitions proves that V F (b) < +∞.

Step 2. Local variation and monotonicity. For a ≤ s < t ≤ b, concatenating partitions of [a,s] and [s,t] gives

V F (t) − V F (s) = V ar[s,t](F). (13.1)

In particular, V F is increasing and

V F (t) − V F (s) ≥|F(t) − F(s)|. (13.2)

Step 3. Absolute continuity of the variation function. It remains to prove that V F is absolutely continuous. Let 𝜀 > 0. By the absolute continuity of F, there exists δ > 0 such that for every finite family of pairwise disjoint intervals (αj,βj) in [a,b] satisfying

∑ j=1m(β j − αj) < δ,

we have

∑ j=1m|F(β j) − F(αj)| < 𝜀.

Consider such a family (αj,βj)1≤j≤m. Let η > 0. For each j, by (13.1), we can choose a partition

αj = tj,0 < ⋯ < tj,ℓj = βj

such that

V F (βj) − V F (αj) ≤∑ i=1ℓj |F(tj,i) − F(tj,i−1)| + η m.

The intervals (tj,i−1,tj,i) are pairwise disjoint when j and i vary, and their total length is smaller than δ. Thus

∑ j=1m (V F (βj) − V F (αj) ) ≤∑ j=1m ∑ i=1ℓj |F(tj,i) − F(tj,i−1)| + η < 𝜀 + η.

Letting η → 0+ proves the absolute continuity of V F .

Step 4. Decomposition into two increasing functions. Define

F1 := V F + F 2 ,F2 := V F − F 2 .

Since V F and F are absolutely continuous, Proposition 3.16 shows that F1 and F2 are absolutely continuous. For a ≤ s < t ≤ b, inequality (13.2) gives

F1(t) − F1(s) = V F (t) − V F (s) + F(t) − F(s) 2 ≥ 0, F2(t) − F2(s) = V F (t) − V F (s) − F(t) + F(s) 2 ≥ 0.

Thus F1 and F2 are increasing, and F = F1 − F2. □

Lemma 13.10 (Increasing absolutely continuous functions). Let H be increasing and absolutely continuous on [a,b]. Then H′ exists λ-almost everywhere on (a,b), H′ belongs to L1([a,b]), and

H(x) = H(a) + ∫ axH′(t)dt

for every x ∈ [a,b].

Proof. By Proposition 3.16, absolute continuity implies continuity, hence H is right-continuous. By Theorem 3.17, the increasing function H has an associated Stieltjes measure μH on [a,b]. Since H is absolutely continuous, Proposition 3.18 gives

μH ≪ λ1|[a,b].

By the finite Radon–Nikodym theorem, Corollary 12.2, there exists h in L1([a,b]) such that

μH(E) = ∫ Eh(t)dt

for every Borel set E ⊂ [a,b]. In particular, for every x in [a,b],

H(x) − H(a) = μH((a,x]) = ∫ axh(t)dt.

By the direct part of the fundamental theorem of calculus, Theorem 13.7, the function

x↦∫ axh(t)dt

is differentiable λ-almost everywhere on (a,b), with derivative h. Therefore H′ exists λ-almost everywhere, H′ = h almost everywhere, H′ belongs to L1([a,b]), and the desired identity follows. □

Proof of Theorem 13.8. Let F be absolutely continuous on [a,b]. By Lemma 13.9, there exist two increasing absolutely continuous functions F1 and F2 on [a,b] such that

F = F1 − F2.

By Lemma 13.10, F1′ and F2′ exist almost everywhere, belong to L1([a,b]), and satisfy

Fi(x) = Fi(a) + ∫ axF i′(t)dt,i = 1, 2.

Subtracting the two identities gives

F(x) = F(a) + ∫ ax (F 1′(t) − F 2′(t) )dt

for every x ∈ [a,b]. The direct part of the fundamental theorem of calculus, Theorem 13.7, applied to the integrable function F1′− F 2′ shows that the derivative of the right-hand side is F1′− F 2′ almost everywhere. Since the right-hand side is equal to F, we obtain

F′ = F 1′− F 2′

almost everywhere. Thus F′ belongs to L1([a,b]) and

F(x) = F(a) + ∫ axF′(t)dt

for every x ∈ [a,b]. □

Remark. The Cantor function is continuous and increasing, is differentiable with derivative 0 at λ-almost every point, but is not constant. Equivalently, its associated Stieltjes measure is the Cantor measure, which is singular with respect to the Lebesgue measure. This example shows that differentiability almost everywhere, even with an integrable derivative, is not enough to recover a function by integrating its derivative. The absolute continuity assumption in Theorem 13.8 is therefore essential.

13.1.4 The space AC([a,b])

The preceding theorem also identifies the natural structure of AC([a,b]). The derivative of an absolutely continuous function is understood below as an element of L1([a,b]), hence up to equality almost everywhere.

Proposition 13.11 (Banach structure of absolutely continuous functions). Let a < b be real numbers. The set AC([a,b]) is a real vector space. Moreover,

∥F∥AC := |F(a)| + ∫ ab|F′(t)|dt

defines a norm on AC([a,b]), and AC([a,b]) is a Banach space for this norm.

Proof. By Proposition 3.16, AC([a,b]) is a real vector space. Consider the map

Φ: AC([a,b]) → ℝ × L1([a,b]),Φ(F) := (F(a),F′).

The converse part of the fundamental theorem of calculus, Theorem 13.8, shows that Φ is well defined. The linearity of Φ follows from the linearity of differentiation almost everywhere and from the vector-space property of AC([a,b]). It is injective: if F(a) = 0 and F′ = 0 almost everywhere, then Theorem 13.8 gives

F(x) = F(a) + ∫ axF′(t)dt = 0

for every x in [a,b].

It is also surjective. Let (c,g) be in ℝ × L1([a,b]), choose a representative of g, and define

F(x) := c + ∫ axg(t)dt.

By the direct part of the fundamental theorem of calculus, Theorem 13.7, the function F is absolutely continuous and F′ = g almost everywhere. Hence Φ(F) = (c,g).

The norm ∥⋅∥AC is exactly the pullback by Φ of the product norm

∥(c,g)∥ := |c| + ∥g∥L1([a,b])

on ℝ × L1([a,b]). Therefore ∥⋅∥AC is a norm. Since L1([a,b]) is complete by Theorem 8.19, the product space ℝ × L1([a,b]) is complete. The isometry Φ then shows that AC([a,b]) is complete for ∥⋅∥AC. □

Remark. The norm

∥F∥∞ + ∥F′∥ L1([a,b])

is equivalent to ∥F∥AC. The derivative term is essential: the uniform norm alone does not capture the absolutely continuous structure.

13.2 Change of variables

We now turn to change of variables. We first recall the one-dimensional statement for the Riemann integral, then derive the corresponding Lebesgue statement in dimension 1, and finally prove the multidimensional formula. The one-dimensional proof uses a transport measure; the multidimensional proof first treats elementary diffeomorphisms and then factors a general local diffeomorphism into elementary ones.

13.2.1 One-dimensional change of variables

The first result in this subsection is the classical Riemann change-of-variables theorem. We recall it to fix the orientation convention and to connect the Lebesgue formula below with the familiar one-dimensional statement.

Theorem 13.12 (Riemann one-dimensional change-of-variables theorem). Let a < b be real numbers and let

φ: [a,b] → φ([a,b])

be a function of class C1 whose derivative does not vanish on [a,b]. Let f be a function defined on φ([a,b]) and having only a finite number of discontinuities on this interval. Then

∫ φ(a)φ(b)f(t)dt = ∫ abf(φ(x))φ′(x)dx.

Observe that if φ′(x) > 0 for all x in [a,b], then φ([a,b]) = [φ(a),φ(b)]; if φ′(x) < 0 for all x in [a,b], then φ([a,b]) = [φ(b),φ(a)].

We now pass from intervals and Riemann-integrable functions to Borel sets and positive Borel functions. The next lemma packages the one-dimensional Jacobian formula as the equality between the Lebesgue measure on the target interval and a transport measure defined on that interval.

Lemma 13.13 (Transport measure for a one-dimensional diffeomorphism). Let I,J be open intervals of ℝ, and let φ: I → J be a diffeomorphism of class C1. For every E in B(J), define

ν(E) := ∫ I1E(φ(x))|φ′(x)|dx.

Then ν is a measure on B(J) and

ν(E) = λ(E)

for every E in B(J).

Proof. Step 1. Construction of the transport measure. For every Borel set E ⊂ J, the set φ−1(E) is Borel in I, because φ is continuous. Hence the formula defining ν(E) is meaningful. If (Ek)k≥1 is a pairwise disjoint sequence in B(J), then

1∪k≥1Ek(φ(x))|φ′(x)| = ∑ k=1∞1 Ek(φ(x))|φ′(x)|.

The integration theorem for series of positive functions, Corollary 7.4, gives

ν (⋃ k=1∞E k) = ∑ k=1∞ν(E k).

Thus ν is a measure.

Step 2. Computation on half-open intervals. Because φ′ is continuous and never vanishes on the connected set I, it has a constant sign on I. Let c < d be two points of J. If φ′ > 0 on I, then

φ−1((c,d]) = (φ−1(c),φ−1(d)],

and the usual fundamental theorem for C1 functions gives

ν((c,d]) = ∫ φ−1(c)φ−1(d)φ′(x)dx = d − c.

If φ′ < 0 on I, then

φ−1((c,d]) = [φ−1(d),φ−1(c)),

and

ν((c,d]) = ∫ φ−1(d)φ−1(c) − φ′(x)dx = d − c.

Thus ν and λ coincide on all half-open intervals contained in J.

Step 3. Extension to all Borel sets. We now prove that ν = λ on B(J) by localizing on bounded half-open intervals. Choose an increasing sequence (Jn)n≥1 of bounded half-open intervals contained in J such that

J = ⋃ n≥1Jn.

For every n ≥ 1, the restrictions of ν and λ to B(Jn) are finite measures, because ν(Jn) = λ(Jn) < +∞ by the computation above. By Lemma 3.13, the family

PJn := {∅,Jn}∪{(s,t] ⊂ Jn : s < t}

is a π-system that generates B(Jn). The two finite measures coincide on this π-system, so Corollary 3.12 gives

ν(F) = λ(F)

for every F in B(Jn). In particular,

ν(E ∩ Jn) = λ(E ∩ Jn)

for every E in B(J) and every n ≥ 1. Since (E ∩ Jn)n≥1 is increasing and has union E, the continuity from below of measures, Theorem 2.3, gives

ν(E) = lim ⁡ n→∞ν(E ∩ Jn) = lim ⁡ n→∞λ(E ∩ Jn) = λ(E).

This proves the lemma. □

The transport-measure identity now gives the Lebesgue one-dimensional change-of-variables theorem on intervals. The proof first checks the formula on nonnegative simple functions and then uses monotone convergence.

Theorem 13.14 (Lebesgue one-dimensional change-of-variables theorem). Let I,J be open intervals of ℝ, and let φ: I → J be a diffeomorphism of class C1. Let f : J → [0,∞] be a Borel function. Then the map

x↦f(φ(x))|φ′(x)|

is measurable on I, and

∫ Jf(t)dt = ∫ If(φ(x))|φ′(x)|dx.

The same identity also holds for every f in L1(J).

Proof. Step 1. Measurability and the simple-function case. Since f is Borel and φ is continuous, the map x↦f(φ(x))|φ′(x)| is measurable. Let ν be the measure constructed in Lemma 13.13. If

s = ∑ k=1ma k1Ek

is a nonnegative simple Borel function on J, then by the definition of ν and by Lemma 13.13,

∫ Js(t)dt = ∫ Jsdν = ∫ Is(φ(x))|φ′(x)|dx.

Step 2. Passage to nonnegative Borel and integrable functions. For a general nonnegative Borel function f, choose simple functions sn ↑ f and apply the monotone convergence theorem, Theorem 7.1, on both sides. If f is in L1(J), apply the nonnegative case to f+ and f−. □

The next corollary removes the assumption that the open sets are intervals. The only new point is that every open subset of ℝ is the disjoint union of its connected components.

Corollary 13.15 (One-dimensional change of variables for positive functions). Let I and J be open subsets of ℝ, and let φ: I → J be a diffeomorphism of class C1. Let f : J → [0,∞] be a Borel function. Then

∫ Jf(t)dt = ∫ If(φ(x))|φ′(x)|dx.

The same identity also holds for every f in L1(J).

Proof. Step 1. Decomposition into connected components. The open sets I and J are countable unions of pairwise disjoint open intervals, namely their connected components. Since φ is a homeomorphism, it induces a bijection between the connected components of I and those of J. Therefore we may write

I = ⋃ n=1∞I n,J = ⋃ n=1∞J n,

where the unions are disjoint, each In and each Jn is an open interval, and

φ(In) = Jn

for every n ≥ 1.

Step 2. Summation of the interval formulas. Applying Theorem 13.14 on each pair (In,Jn) and summing by the monotone convergence theorem, Theorem 7.1, gives the identity for nonnegative Borel functions. If f ∈L1(J), apply the nonnegative case to f+ and f−. □

13.2.2 Multidimensional change of variables

The following part proves the multidimensional change-of-variables formula first in the compactly supported continuous case. The full extension to nonnegative Borel functions and then to L1 functions will be given later in Corollary 14.6, once the Radon-measure machinery is available.

Definition 13.16 (Elementary diffeomorphisms). Let d ≥ 2. A C1 diffeomorphism Ψ: U → V between open subsets of ℝd is called an elementary diffeomorphism if there exists k in {1,…,d} and a C1 function ψ such that

Ψ(x1,…,xd) = (x1,…,xk−1,ψ(x1,…,xd),xk+1,…,xd ).

Thus only one coordinate is changed.

The strategy is to prove the formula for elementary diffeomorphisms, then to show that a general local diffeomorphism can be decomposed, after a linear normalization, as a finite composition of such elementary diffeomorphisms.

Lemma 13.17 (Change of variables for elementary diffeomorphisms). Let d ≥ 2, let U and V be open subsets of ℝd, and let Ψ: U → V be an elementary diffeomorphism of class C1. If

Ψ(x1,…,xd) = (x1,…,xk−1,ψ(x1,…,xd),xk+1,…,xd ),

then, for every nonnegative Borel function f on V ,

∫ V f(y)dy = ∫ Uf(Ψ(x)) | ∂ψ ∂xk(x)| dx.

The same identity also holds for every f in L1(V ).

Proof. Up to permuting the coordinates, we may assume that k = d. We write

x = (x′,t),x′ = (x 1,…,xd−1) ∈ ℝd−1,t ∈ ℝ.

For every x′ in ℝd−1, define the sections

Ux′ := {t ∈ ℝ: (x′,t) ∈ U},V x′ := {s ∈ ℝ: (x′,s) ∈ V }.

Since Ψ leaves the first d − 1 coordinates unchanged, the map

ψx′: Ux′ → V x′,ψx′(t) := ψ(x′,t),

is a C1 diffeomorphism between open subsets of ℝ. Therefore Corollary 13.15 gives, for every fixed x′ and every nonnegative Borel function f,

∫ V x′f(x′,s)ds = ∫ Ux′f (x′,ψ(x′,t) ) |∂ψ ∂t (x′,t)| dt.

We integrate this identity with respect to x′ and use Tonelli’s theorem, Theorem 10.5. The left-hand side becomes

∫ ℝd−1 ∫ V x′f(x′,s)dsdx′ = ∫ V f(y)dy,

and the right-hand side becomes

∫ ℝd−1 ∫ Ux′f (x′,ψ(x′,t) ) |∂ψ ∂t (x′,t)| dtdx′ = ∫ Uf(Ψ(x)) | ∂ψ ∂xd(x)| dx.

This proves the formula for nonnegative Borel functions. If f ∈L1(V ), apply the nonnegative case to f+ and f−. □

Lemma 13.18 (Linear change of variables for continuous compactly supported functions). Let A: ℝd → ℝd be an invertible linear map. Then, for every f in Cc(ℝd),

∫ ℝdf(y)dy = ∫ ℝdf(Ax)| det ⁡ A|dx.

Proof. If d = 1, this is exactly Theorem 13.14 applied to the diffeomorphism x↦Ax. Assume now that d ≥ 2. The formula is immediate for permutations of the coordinates. It also follows from Lemma 13.17 for diagonal maps and for shears. Since every invertible matrix is a product of elementary matrices of these three types by Gaussian elimination, and since the Jacobian determinant is multiplicative under composition, the general case follows. □

Lemma 13.19 (Local factorization of diffeomorphisms). Let d ≥ 2, let φ: U → V be a C1 diffeomorphism between open sets of ℝd, and let a be in U. Then there exists an open neighbourhood W of a, an open neighbourhood Z of φ(a), and elementary diffeomorphisms

Ψ1,…,Ψd

between suitable open sets such that

Dφ(a)−1 ∘ φ = Ψ d ∘⋯ ∘Ψ1

on W, and such that φ(W) = Z. The composition is understood between the successive open sets which occur in the construction.

Proof. Step 1. Linear normalization. We set

A := Dφ(a)−1,F 0 := A ∘ φ.

Then DF0(a) = I. After shrinking U around a, we may assume, by the inverse function theorem, that F0 is a diffeomorphism from an open neighbourhood W0 of a onto an open set.

Step 2. Inductive elimination of the coordinates. We construct inductively open neighbourhoods Wk, points bk in Wk, and diffeomorphisms Fk such that

1.
Fk is a C1 diffeomorphism on Wk,
2.
the first k coordinates of Fk are the identity on Wk,
3.
DFk(bk) = I.

Initially, b0 := a and F0 satisfies 1) and 3). Assume that 0 ≤ k ≤ d − 1 and that Fk has already been constructed. Since DFk(bk) = I, we have

∂(Fk)k+1 ∂xk+1 (bk) = 1.

After shrinking Wk if necessary, we may therefore assume that this partial derivative never vanishes on Wk. We define

Ψk+1(x1,…,xd) := (x1,…,xk, (Fk)k+1(x),xk+2,…,xd )

for x in Wk. By the inverse function theorem, after possibly shrinking Wk once more, the map Ψk+1 is an elementary C1 diffeomorphism from Wk onto an open set Wk+1. We set

Fk+1 := Fk ∘Ψk+1−1

on Wk+1 and

bk+1 := Ψk+1(bk).

For j ≤ k, the j-th coordinate of Fk is the identity, and Ψk+1 leaves the first k coordinates unchanged. Hence, for every y in Wk+1,

(Fk+1)j(y) = (Fk)j(Ψk+1−1(y)) = y j.

Moreover,

(Fk+1)k+1(y) = (Fk)k+1(Ψk+1−1(y)) = y k+1

by the definition of Ψk+1. Thus the first k + 1 coordinates of Fk+1 are the identity on Wk+1. Finally, since DFk(bk) = I, the Jacobian matrix of Ψk+1 at bk is also the identity. Therefore

DFk+1(bk+1) = DFk(bk)DΨk+1−1(b k+1) = I.

This completes the induction.

Step 3. Reconstruction of the factorization. After d steps, all the coordinates of Fd are the identity, so Fd = Id on Wd. Tracing back the construction, we obtain

F0 = Ψd ∘⋯ ∘Ψ1

on W0, where the composition is taken through the successive open sets W0,W1,…,Wd. We set W := W0 and Z := φ(W). □

Corollary 13.20 (Local-to-global change of variables). Let d ≥ 2, let φ: U → V be a C1 diffeomorphism between open sets of ℝd. For every a in U, there exists an open neighbourhood W of a and an open neighbourhood Z of φ(a) such that φ(W) = Z and such that, for every g in Cc(Z),

∫ Zg(y)dy = ∫ W g(φ(x))|Jacφ(x)|dx.

Proof. By Lemma 13.19, after shrinking around a if necessary, we can write on W

Dφ(a)−1 ∘ φ = Ψ d ∘⋯ ∘Ψ1.

The formula is known for each elementary diffeomorphism Ψj by Lemma 13.17, and for the linear map Dφ(a) by Lemma 13.18. By composing these formulas and using the multiplicativity of the Jacobian determinant, we obtain the desired local identity. □

Theorem 13.21 (Multidimensional change-of-variables theorem). Let d ≥ 1, let U and V be open sets of ℝd, and let φ: U → V be a diffeomorphism of class C1. Then, for every f in Cc(V ),

∫ V f(y)dy = ∫ Uf(φ(x))|Jacφ(x)|dx.

Proof. Step 1. Reduction to the case d ≥ 2. If d = 1, this is Corollary 13.15 applied to compactly supported continuous functions. We now assume that d ≥ 2.

Step 2. A finite local cover of the support. Let K := supp(f). For every y in K, set a := φ−1(y) and choose open neighbourhoods Wy of a and Zy of y given by Corollary 13.20, with φ(Wy) = Zy. Since K is compact, there exist finitely many points y1,…,ym in K and open sets Z~j such that

yj ∈Z~j,Z~j¯ ⊂ Zyj(j = 1,…,m),

and

K ⊂⋃ j=1mZ~ j.

Step 3. A partition of the function. For every j = 1,…,m, define

uj(y) := dist(y,V ∖Z~j),y ∈ V.

Then uj is continuous, nonnegative, and

supp(uj) ⊂Z~j¯ ⊂ Zyj.

We set

u := ∑ j=1mu j.

Since the open sets Z~j cover K, we have u > 0 on K. Moreover, if u(y) = 0, then y does not belong to K = supp(f), hence f(y) = 0. We may therefore define, for every j = 1,…,m,

fj(y) := { uj(y) u(y) f(y)  if  u(y) > 0, 0  if  u(y) = 0.

We now check that each fj is continuous on V . Continuity is clear at points where u > 0. If u(y0) = 0, then y0∉K = supp(f). Since K is closed, there is a neighbourhood of y0 on which f = 0. Hence each fj is identically zero on a neighbourhood of y0, and is continuous at y0. Moreover,

supp(fj) ⊂ K ∩ supp(uj) ⊂ K ∩Z~j¯ ⊂ Zyj,

so fj belongs to Cc(Zyj). Finally,

f = ∑ j=1mf j.

Step 4. Summation of the local formulas. Applying Corollary 13.20 to each fj and summing, we obtain

∫ V f(y)dy = ∑ j=1m ∫ V fj(y)dy = ∑ j=1m ∫ Ufj(φ(x))|Jacφ(x)|dx = ∫ Uf(φ(x))|Jacφ(x)|dx. □
