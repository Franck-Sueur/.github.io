Chapter 7
Lebesgue’s monotone convergence theorem

This chapter contains the first major convergence theorem of the course. Once monotone convergence has been proved, the linearity of the integral for positive functions, the series version, the generalized Chasles property, and Fatou’s lemma follow in a systematic way.

7.1 Monotone convergence theorem

An ingredient for establishing the linearity of the integral of positive measurable functions, which is also one of the most important results of this course, is the following theorem.

Theorem 7.1 (Monotone convergence theorem, or Beppo Levi theorem). Let (X,A,μ) be a measure space and let (fn)n≥1 be a sequence of measurable functions from X to [0,∞] such that

∀ ⁡n ≥ 1,∀ ⁡x in X,fn(x) ≤ fn+1(x).

For every x in X, we define

f(x) := lim ⁡ n→∞fn(x).

Then f is measurable, the sequence (∫ Xfndμ)n≥1 converges in [0,∞], and

lim ⁡ n→∞∫ Xfndμ = ∫ Xfdμ.

Proof. Step 1. The easy inequality. The function f is measurable by Theorem 4.10, since it is the pointwise limit of measurable functions.

For every n ≥ 1, we have 0 ≤ fn ≤ f on X, so Theorem 6.3 gives

∫ Xfndμ ≤∫ Xfdμ.

Moreover, since fn ≤ fn+1, the sequence (∫ Xfndμ)n≥1 is increasing. Hence its limit

ℓ := lim ⁡ n→∞∫ Xfndμ

exists in [0,∞] and satisfies

ℓ ≤∫ Xfdμ.

Step 2. Testing against a simple function below f. Let now s be a simple positive measurable function such that s ≤ f on X, and let c in ]0, 1[. For every n ≥ 1, we define

Xn := {x ∈ X : fn(x) ≥ cs(x)}.

Each set Xn belongs to A, and the sequence (Xn)n≥1 is increasing. Moreover,

⋃ n≥1Xn = X.

Indeed, let x in X. If s(x) = 0, then x belongs to Xn for every n ≥ 1. If s(x) > 0, then

fn(x) → f(x)as n → +∞,f(x) ≥ s(x) > cs(x),

so there exists n ≥ 1 such that x belongs to Xn.

Let

s = ∑ i=1rα i1Ai

be the canonical decomposition of s. For every n ≥ 1, we have

∫ Xnsdμ = ∑ i=1rα iμ(Ai ∩ Xn).

For every i ∈{1,…,r}, the sequence (Ai ∩ Xn)n≥1 is increasing and

⋃ n≥1(Ai ∩ Xn) = Ai.

The first item of Theorem 2.3 therefore yields

μ(Ai ∩ Xn) → μ(Ai)as n → +∞.

Since the sum is finite, we deduce that

∫ Xnsdμ →∫ Xsdμas n → +∞. (7.1)

Step 3. Passage to the supremum over simple functions. For every n ≥ 1, we have

∫ Xfndμ ≥∫ Xnfndμ ≥ c∫ Xnsdμ.

Passing to the limit and using (7.1), we obtain

ℓ ≥ c∫ Xsdμ.

Letting c tend to 1, which is valid in [0, +∞] also when ∫ Xsdμ = +∞, we get

ℓ ≥∫ Xsdμ.

Since this is true for every simple positive measurable function s such that s ≤ f, Definition 6.1 yields

ℓ ≥∫ Xfdμ.

Therefore

ℓ = ∫ Xfdμ,

which concludes the proof. □

Example 7.2 (Monotone approximation by simple truncations). Let (X,A,μ) be a measure space and let f : X → [0,∞] be measurable. For every n ≥ 1, we define

fn := min ⁡(f,n).

Then each fn is measurable, the sequence (fn)n≥1 is increasing, and

0 ≤ fn ≤ f

on X. Moreover, for every x in X, the sequence (fn(x))n≥1 increases to f(x). This is the most basic monotone approximation of a positive measurable function. By the monotone convergence theorem just proved, it follows that

∫ Xfndμ ↑∫ Xfdμ.

7.2 Linearity of the integral of positive measurable functions

The monotone convergence theorem combined with Theorem 6.6 and Lemma 5.13 finally allows us to obtain the desired general linearity properties.

Corollary 7.3 (Linearity of the integral). Let (X,A,μ) be a measure space. If f,g: X → [0,∞] are measurable, then for all E ∈A,

∫ E(f + g)dμ = ∫ Efdμ + ∫ Egdμ.

Proof. By Theorem 6.6, there exist two sequences (sk)k≥1 and (tk)k≥1 of simple positive measurable functions such that

sk ↑ f,tk ↑ g

pointwise on X. For every k ≥ 1, the function sk + tk is simple, positive, and measurable, and

sk + tk ↑ f + g

pointwise on X.

By Lemma 5.13, for every k ≥ 1,

∫ X(sk + tk)dμ = ∫ Xskdμ + ∫ Xtkdμ.

Applying the monotone convergence theorem to the three increasing sequences (sk)k≥1, (tk)k≥1, and (sk + tk)k≥1, we obtain

∫ X(f + g)dμ = ∫ Xfdμ + ∫ Xgdμ.

Finally, item 1 of Theorem 6.4 gives

∫ E(f + g)dμ = ∫ X(f + g)1Edμ = ∫ X(f1E + g1E)dμ = ∫ Xf1Edμ + ∫ Xg1Edμ = ∫ Efdμ + ∫ Egdμ.

This is the desired identity. The same identity extends by induction to every finite sum of positive measurable functions. □

7.3 Monotone convergence theorem for series of positive functions

Another corollary of the monotone convergence theorem concerns a series of positive functions.

Corollary 7.4 (Integration of normally convergent series). Let (X,A,μ) be a measure space, and let (fn)n≥1 be a sequence of measurable functions from X to [0,∞]. Then the function

f := ∑ n=1∞f n

is measurable, and for all E ∈A, we have

∫ Efdμ = ∑ n=1∞ (∫ Efndμ ).

Proof. For every N ≥ 1, we define the partial sum

SN := ∑ n=1Nf n.

Each function SN is measurable, the sequence (SN)N≥1 is increasing, and

SN ↑ f

pointwise on X. By the previous corollary, for every N ≥ 1 we have

∫ ESNdμ = ∑ n=1N ∫ Efndμ.

Applying the monotone convergence theorem to the sequence (SN1E)N≥1 on X yields

∫ Efdμ = lim ⁡ N→∞∫ ESNdμ = lim ⁡ N→∞∑ n=1N ∫ Efndμ = ∑ n=1∞∫ Efndμ.
□

7.4 Chasles property for positive functions

We can also deduce a Chasles-type result, which generalizes the statement seen for simple functions.

Corollary 7.5 (Integrals over increasing domains). Let (X,A,μ) be a measure space. Let f : X → [0,∞] be a measurable function. If (En)n≥1 is a sequence of elements of A which are pairwise disjoint, then

∫ Efdμ = ∑ n=1∞∫ Enfdμ,where E := ⋃ n=1∞E n.

Proof. For every n ≥ 1, we define

gn := f1En.

The functions gn are positive and measurable. Since the sets En are pairwise disjoint, we have

∑ n=1∞g n = f1E

pointwise on X. By Corollary 7.4 and by item 1 of Theorem 6.4, we obtain

∫ Efdμ = ∫ Xf1Edμ = ∫ X ∑ n=1∞g ndμ = ∑ n=1∞∫ Xgndμ = ∑ n=1∞∫ Enfdμ. □

7.5 Fatou’s Lemma

Finally, let us end this chapter with the following corollary of the monotone convergence theorem which does not require considering a convergent sequence but only allows us to prove an inequality.

Corollary 7.6 (Fatou’s lemma). Let (X,A,μ) be a measure space and let (fn)n≥1 be a sequence of measurable functions from X to [0,∞]. Then

∫ X liminf ⁡ n→∞fndμ ≤liminf ⁡n→∞∫ Xfndμ.

Proof. For every n ≥ 1, we define

gn(x) := inf ⁡ i≥nfi(x).

Each function gn is positive and measurable by Theorem 4.10, and the sequence (gn)n≥1 is increasing. Moreover, for every x in X, we have

gn(x) ↑liminf ⁡n→∞fn(x).

The monotone convergence theorem therefore yields

∫ X liminf ⁡ n→∞fndμ = lim ⁡ n→∞∫ Xgndμ.

Now let n ≥ 1. For every i ≥ n, we have gn ≤ fi, hence

∫ Xgndμ ≤∫ Xfidμ.

Taking the infimum over all i ≥ n, we obtain

∫ Xgndμ ≤ inf ⁡ i≥n ∫ Xfidμ.

Passing to the limit in n, we conclude that

∫ X liminf ⁡ n→∞fndμ ≤ lim ⁡ n→∞ inf ⁡ i≥n ∫ Xfidμ = liminf ⁡ n→∞∫ Xfndμ.
□
