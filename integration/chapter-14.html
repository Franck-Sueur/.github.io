Chapter 14
Radon measures, Riesz representation and the Lebesgue measure

We return to measures on open subsets of ℝN and exploit the underlying topological structure. The chapter proves the Riesz representation theorem for positive functionals on Cc(Ω), uses it to recover the Lebesgue measure, and then studies bounded Radon measures and their weak convergence. The proof of the Riesz theorem uses two topological tools recalled in the appendix: Urysohn’s lemma and a partition-of-unity lemma, stated there as Lemmas 16.41 and 16.42.

14.1 The converse problem and the Riesz representation theorem

In this section Ω stands for an open subset of ℝN (N ≥ 1). We recall from Definition 2.8 that a positive Radon measure on Ω is a Borel measure which is finite on compact sets. We already saw in Section 8.8 that every positive Radon measure on Ω defines a positive linear functional on Cc(Ω) by integration. We now address the converse problem: starting from a positive linear functional on Cc(Ω), reconstruct a measure. The theorem below shows that the resulting measure is not only locally finite, but also complete and regular.

Actually, the result is even stronger, for it provides a complete measure, in the following sense (not to be confused with the topological notion of completeness), representing L. The regularity properties appearing in items 3) and 4) below are precisely the notions introduced in Section 2.3. We also recall that a measure space is said to be complete if every negligible set is measurable.

Theorem 14.1 (Riesz representation theorem for positive functionals on Cc). Let L : Cc(Ω) → ℝ be a positive linear functional. Then there exists a σ-algebra A containing the Borel σ-algebra B(Ω) and a measure μ on A such that

1.
L(f) = ∫ Ωfdμ, for every f ∈Cc(Ω),
2.
μ(K) < ∞ for every compact set K ⊂Ω,
3.
for every E ∈A,
μ(E) = inf ⁡{μ(V ) : E ⊂ V,V  open}, (14.1)
4.
for every open set E, and every E ∈A with μ(E) < ∞,
μ(E) = sup ⁡{μ(K) : K ⊂ E,K compact}, (14.2)
5.
the measure space (X,A,μ) is complete,
6.
for any E ∈B(Ω) and any 𝜀 > 0, there exists a closed set C and an open set V such that C ⊂ E ⊂ V , and
μ(V ∖ C) < 𝜀. (14.3)

Moreover, this measure is unique in the sense that if (A1,μ1) and (A2,μ2) satisfy the properties 1)-2)-3-4), then the restrictions of μ1 and μ2 to B(Ω) are equal.

Proof. Let us start by proving uniqueness. Assume that μ1 and μ2 are two Radon measures satisfying the conclusion of the Riesz representation Theorem. By the regularity property (14.2), it suffices to prove that μ1(K) = μ2(K) for every compact set K.

Let 𝜀 > 0 and K a compact set. By (14.1), there exists an open set V containing K such that μ2(V ) < μ2(K) + 𝜀. By Urysohn’s lemma (Lemma 16.41 in the appendix) one can find a function f ∈Cc(V ; [0, 1]) such that f = 1 on K. In particular,

1K ≤ f ≤1V ,

hence

μ1(K) = ∫ Ω1Kdμ1 ≤∫ Ωfdμ1 = L(f) = ∫ Ωfdμ2 ≤∫ Ω1V dμ2 = μ2(V ) < μ2(K)+𝜀.

Thus μ1(K) ≤ μ2(K) and exchanging the roles of μ1 and μ2 we deduce that this inequality is actually an equality. This concludes the uniqueness part.

We now turn our attention to the existence. For every open set V ⊂Ω, we define

μ(V ) := sup ⁡{L(f) : f ∈Cc(Ω; [0, 1]),supp(f) ⊂ V }. (14.4)

Clearly, if V 1 ⊂ V 2, then μ(V 1) ≤ μ(V 2) so that we can extend μ to any arbitrary E ⊂Ω by setting

μ(E) := inf ⁡{μ(V ) : E ⊂ V,V  open}.

Note that both definitions are consistent for open sets, and that property (14.1) will be automatically satisfied. Moreover, μ is an increasing set function, i.e. if E1 ⊂ E2, then μ(E1) ≤ μ(E2).

Let AF be the family of all sets E ⊂Ω such that μ(E) < ∞ and

μ(E) = sup ⁡{μ(K) : K ⊂ E,K compact}.

Finally, let A be the class of all E ⊂Ω such that E ∩ K ∈AF for any compact K.

Step 1. If K is compact, then K ∈AF , and

μ(K) = inf ⁡{L(f) : f ∈Cc(Ω; [0, 1]),f = 1 on K}. (14.5)

Moreover, if V is open, then V satisfies (14.2). In particular if μ(V ) < ∞, then V ∈AF .

Let f ∈Cc(Ω; [0, 1]) such that f = 1 on K, α ∈ (0, 1), and V α := {f > α}. Then K ⊂ V α and αg ≤ f for every g ∈Cc(V α; [0, 1]). Hence

μ(K) ≤ μ(V α) = sup ⁡{L(g) : g ∈Cc(V α; [0, 1])}≤ α−1L(f).

Letting α → 1 leads to μ(K) ≤ L(f) < ∞. Therefore K ∈AF since (14.2) is immediate. Next if 𝜀 > 0, there exists an open set V containing K with μ(V ) < μ(K) + 𝜀. By Urysohn’s lemma (Lemma 16.41 in the appendix), there exists a function f ∈Cc(V ; [0, 1]) satisfying f = 1 on K, and thus

μ(K) ≤ L(f) ≤ μ(V ) < μ(K) + 𝜀,

which gives (14.5).

Consider now an open set V . Then for any α < μ(V ), there exists f ∈Cc(V ; [0, 1]) such that α < L(f). Hence for every open set W containing

K := supp(f),

then f ∈Cc(W) and by definition of μ we have that

L(f) ≤ μ(W).

Taking the infimum over all such W’s leads to L(f) ≤ μ(K). This proves the existence of a compact set K ⊂ V with α < μ(K) which ensures that V satisfies (14.2), and that V ∈AF if further μ(V ) < ∞.

Step 2. For every sets En ⊂Ω for n ∈ ℕ∗, then

μ (⋃ n=1∞E n) ≤∑ n=1∞μ(E n).

We first prove that μ is finitely subadditive on open sets, i.e.,

μ(V 1 ∪ V 2) ≤ μ(V 1) + μ(V 2) (14.6)

when V 1 and V 2 are open sets. Let g ∈Cc(V 1 ∪ V 2; [0, 1]). By the partition-of-unity lemma from the appendix (Lemma 16.42), there exist functions f1 and f2 such that fi ∈Cc(V i; [0, 1]) and f1 + f2 = 1 on supp(g). Hence fig ∈Cc(V i; [0, 1]),

g = f1g + f2g

so that by linearity of L and by definition of μ,

L(g) = L(f1g) + L(f2g) ≤ μ(V 1) + μ(V 2).

Taking the supremum with respect to all g as above gives

μ(V 1 ∪ V 2) ≤ μ(V 1) + μ(V 2).

Now if μ(En) = ∞ for some n then the result is obvious. Otherwise, if μ(En) < ∞ for all n, then for any 𝜀 > 0 there exists open sets V n such that En ⊂ V n and

μ(V n) < μ(En) + 2−n𝜀.

Define

V := ⋃ n=1∞V n,

and take f ∈Cc(V ; [0, 1]). In particular, since supp(f) is compact, one can find finitely many V 1,…,V p such that

supp(f) ⊂⋃ n=1pV n.

Hence iterating (14.6),

L(f) ≤ μ (⋃ n=1pV n) ≤∑ n=1pμ(V n) ≤∑ n=1∞μ(E n) + 𝜀.

Since this holds for every f ∈Cc(V ; [0, 1]), and since ⋃ ⁡ n=1∞E n ⊂ V , it follows that

μ (⋃ n=1∞E n) ≤ μ(V ) ≤∑ n=1∞μ(E n) + 𝜀,

which completes the proof of step 2 since 𝜀 is arbitrary.

Step 3. suppose that E = ⋃ ⁡ n=1∞E n, where En are pairwise disjoint elements of AF for all n ∈ ℕ∗. Then,

μ(E) = ∑ n=1∞μ(E n). (14.7)

If in addition, μ(E) < ∞, then E ∈AF .

We first prove that μ is finitely additive on compact sets, i.e.,

μ(K1 ∪ K2) = μ(K1) + μ(K2) (14.8)

if K1 and K2 are disjoint compact sets. Let 𝜀 > 0. By Urysohn’s lemma (Lemma 16.41 in the appendix), there exists f ∈Cc(Ω; [0, 1]) such that f = 1 on K1 and f = 0 on K2. Then by Step 1 there exists a function g ∈Cc(Ω) such that g = 1 on K1 ∪ K2 and

L(g) ≤ μ(K1 ∪ K2) + 𝜀.

Note that fg = 1 on K1 and (1 − f)g = 1 on K2. Hence by linearity of L, it follows that

μ(K1) + μ(K2) ≤ L(fg) + L((1 − f)g) = L(g) ≤ μ(K1 ∪ K2) + 𝜀.

Since 𝜀 is arbitrary, (14.8) follows from step 2.

If μ(E) = ∞, then (14.7) is an immediate consequence of step 2. Therefore, we can assume that μ(E) < ∞. Let 𝜀 > 0, since En ∈AF , there exist compact sets Hn ⊂ En with

μ(Hn) > μ(En) − 2−n𝜀,

for each n ∈ ℕ∗. Define

Kn := ⋃ k=1nH k ⊂ E,

which is compact. Thus using an induction on (14.8), we deduce that

μ(E) ≥ μ(Kn) = ∑ k=1nμ(H k) > ∑ k=1nμ(E k) − 𝜀.

Since the previous relation holds for every n ∈ ℕ∗ and every 𝜀 > 0, using again step 2, we deduce (14.7). Moreover for n large enough (depending on 𝜀) we have

μ(E) ≤∑ k=1nμ(E k) + 𝜀 ≤ μ(Kn) + 2𝜀,

which proves that E ∈AF .

Step 4. If E ∈AF and 𝜀 > 0, there is a compact set K and an open set V such that K ⊂ E ⊂ V and μ(V ∖ K) < 𝜀. Moreover, if A and B ∈AF , then A ∖ B, A ∪ B and A ∩ B ∈AF .

Our definitions prove that there exists a compact set K and an open set V with K ⊂ E ⊂ V to that

μ(V ) −𝜀 2 < μ(E) < μ(K) + 𝜀 2 < ∞,

where we used the fact that, from step 1, μ is finite on compact sets. Using again step 1, since V ∖ K is open and μ(V ∖ K) < ∞, it therefore belongs to AF . We apply step 3 to get that

μ(K) + μ(V ∖ K) = μ(V ) < μ(K) + 𝜀 < ∞.

Now if A and B ∈AF and 𝜀 > 0, one can find compact sets K1 and K2, and open sets V 1 and V 2 such that K1 ⊂ A ⊂ V 1 and K2 ⊂ B ⊂ V 2, and μ(V i ∖ Ki) < 𝜀 (for i = 1, 2). Since

A ∖ B ⊂ V 1 ∖ K2 ⊂ (V 1 ∖ K1) ∪ (K1 ∖ V 2) ∪ (V 2 ∖ K2),

from the subadditivity proved in step 2, we infer that

μ(A ∖ B) ≤ 2𝜀 + μ(K1 ∖ V 2).

But since K1 ∖ V 2 is a compact subset of A ∖ B, it proves that A ∖ B ∈AF . Then since

A ∪ B = (A ∖ B) ∪ B,

an application of step 3 proves that A ∪ B ∈AF . Finally, since A ∩ B = A ∖ (A ∖ B), we also have A ∩ B ∈AF .

Step 5. A is a σ-algebra which contains all Borel sets, and all sets E ⊂Ω such that μ(E) = 0. Moreover

AF = {E ∈A : μ(E) < ∞}.

Finally, μ is a measure on A satisfying (14.1) and (14.2).

First step 1 gives that Ω is in A.

Now let K be an arbitrary compact set in X. If A ∈A, then A ∩ K ∈AF and thus by step 4,

Ac ∩ K = K ∖ (A ∩ K) ∈A F .

Consequently, Ac ∈A. Now if An ∈A for each n ∈ ℕ∗, define B1 = A1 ∩ K and for n ≥ 2,

Bn = (An ∩ K) ∖⋃ k=1n−1B k.

Then by step 4, (Bn) is made of pairwise disjoint elements of AF . Thus by step 3, we have

K ∩⋃ n=1∞A n = ⋃ n=1∞B n ∈AF

and thus

⋃ n=1∞A n ∈A.

This proves that A is a σ-algebra. If C is closed, then K ∩ C is compact and by step 1, it belongs to AF . Hence C ∈A. This proves that A is a σ-algebra containing all closed sets and consequently all Borel sets. If E ⊂Ω is such that μ(E) = 0, then clearly E ∈A since μ is an increasing set function.

By steps 1 and 4, we clearly have that

AF ⊂{E ⊂A : μ(E) < ∞}.

Conversely, let E ∈A such that μ(E) < ∞ and let 𝜀 > 0. There exists an open set V containing E such that μ(V ) < ∞. Using again steps 1 and 4, one can find a compact set K ⊂ V such that μ(V ∖ K) < 𝜀. Since

E ∩ K ∈AF ,

there exists a compact set H ⊂ E ∩ K with

μ(E ∩ K) < μ(H) + 𝜀.

Since

E ⊂ (E ∩ K) ∪ (V ∖ K),

it follows that

μ(E) ≤ μ(E ∩ K) + μ(V ∖ K) < μ(H) + 2𝜀,

which implies that E ∈AF . Hence properties (14.1) and (14.2) follow.

We next prove that μ is a measure on (Ω,A). If (En) is a sequence of pairwise disjoint elements of A, then

E := ⋃ n=1∞E n ∈A.

If μ(E) = ∞, then by Step 2, we have

μ (E) = ∑ n=1∞μ(E n),

while if μ(E) < ∞ then μ(En) < ∞ for each n ∈ ℕ∗ and thus E, En ∈AF for all n ∈ ℕ∗. Consequently, by step 3, we have the same result which proves that μ is a measure on A.

Step 6. Proof of the representation property 1).

Let f ∈Cc(Ω). Clearly it is enough to check the inequality L(f) ≤∫ Ωfdμ because by linearity of L, it implies

−L(f) = L(−f) ≤∫ Ω(−f)dμ = −∫ Ωfdμ,

and therefore the representation property 1). Let K := suppf and [a,b] be an interval which contains the range of f. For 𝜀 > 0, let y0,…,yn ∈ ℝ be such that y0 < a < y1 < … < yn = b, and max ⁡ 1≤i≤n(yi − yi−1) < 𝜀. Define

Ei := {yi−1 < f ≤ yi}∩ K.

Since f is continuous, f is Borel measurable and the sets Ei are therefore disjoint Borel sets whose union is K. There are open sets V i containing Ei and such that μ(V i) < μ(Ei) + 𝜀∕n and f(x) < yi + 𝜀 for all x ∈ V i and all i = 1,…,n. By the partition-of-unity lemma from the appendix (Lemma 16.42), one can find functions hi ∈Cc(V i; [0, 1]) such that ∑ ⁡ i=1nh i = 1 on K. Hence,

f = ∑ i=1nh if

in Ω and by step 1, we infer that

μ(K) ≤ L (∑ i=1nh i) = ∑ i=1nL(h i).

Note that

L(hi) ≤ μ(V i) < μ(Ei) + 𝜀∕n,

hif ≤ (yi + 𝜀)hi and yi − 𝜀 < f(x) for x ∈ Ei. Denoting by M := max ⁡ K|f| < +∞ we have

L(f) = ∑ i=1nL(h if) ≤∑ i=1n(y i + 𝜀)L(hi) = ∑ i=1n(M + y i + 𝜀)L(hi) − M∑ i=1nL(h i) ≤∑ i=1n(M + y i + 𝜀) (μ(Ei) + 𝜀 n ) − Mμ(K) ≤∑ i=1n(y i − 𝜀)μ(Ei) + 2𝜀μ(K) + 𝜀 n∑ i=1n(M + y i + 𝜀) ≤∫ Ωfdμ + 𝜀(2μ(K) + 2M + 𝜀).

Since 𝜀 is arbitrary, the proof of the representation property 1) is complete.

Step 7. For any E ∈B(Ω), for any 𝜀 > 0, there are a closed set C and an open set V such that C ⊂ E ⊂ V and μ(V ∖ C) < 𝜀.

Let E ∈B(Ω) and let (Kn) be an increasing sequence of compact sets whose union is Ω (take e.g. Kn := {x ∈Ω : |x|≤ n and dist(x, ℝN ∖Ω) ≥ 1∕n}). Since μ is a Radon measure, then μ(E ∩ Kn) < ∞ for all n ≥ 1, and there exists an open set V n such that E ∩ Kn ⊂ V n and

μ(V n) < λ(E ∩ Kn) + 2−n−1𝜀.

In particular, since μ(E ∩ Kn) < ∞, then

μ(V n ∖ (E ∩ Kn) < 2−n−1𝜀.

Define the open set

V := ⋃ n≥1V n,

which satisfies E ⊂ V , and

V ∖ E ⊂⋃ n≥1V n ∖ (E ∩ Kn).

Then we have

μ(V ∖ E) < 𝜀∕2. (14.9)

Moreover, applying this property to F := Ec, there exists an open set W containing F and such that

μ(W ∖ F) ≤ 𝜀∕2. (14.10)

Let C := Wc be closed, then C ⊂ E and

μ(E ∖ C) = μ(E ∩ W) = μ(W ∖ (Ec)) = μ(W ∖ F) < 𝜀∕2.

Therefore, combining (14.9) and (14.10), we arrive at the conclusion that for any E ∈B(Ω), for any 𝜀 > 0, there are a closed set C and an open set V such that C ⊂ E ⊂ V and μ(V ∖ C) < 𝜀. The proof of the theorem is now completed. □

We give a first application of the Riesz representation Theorem, which concerns the regularity of Radon measures. It will be useful to prove the density of continuous functions and the separability of Lebesgue spaces in Chapter 15.

Theorem 14.2 (Regularity theorem for Radon measures). Any positive Radon measure λ on Ω satisfies

λ(E) = inf ⁡{λ(V ) : E ⊂ V,V  open}for every Borel set E ⊂Ω,

and

λ(E) = sup ⁡{λ(K) : K ⊂ E,K compact}for every Borel set E ⊂Ω with λ(E) < ∞.

Moreover, for any E ∈B(Ω) and any 𝜀 > 0, there exists a closed set C and an open set V such that C ⊂ E ⊂ V , and

λ(V ∖ C) < 𝜀. (14.11)

Proof. Define

L(f) := ∫ Ωfdλ,

for any f ∈Cc(Ω). Since λ(K) < ∞ for any compact set K ⊂Ω, L is a positive linear form on Cc(Ω), and from the Riesz representation Theorem, there exists a unique Radon measure μ such that

∫ Ωfdλ = ∫ Ωfdμ.

Let V be an open subset of Ω. Then V = ⋃ ⁡ n=1∞K n for some compact sets Kn with n ∈ ℕ∗. By Urysohn’s lemma (Lemma 16.41 in the appendix), we can choose fn ∈Cc(V ; [0, 1]) such that fn = 1 on Kn. Define

gn := max ⁡ 1≤i≤nfi,

then gn ∈Cc(V ; [0, 1]) and it increasingly converges to 1V pointwise in Ω. Hence by the monotone convergence Theorem,

λ(V ) = lim ⁡ n→∞∫ Ωgndλ = lim ⁡ n→∞∫ Ωgndμ = μ(V ).

Now let E be a Borel subset of Ω and let 𝜀 > 0. By (14.3), there exists an open set V and a closed set C such that C ⊂ E ⊂ V and μ(V ∖ C) < 𝜀. But since V ∖ C is open we infer that λ(V ∖ C) < 𝜀. Consequently,

λ(E) ≤ λ(V ) = μ(V ) ≤ μ(E) + 𝜀 ≤ μ(V ) + 𝜀 = λ(V ) + 𝜀 ≤ λ(E) + 2𝜀,

so that μ(E) = λ(E) by the arbitrariness of 𝜀.

Therefore, the restriction of μ to the Borel sets matches with the given Radon measure λ, and since μ satisfies the desired regularity property by the Riesz representation theorem, we may now deduce Theorem 14.2. □

14.2 Lusin’s theorem

The regularity of Radon measures has an important consequence: on a set of arbitrarily large measure, a measurable function may be replaced by a continuous one.

Theorem 14.3 (Lusin theorem). Let μ be a positive Radon measure on Ω. Let E in B(Ω) be such that μ(E) < ∞, and let f : Ω → ℝ be a Borel measurable function. Then for every 𝜀 > 0, there exists a compact set K ⊂ E such that

μ(E ∖ K) < 𝜀

and the restriction f|K is continuous.

Proof. Step 1: indicator functions. Let A in B(Ω) and let η > 0. By Theorem 14.2, there exists a compact set F ⊂ A and an open set V such that

F ⊂ A ⊂ V,μ(V ∖ F) < η.

By Urysohn’s lemma (Lemma 16.41 in the appendix), there exists h ∈Cc(Ω; [0, 1]) such that h = 1 on F and h = 0 on Ω ∖ V . Hence

h = 1A

on Ω ∖ (V ∖ F).

Step 2: simple functions. Let

s = ∑ j=1mα j1Aj

be a simple Borel function on Ω, and let η > 0. Applying Step 1 to each set Aj with η∕m in place of η, we obtain functions hj ∈Cc(Ω) and Borel sets Nj ⊂Ω such that

μ(Nj) < η m,hj = 1Aj

on Ω ∖ Nj. If we define

g := ∑ j=1mα jhj,N := ⋃ j=1mN j,

then g belongs to Cc(Ω), μ(N) < η, and

g = s

on Ω ∖ N.

Step 3: bounded measurable functions. Assume now that f is bounded on E. Arguing as in the proof of Theorem 6.6, we can choose a sequence (sn)n≥1 of simple Borel functions such that

sup ⁡ x∈E|f(x) − sn(x)|≤ 2−n

for every n ≥ 1. Applying Step 2 with η = 2−n−2𝜀, we obtain gn ∈Cc(Ω) and a Borel set Nn ⊂Ω such that

μ(Nn) < 2−n−2𝜀,g n = sn

on Ω ∖ Nn. Let

F := E ∖⋃ n=1∞N n.

Then F is a Borel set and

μ(E ∖ F) ≤∑ n=1∞μ(N n) < 𝜀 2.

Moreover, for every x in F and every n ≥ 1, we have gn(x) = sn(x), so

sup ⁡ x∈F |f(x) − gn(x)|≤ 2−n.

Thus (gn)n≥1 converges uniformly to f on F. Since each gn is continuous on Ω, the restriction f|F is continuous. By Theorem 14.2 again, there exists a compact set K ⊂ F such that

μ(F ∖ K) < 𝜀 2.

Hence

μ(E ∖ K) ≤ μ(E ∖ F) + μ(F ∖ K) < 𝜀,

and f|K is continuous.

Step 4: the general case. For every M > 0, we define

EM := E ∩{|f|≤ M}.

Since f is finite-valued, the sequence (EM)M≥1 is increasing and its union is E. Because μ(E) < ∞, continuity from below gives

μ(E ∖ EM) → 0as M → +∞.

We fix M so large that

μ(E ∖ EM) < 𝜀 2.

The function f is bounded on EM, so Step 3 yields a compact set K ⊂ EM such that

μ(EM ∖ K) < 𝜀 2

and f|K is continuous. Therefore

μ(E ∖ K) ≤ μ(E ∖ EM) + μ(EM ∖ K) < 𝜀.

This concludes the proof. □

14.3 Construction of the Lebesgue measure

The Riesz representation Theorem enables one to prove the existence of the Lebesgue measure, and to prove that the Lebesgue integral with respect to the Lebesgue measure is a natural extension of the Riemann integral. Let us recall that, by definition, a Fσ is a countable union of closed sets and a Gδ is a countable intersection of open sets.

Theorem 14.4 (Existence and regularity theorem for Lebesgue measure). There exists a σ-algebra L(ℝN) (containing the Borel σ-algebra B(ℝN)) and a unique measure λN on L(ℝN) such that

1.
λN([0, 1]N) = 1;
2.
For every E ∈L(ℝN) and every x ∈ ℝN, λN(x + E) = λN(E);
3.
E ∈L(ℝN) if and only if there exists a Fσ set A and a Gδ set B such that A ⊂ E ⊂ B and λN(B ∖ A) = 0;
4.
For every f ∈Cc(ℝN),
∫ ℝNfdλN = ∫ ℝNf(x)dx,

where the integral in left hand side is the Lebesgue integral of f with respect to the measure λN, and the integral in the right hand side is the Riemann integral of f.

The restriction of λN to B(ℝN) is the Borel Lebesgue measure. Its completion on L(ℝN) is called the Lebesgue measure, and L(ℝN) is called the Lebesgue σ-algebra; its elements are the Lebesgue measurable sets.

Proof. Step 1. Define L : Cc(ℝN) → ℝ by

L(f) = ∫ ℝNf(x)dx,

where the integral is the Riemann integral of f. Note that since f has compact support, then the previous integral is not improper since

∫ ℝNf(x)dx = ∫ supp(f)f(x)dx.

Clearly L is a positive linear functional on Cc(ℝN), and according to the Riesz representation Theorem, there exist a σ-algebra L(ℝN) (containing the Borel σ-algebra B(ℝN)) and a measure λN on L(ℝN) such that λN(K) < ∞ for every compact set K ⊂ ℝN and

L(f) = ∫ ℝNf(x)dx = ∫ ℝNfdλN

for every f ∈Cc(ℝN).

Step 2. The conclusion of Theorem 14.1 also proves that for any E ∈L(ℝN)

λN(E) = inf ⁡{λN(V ) : E ⊂ V,V  open} (14.12)

and any E ∈L(ℝN) with λN(E) < ∞

λN(E) = sup ⁡{λN(K) : K ⊂ E,K compact}.

Moreover, from (14.3), for every E ∈L(ℝN) and any 𝜀 > 0, there exists a closed set C and an open set V such that C ⊂ E ⊂ V and λN(V ∖ C) < 𝜀. Hence, for each n ≥ 1, one can find a closed set Cn and an open set V n such that

Cn ⊂ E ⊂ V n, and λN(V n ∖ Cn) < 1∕n.

Define

A := ⋃ n≥1Cn and B := ⋂ n≥1V n.

Then A is a Fσ set, B is a Gδ set, A ⊂ E ⊂ B and

λN(B ∖ A) ≤ λN(V n ∖ Cn) < 1∕n → 0as n → +∞.

Conversely, assume that E ⊂ ℝN is such that A ⊂ E ⊂ B and λN(B ∖ A) = 0 for some Fσ set A and some Gδ set B. Then E = A ∪ (E ∖ A) where A ∈B(ℝN) and E ∖ A ⊂ B ∖ A with B ∖ A ∈B(ℝN) and λN(B ∖ A) = 0. Since the measure λN is complete, we deduce that E ∖ A ∈L(ℝN) and finally that E ∈L(ℝN).

Step 3. Let us prove that for every open cartesian product

Q := ∏ i=1N(a i,bi)

(for ai < bi and i ∈{1,…,N}), then

λN(Q) = ∏ i=1N(b i − ai). (14.13)

Define for each n ≥ 1 and each x ∈ ℝN,

fn(x) := ∏ i=1Nφ nai,bi (xi),

where

φnai,bi (xi) := { 0 if xi∉[ai,bi], 1 if xi ∈ [ai + 1 n,bi −1 n ] , n(xi − ai) if xi ∈ [ai,ai + 1 n ] , − n(xi − bi) if xi ∈ [bi −1 n,bi] .

Then fn ∈Cc(ℝN) for all n ≥ 1 and 1Q n¯ ≤ fn ≤1Q where

Qn¯ := ∏ i=1N[a i + 1∕n,bi − 1∕n]

is a closed cube. Hence integrating the previous chain of inequalities with respect to the Lebesgue measure λN leads to

λN(Qn¯) ≤∫ ℝNfndλN = ∫ ℝNfn(x)dx ≤ λN(Q). (14.14)

Since Qn¯ is an increasing sequence of (Lebesgue) measurable sets whose union is Q = ∏ ⁡ i=1N(a i,bi), we deduce from the properties of positive measures that λN(Qn¯) → λN(Q) as n → +∞. Next by construction of fn, its Riemann integral can be exactly computed as

∫ ℝNfn(x)dx = ∫ Qfn(x)dx = ∏ i=1N ∫ aibi φnai,bi (xi)dxi = ∏ i=1N (b i − ai −1 n ).

Taking the limit in 14.14 as n →∞ yields formula 14.13.

Step 4. Let us prove that for any i ∈{1,…,N} and any a ∈ ℝ,

λN({xi = a}) = 0. (14.15)

Let us assume without loss of generality that i = 1 and a = 0. Then for each k ≥ 1, we have

{x1 = 0}∩ Q(0,n) ⊂ (−1∕k, 1∕k) ×∏ i=2N(−n,n)

where Q(0,n) = ∏ ⁡ i=1N(−n,n) is the open cube of center 0 and side length 2n. Using (14.13), we infer that

λN({x1 = 0}∩ Q(0,n)) ≤ 2 k(2n)N−1.

For fixed n ≥ 1, letting k → +∞ implies that

λN({x1 = 0}∩ Q(0,n)) = 0.

Then taking the limit as n →∞ and using the properties of positive measures yields λN({x1 = 0}) = 0.

Step 5. Since

∏ i=1N[a i,bi] ∖∏ i=1N(a i,bi)

is made of finitely many subsets of hyperplane of the form {xi = a}, we deduce from Step 4 that

λN (∏ i=1N[a i,bi] ∖∏ i=1N(a i,bi)) = 0

so that

λN (∏ i=1N[a i,bi]) = λN (∏ i=1N(a i,bi)) = ∏ i=1N(b i − ai).

In particular, taking ai = 0 and bi = 1 for all i ∈{1,…,N} leads to λN([0, 1]N) = 1.

Step 6. Let us prove that λN is translation invariant. Let x ∈ ℝN and V ⊂ ℝN an open set. Since the translation τx : y ∈ ℝN↦x + y is a homeomorphism (with inverse (τx)−1 = τ −x), then x + V is open, and by definition of λN on open sets (see (14.4)) we have

λN(x + V ) = sup ⁡ {∫ ℝNf(y)dy : f ∈Cc(ℝN; [0, 1]),supp(f) ⊂ x + V }.

By changing variables in the Riemann integral we obtain that

λN(x + V ) = sup ⁡ {∫ ℝNg(x + y)dy : g ∈Cc(ℝN; [0, 1]),supp(g) ⊂ V } = sup ⁡ {∫ ℝNg(z)dz : g ∈Cc(ℝN; [0, 1]),supp(g) ⊂ V } = λN(V ).

Next from the above mentioned properties of the translation, if E ∈B(ℝN), then x + E ∈B(ℝN). Applying the outer regularity (14.12) of the Lebesgue measure, we get that

λN(x + E) = inf ⁡{λN(V ) : x + E ⊂ V,V  open} = inf ⁡{λN(−x + V ) : E ⊂−x + V,V  open} = inf ⁡{λN(U) : E ⊂ U,U open} = λN(E).

Finally, from step 2, we know that if E ∈L(ℝN) then there exists a Fσ set A, and a Gδ set B such that A ⊂ E ⊂ B and λN(B ∖ A) = 0. Then

x + A ⊂ x + E ⊂ x + B,

where x + A is a Fσ and x + B is a Gδ. Moreover, since

(x + B) ∖ (x + A) = x + (B ∖ A)

and B ∖ A ∈B(ℝN), then

λN((x + B) ∖ (x + A)) = λN(x + (B ∖ A)) = λN(B ∖ A) = 0.

Consequently, x + E ∈L(ℝN) and

λN(x + E) = λN(x + A) = λN(A) = λN(E).

Step 7. It remains to prove uniqueness. Let ν be a translation invariant Radon measure on (ℝN,B(ℝN)) such that ν([0, 1]N) = 1. We claim that ν = λN on B(ℝN).

We first prove that for every i ∈{1,…,N} and every a ∈ ℝ,

ν({xi = a}) = 0.

By translation invariance it is enough to consider the case i = 1 and a = 0. Let e1 := (1, 0,…, 0) and, for m ≥ 1, set

Hm := {0}× [−m,m]N−1.

If F ⊂ ℚ ∩ [0, 1] is finite, then the translates (qe1 + Hm)q∈F are pairwise disjoint and all contained in the compact set [0, 1] × [−m,m]N−1. Hence

|F|ν(Hm) = ∑ q∈F ν(qe1+Hm) = ν (⋃ q∈F (qe1+Hm) ) ≤ ν([0, 1]×[−m,m]N−1) < ∞.

Since F can have arbitrarily large cardinality, we obtain ν(Hm) = 0. Because

{x1 = 0} = ⋃ m=1∞H m,

continuity from below yields ν({x1 = 0}) = 0, and the general statement follows by translation invariance.

As a consequence, the boundary of every axis-parallel rectangle has ν-measure 0. In particular,

ν([0, 1)N) = ν([0, 1]N) = 1.

Fix n ≥ 1. The half-open cube [0, 1)N is the disjoint union of the nN translates

k n + [0, 1∕n)N,k ∈{0,…,n − 1}N.

By translation invariance,

1 = ν([0, 1)N) = nNν([0, 1∕n)N),

so that

ν([0, 1∕n)N) = n−N.

Therefore, if

R = ∏ i=1N[a i,bi)

has rational endpoints, then after choosing n large enough so that ai,bi ∈ n−1ℤ for every i, the rectangle R is a finite disjoint union of translates of [0, 1∕n)N. Hence

ν(R) = ∏ i=1N(b i − ai).

By Steps 4 and 5, the same formula holds for λN. Thus ν and λN coincide on every half-open rectangle with rational endpoints.

For every integer m ≥ 1, we set

Qm := [−m,m)N

and denote by Pm the family of all half-open rectangles with rational endpoints contained in Qm. This is a π-system on Qm, it generates B(Qm), and the restrictions of ν and λN to B(Qm) are finite measures which coincide on Pm. Corollary 3.12 therefore implies that

ν(E) = λN(E)

for every Borel set E ⊂ Qm. Finally, if E ∈B(ℝN), then E ∩ Qm ↑ E as m →∞, so continuity from below gives

ν(E) = lim ⁡ m→∞ν(E ∩ Qm) = lim ⁡ m→∞λN(E ∩ Qm) = λN(E).

This proves the uniqueness of the Borel Lebesgue measure. Since Step 2 shows that L(ℝN) is exactly the completion of B(ℝN) with respect to λN, the complete extension is unique as well. □

14.4 Complement: measure-theoretic extension of the multidimensional change-of-variables formula

We now complement Theorem 13.21 by extending the formula from Cc(V ) to nonnegative Borel functions and then to all integrable functions. The measure introduced below is the multidimensional analogue of the transport measure used in Lemma 13.13 in the one-dimensional proof.

Lemma 14.5 (Transport Radon measure associated with a diffeomorphism). Let d ≥ 1, let U and V be open sets of ℝd, and let φ: U → V be a diffeomorphism of class C1. For every E in B(V ), define

ν(E) := ∫ φ−1(E)|Jacφ(x)|dx.

Then ν is a positive Radon measure on V . Moreover, for every nonnegative Borel function g on V ,

∫ V gdν = ∫ Ug(φ(x))|Jacφ(x)|dx.

Proof. For every Borel set E ⊂ V , the set φ−1(E) is Borel in U, because φ is continuous. Hence ν(E) is well defined in [0, +∞]. If (En)n≥1 is a pairwise disjoint sequence in B(V ), then the sets φ−1(E n) are pairwise disjoint and

1φ−1(∪n≥1En)|Jacφ| = ∑ n=1∞1 φ−1(En)|Jacφ|.

Corollary 7.4 therefore gives

ν (⋃ n=1∞E n) = ∑ n=1∞ν(E n),

so ν is a positive Borel measure on V .

Let K be a compact subset of V . Since φ is a homeomorphism, φ−1(K) is a compact subset of U. The function |Jacφ| is continuous, hence bounded on φ−1(K). Therefore

ν(K) = ∫ φ−1(K)|Jacφ(x)|dx < +∞,

because compact subsets of ℝd have finite Lebesgue measure. Thus ν is a positive Radon measure in the sense of Definition 2.8.

The integral identity holds first for indicator functions by the definition of ν. By finite linearity it holds for nonnegative simple Borel functions. For a general nonnegative Borel function g, choose simple functions gn ↑ g and apply the monotone convergence theorem, Theorem 7.1, to both sides. □

Corollary 14.6 (Change of variables for Radon measures). Let d ≥ 1, let U and V be open sets of ℝd, and let φ: U → V be a diffeomorphism of class C1. Then, for every nonnegative Borel function f on V ,

∫ V f(y)dy = ∫ Uf(φ(x))|Jacφ(x)|dx.

The same identity also holds for every f in L1(V ).

Proof. Let ν be the measure from Lemma 14.5. For every g in Cc(V ), that lemma gives

∫ V gdν = ∫ Ug(φ(x))|Jacφ(x)|dx.

By Theorem 13.21, the right-hand side is equal to

∫ V g(y)dy.

Thus ν and λd define the same positive linear functional on Cc(V ). Since both measures are positive Radon measures on V , Theorem 14.2 gives the outer and inner regularity assumptions required in the uniqueness statement of the Riesz representation theorem, Theorem 14.1. Hence ν = λd on B(V ). For every nonnegative Borel function f on V , Lemma 14.5 then gives

∫ V f(y)dy = ∫ V fdν = ∫ Uf(φ(x))|Jacφ(x)|dx.

If f belongs to L1(V ), apply this identity to f+ and f−. □

Corollary 14.7 (Linear change of variables). Let A: ℝd → ℝd be an invertible linear map. Then, for every nonnegative Borel function f on ℝd,

∫ ℝdf(y)dy = ∫ ℝdf(Ax)| det ⁡ A|dx.

The same identity also holds for every f in L1(ℝd).

Proof. Apply Corollary 14.6 to the C1 diffeomorphism φ = A. □

Example 14.8 (Volume of an ellipsoid). Let A be an invertible linear map on ℝd, let

B := {x ∈ ℝd : |x| < 1},E := A(B).

Then E is an ellipsoid. Applying Corollary 14.7 to the integrable function 1E, we obtain

λd(E) = ∫ ℝd1E(y)dλd(y) = ∫ ℝd1E(Ax)| det ⁡ A|dλd(x) = | det ⁡ A|∫ B1dλd(x) = | det ⁡ A|λd(B).

In particular, if Q is a symmetric positive definite matrix and

EQ := {x ∈ ℝd : x ⋅ Qx < 1},

then there exists an invertible matrix S such that Q = ST S. The set EQ is the preceding ellipsoid with

A = S−1,E Q = S−1(B),

and therefore

λd(EQ) = λd(B) | det ⁡ S| = λd(B) det ⁡ Q.

For example, in dimension 2, the ellipse

x12 a2 + x22 b2 < 1

has area πab. In dimension 3, the ellipsoid

x12 a2 + x22 b2 + x32 c2 < 1

has volume 4πabc∕3.

14.5 Bounded Radon measures

So far, most measures in the notes have been positive. We now use the signed-measure formalism from Section 2.6, in particular the total variation measure, in the topological setting of Radon measures. We first recall that C0(Ω) is defined, for any open subset Ω ⊂ ℝN, as the closure of the space Cc(Ω) for the uniform topology. Its characterization by functions vanishing at infinity will be given later in Proposition 16.43 of the appendix.

Definition 14.9 (Bounded signed Radon measures). A finite signed Borel measure λ on Ω is called a bounded signed Radon measure if its total variation |λ| is a positive Radon measure and

|λ|(Ω) < +∞.

We denote by M(Ω) the vector space of bounded signed Radon measures on Ω, endowed with the norm

∥λ∥M(Ω) := |λ|(Ω).

The next result identifies M(Ω) with the dual space of C0(Ω). The equality between the operator norm and the total variation is the reason why the total variation is the natural norm on signed Radon measures.

Theorem 14.10 (Riesz–Markov representation theorem for bounded Radon measures). For every continuous linear functional L ∈C0(Ω)′, there exists a unique bounded signed Radon measure λ ∈M(Ω) such that

L(u) = ∫ Ωudλ

for every u ∈C0(Ω). Moreover,

∥L∥C0(Ω)′ = |λ|(Ω) = ∥λ∥M(Ω).

Proof. Step 1. Construction of the positive and negative parts of the functional. We construct two positive continuous linear forms L+ and L− on C0(Ω) such that L = L+ − L−. Let

C+ := {u ∈C 0(Ω) : u ≥ 0}.

For u ∈C+, define

L+(u) := sup ⁡{L(v) : v ∈C+,0 ≤ v ≤ u}.

This number is finite, and

0 ≤ L+(u) ≤∥L∥∥u∥ ∞.

We first prove that L+ is positively homogeneous on C+. If a ≥ 0 and u ∈C+, then, for a > 0, the competitors 0 ≤ v ≤ au are exactly the functions v = aw with 0 ≤ w ≤ u, and the case a = 0 is immediate. Hence

L+(au) = aL+(u).

We next prove additivity on C+. Let u1,u2 be in C+. If 0 ≤ vi ≤ ui for i = 1, 2, then 0 ≤ v1 + v2 ≤ u1 + u2, and therefore

L+(u 1 + u2) ≥ L(v1 + v2) = L(v1) + L(v2).

Taking the supremum in v1 and v2 gives

L+(u 1 + u2) ≥ L+(u 1) + L+(u 2).

Conversely, let v be in C+ and satisfy 0 ≤ v ≤ u1 + u2. Set

v1 := min ⁡(u1,v),v2 := v − v1 = max ⁡(v − u1, 0).

Then v1,v2 belong to C+, with v1 ≤ u1 and v2 ≤ u2, and v = v1 + v2. Hence

L(v) = L(v1) + L(v2) ≤ L+(u 1) + L+(u 2).

Taking the supremum in v gives the reverse inequality. Thus L+ is additive on the positive cone.

We extend L+ to C0(Ω) as follows. If u = p − q with p,q in C+, set

L+(u) := L+(p) − L+(q).

This is well defined. Indeed, if p − q = p′− q′ with p,q,p′,q′ in C+, then p + q′ = p′ + q, and additivity on C+ gives

L+(p) + L+(q′) = L+(p′) + L+(q).

The extension is linear by construction, and it is positive because it coincides with the original L+ on C+. Moreover, if u ∈C0(Ω), then

|L+(u)|≤ L+(u+) + L+(u−) ≤ 2∥L∥∥u∥ ∞,

so L+ is continuous. Finally define

L− := L+ − L.

For u ∈C+, the function u itself is an admissible competitor in the definition of L+(u), so L+(u) ≥ L(u). Hence L− is positive. It is continuous as a difference of continuous linear forms, and L = L+ − L−.

Step 2. Representation by finite positive Radon measures. By applying the positive Riesz representation theorem, Theorem 14.1, to the restrictions of L+ and L− to Cc(Ω), we obtain positive Radon measures λ+ and λ− such that

L±(u) = ∫ Ωudλ±

for every u ∈Cc(Ω). We first check that these measures are finite. For every compact set K ⊂Ω, Urysohn’s lemma, Lemma 16.41, gives uK ∈Cc(Ω) with 0 ≤ uK ≤ 1 and uK = 1 on K, hence

λ±(K) ≤ L±(u K) ≤∥L±∥.

By inner regularity on the open set Ω, λ±(Ω) ≤∥L±∥ < +∞. Since λ± are finite and Cc(Ω) is dense in C0(Ω) for the uniform norm, the identities above extend to every u ∈C0(Ω). Set

λ := λ+ − λ−.

Then λ is a finite signed Borel measure. Moreover, by the partition formula for total variation, Proposition 2.27, for every Borel set E ⊂Ω we have

|λ|(E) ≤ λ+(E) + λ−(E).

In particular,

|λ|(Ω) ≤ λ+(Ω) + λ−(Ω) < +∞.

Thus |λ| is finite on compact subsets of Ω, hence it is a positive Radon measure in the sense of Definition 2.8. Therefore λ is a bounded signed Radon measure. Finally,

L(u) = ∫ Ωudλ

for every u ∈C0(Ω).

Step 3. Verification of the norm identity. The argument below applies to any bounded signed Radon measure which represents L. For every u ∈C0(Ω),

|L(u)|≤∫ Ω|u|d|λ|≤∥u∥∞|λ|(Ω),

so

∥L∥C0(Ω)′ ≤|λ|(Ω).

For the reverse inequality, let (P,N) be a Hahn decomposition for λ. Since |λ| is a finite Radon measure, the regularity theorem for Radon measures, Theorem 14.2, gives, for every 𝜀 > 0, compact sets

K+ ⊂ P,K− ⊂ N

such that

|λ|(Ω ∖ (K+ ∪ K−)) < 𝜀.

By Urysohn’s lemma, Lemma 16.41, there exists u ∈Cc(Ω) with ∥u∥∞ ≤ 1, u = 1 on K+, and u = −1 on K−. Then

L(u) = ∫ Ωudλ ≥|λ|(K+ ∪ K−) −|λ|(Ω ∖ (K+ ∪ K−)) ≥|λ|(Ω) − 2𝜀.

Taking the supremum over all u with ∥u∥∞ ≤ 1 and then letting 𝜀 → 0 gives

∥L∥C0(Ω)′ ≥|λ|(Ω).

Thus the norms are equal.

Step 4. Uniqueness. Finally, if two bounded signed Radon measures represent the same functional, their difference represents the zero functional. Applying the norm identity to this difference gives total variation 0, hence the two measures are equal. □

Example 14.11 (Finite atomic signed Radon measures). Let x1,…,xm be points of Ω, and let a1,…,am be real numbers. We define, for every u in C0(Ω),

L(u) := ∑ j=1ma ju(xj).

Then L is a continuous linear form on C0(Ω), and Theorem 14.10 represents it by an element of M(Ω). The corresponding bounded Radon measure is

λ = ∑ j=1ma jδxj,

because

∫ Ωudλ = ∑ j=1ma ju(xj)

for every u in C0(Ω). In particular, the Dirac mass δx0 at a point x0 in Ω is the bounded Radon measure characterized by

∫ Ωudδx0 = u(x0)for every u ∈C0(Ω).

14.6 Weak convergences

Because of the Riesz representation theorem for bounded Radon measures, Theorem 14.10, we identify M(Ω) with C0(Ω)′ and write the action of a bounded signed Radon measure ν on a test function u as

ν(u) = ∫ Ωudν.

Definition 14.12 (Weak-* convergence of bounded Radon measures). We say that a sequence (λn) ⊂M(Ω) converges weak∗ to λ in M(Ω) if for any v in C0(Ω),

∫ Ωvdλn →∫ Ωvdλ as n →∞.

A proof of the separability of the space C0(Ω) for the sup norm is given later in Proposition 16.44 of the appendix. Once this is known, the sequential Banach–Alaoglu theorem from the appendix (Theorem 16.58) implies that any bounded sequence of bounded Radon measures has a subsequence which converges weak∗ to a bounded Radon measure.

Theorem 14.13 (Weak-star sequential compactness theorem for bounded Radon measures). Let Ω be an open subset of ℝN and let (λn)n be a bounded sequence in M(Ω). Then there is a subsequence (λnk)k≥1 converging weak∗ to a bounded Radon measure λ.

Proof. By Proposition 16.44 of the appendix, the Banach space C0(Ω) is separable for the uniform norm. The sequential Banach–Alaoglu theorem from the appendix (Theorem 16.58) therefore applies to the dual space (C0(Ω))′ and yields a weak∗ convergent subsequence. By the Riesz representation theorem for bounded Radon measures (Theorem 14.10), M(Ω) is isometrically identified with (C0(Ω))′. Transporting the weak∗ convergence through this identification gives the conclusion. □

If μ is a positive Radon measure, we observe that the space L1(Ω,μ) can be injected into M(Ω) through the map

u ∈ L1(Ω,μ)↦Tu ∈M(Ω),

with

Tu : v ∈C0(Ω)↦∫ Ωuvdμ.

As a consequence, if (un) is a uniformly bounded sequence in L1(Ω,μ), then one can extract a subsequence which converges weak∗ in M(Ω) to a bounded Radon measure, i.e., there exist (unk) ⊂ (un) and λ ∈M(Ω) such that for every v ∈C0(Ω),

∫ Ωunkvdμ →∫ Ωvdλas k → +∞.

However, one may wonder if the limit λ ∈M(Ω) is also of the form Tu, with u in L1(Ω,μ). This leads to the following notion, which is induced by the embedding of L1(Ω,μ) into M(Ω).

Definition 14.14 (Weak-* convergence in C0(Ω)′). Let μ be a positive Radon measure. We say that a sequence (un)n in L1(Ω,μ) converges to u against C0(Ω) test functions if for every v in C0(Ω),

∫ Ωunvdμ →∫ Ωuvdμ as n →∞.

It is straightforward that strong convergence in L1(Ω,μ) implies convergence against C0(Ω) test functions. The genuine weak topology of the Banach space L1(Ω,μ) will be introduced later, in Section 15.7, once the dual of L1(Ω,μ) has been identified with L∞(Ω,μ). On finite-measure spaces, the corresponding compactness criterion is the compactness part of the Dunford–Pettis theorem, which will also be stated there.
