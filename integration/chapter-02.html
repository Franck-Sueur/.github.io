Chapter 2
Measures

We now equip measurable spaces with countably additive set functions. After establishing the basic calculus of measures, we introduce negligible sets, completion, and regularity notions, and we conclude with a first look at the Lebesgue measure, which will remain the model example throughout the course.

2.1 First definitions

Definition 2.1 (Measures). Let (X,A) be a measurable space. A measure on (X,A) is a map μ: A → [0,∞] verifying:

1.
μ(∅) = 0,
2.
for every sequence (Ai)i≥1 of pairwise disjoint elements of A, we have
μ (⋃ i=1∞A i) = ∑ i=1∞μ(A i).

A measure space is a triple (X,A,μ) where (X,A) is a measurable space and μ is a measure on (X,A).

The following picture illustrates that a measure assigns a value in [0, +∞] to each measurable set.

Let us look at a few examples.

  • Firstly, (ℕ,P(ℕ)) is a measurable space, corresponding to the case of the so-called discrete σ-algebra. The counting measure is defined by

    #(A) = card ⁡(A)

    when A is finite, and by #(A) = +∞ when A is infinite. It is a measure on (ℕ,P(ℕ)).

  • Let (X,A) be a measurable space, and let x0 be in X. We define δx0 : A → [0,∞] by δx0(A) = 1 if x0 is in A and δx0(A) = 0, otherwise. The map δx0 is a measure, called the Dirac measure at x0.

2.2 Main properties

We now give the main properties of measures.

Theorem 2.2 (Basic properties of measures). Let (X,A,μ) be a measure space.

1.
Let n in ℕ≥1 and let A1,…,An be pairwise disjoint elements of A. Then
μ (⋃ i=1nA i ) = ∑ i=1nμ(A i).
2.
If B1,…,Bn are elements of A, then
μ (⋃ i=1nB i ) ≤∑ i=1nμ(B i).
3.
Let A,B in A such that A ⊂ B. Then μ(A) ≤ μ(B).
4.
If (Bi)i≥1 is a sequence of elements of A, then
μ (⋃ i=1∞B i) ≤∑ i=1∞μ(B i).

Proof.

1.
We complete the family by setting Ai = ∅ for i ≥ n + 1. The sequence (Ai)i≥1 is pairwise disjoint, so countable additivity gives
μ (⋃ i=1nA i ) = μ (⋃ i≥1Ai ) = ∑ i≥1μ(Ai) = ∑ i=1nμ(A i).
2.
We introduce an auxiliary family (Ci)1≤i≤n by setting
C1 := B1,Ci := Bi ∖⋃ j=1i−1B j,(2 ≤ i ≤ n).

Then each Ci is in A, the sets Ci are pairwise disjoint, and

⋃ i=1nB i = ⋃ i=1nC i.

Therefore, by 1),

μ (⋃ i=1nB i ) = μ (⋃ i=1nC i ) = ∑ i=1nμ(C i).

Moreover, for i = 1 we have μ(C1) = μ(B1). For i ≥ 2, we have Ci ⊂ Bi and

Bi = Ci ∪ (Bi ∩⋃ j=1i−1B j ),

where the union is disjoint. Another application of 1) therefore gives

μ(Bi) = μ(Ci) + μ (Bi ∩⋃ j=1i−1B j ) ≥ μ(Ci).

By summing over i we conclude that

μ (⋃ i=1nB i ) = ∑ i=1nμ(C i) ≤∑ i=1nμ(B i).
3.
Since B ∖ A is in A and
B = A ∪ (B ∖ A),

with a disjoint union, 1) gives

μ(B) = μ(A) + μ(B ∖ A) ≥ μ(A).
4.
Define
C1 := B1,Ci := Bi ∖⋃ j=1i−1B j(i ≥ 2).

Then the sets Ci are pairwise disjoint, Ci ⊂ Bi, and ⋃ ⁡ i≥1Bi = ⋃ i≥1Ci. By countable additivity and monotonicity,

μ (⋃ i=1∞B i) = ∑ i=1∞μ(C i) ≤∑ i=1∞μ(B i).
□

One should pay attention to the lack of symmetry in the assumptions of the following couple of results.

Theorem 2.3 (Continuity properties of measures). Let (X,A,μ) be a measure space.

1.
Let (Ai)i≥1 be an increasing sequence of elements of A (i.e. Ai ⊂ Ai+1 for all i), then the sequence (μ(Ai))i converges in [0,∞] and
lim ⁡ N→∞μ(AN) = μ (⋃ i≥1Ai ).
2.
Let (Ai)i≥1 be a decreasing sequence of elements of A (i.e. Ai+1 ⊂ Ai for all i), then the sequence (μ(Ai))i converges in [0,∞]. Moreover, if there exists i0 ≥ 1 such that μ(Ai0) < ∞, then
lim ⁡ i→∞μ(Ai) = μ (⋂ i≥1Ai ).

Proof.

1.
Step 1. Increasing sequences. The convergence of (μ(Ai))i is justified by its growth in [0,∞]. We will associate an auxiliary sequence (Bi)i≥1 with the sequence (Ai)i≥1 as follows: set B1 = A1, and Bi = Ai ∖ Ai−1, if i ≥ 2. We see that Bi are elements of A and that by construction AN is the disjoint union of Bk for 1 ≤ k ≤ N, so that
∑ k=1Nμ(B k) = μ(AN).

Finally,

⋃ i≥1Ai = ⋃ k≥1Bk.

Therefore

μ (⋃ i≥1Ai ) = μ (⋃ k≥1Bk ) = ∑ k≥1μ(Bk) = lim ⁡ N→∞∑ k=1Nμ(B k) = lim ⁡ N→∞μ(AN).
2.
Step 2. Decreasing sequences. Replacing the sequence by the tail (Ai0+k)k≥0, one may suppose that i0 = 1. We set
A := ⋂ i≥1Ai,Ci := Ai ∖ Ai+1,(i ≥ 1).

Then A ∈A and Ci ∈A for all i. We claim that, for every n ≥ 1,

An = A ∪ (⋃ i≥nCi ).

Let us prove this equality carefully. If x is in A, then x is in An. If x is in Ci for some i ≥ n, then x is in Ai, and since the sequence (Ai)i is decreasing we have Ai ⊂ An. Therefore

A ∪ (⋃ i≥nCi ) ⊂ An.

Conversely, let x be in An. If x is in A, there is nothing to prove. Assume that x is not in A. Since A = ⋂ ⁡ i≥1Ai, there exists j ≥ 1 such that x∉Aj. Because the sequence is decreasing and x ∈ An, necessarily j > n. Hence the set

Ix := {i ≥ n: x ∈ Ai}

is nonempty and bounded above by j − 1, so it admits a largest element p. We then have x ∈ Ap and x∉Ap+1, therefore x ∈ Cp with p ≥ n. This proves the reverse inclusion, and therefore the desired equality.

We now check that the union is disjoint. For every i ≥ 1, we have A ⊂ Ai+1 and Ci ⊂ Ai ∖ Ai+1, hence A ∩ Ci = ∅. Moreover, if n ≤ i < j, then Cj ⊂ Aj ⊂ Ai+1, whereas Ci ⊂ Ai ∖ Ai+1, so Ci ∩ Cj = ∅. Therefore countable additivity yields

μ(An) = μ(A) + ∑ i≥nμ(Ci),(n ≥ 1). (2.1)

We have A ⊂ A1 and μ(A1) < ∞. Since A ⊂ A1 and μ(A1) < ∞, equality (2.1) for n = 1 proves that

∑ i≥1μ(Ci) = μ(A1) − μ(A) < ∞.

Therefore the sequence of remainders

( ∑ i≥nμ(Ci) )n

converges to 0. Letting n → +∞ in (2.1), we obtain

μ(An) → μ(A)as n → +∞.
□

Remark.  The necessity of the assumption μ(A1) < ∞ in (2) above can be seen on the measurable space (ℕ,P(ℕ)) equipped with the counting measure #. If

An := {n,n + 1,n + 2,…},

then An ↓∅ and #(An) = +∞ for every n ≥ 1, whereas #(∅) = 0.

2.3 Negligible sets, completion and regularity notions

Before turning to the Lebesgue measure itself, we introduce a few notions that will be used repeatedly in the sequel.

Definition 2.4 (Negligible sets). Let (X,A,μ) be a measure space.

1.
A subset N ⊂ X is said to be μ-negligible if there exists M in A such that N ⊂ M and μ(M) = 0.
2.
If P is a property depending on x in X, we say that P holds μ-almost everywhere if the set of points where P fails is μ-negligible.
3.
The measure space (X,A,μ) is said to be complete if every μ-negligible set belongs to A.

Remark. If we only ask N itself to be measurable and of measure 0, then we recover the usual notion of null set. The formulation above is slightly more flexible, and on a complete measure space the two points of view coincide.

Proposition 2.5 (Countable unions of negligible sets). Let (X,A,μ) be a measure space. Then every countable union of μ-negligible sets is again μ-negligible.

Proof. Let (Ni)i≥1 be a sequence of μ-negligible sets. For each i ≥ 1, there exists Mi in A such that Ni ⊂ Mi and μ(Mi) = 0. Then ⋃ ⁡ i≥1Mi is in A and

μ (⋃ i≥1Mi ) ≤∑ i≥1μ(Mi) = 0.

Hence μ(⋃ ⁡ i≥1Mi) = 0, and since

⋃ i≥1Ni ⊂⋃ i≥1Mi,

the set ⋃ ⁡ i≥1Ni is μ-negligible. □

Remark. If Pn holds μ-almost everywhere on X for every n ≥ 1, then the conjunction

∀ ⁡n ≥ 1,Pn

is again true μ-almost everywhere. Indeed, we only have to remove the countable union of the exceptional negligible sets.

Remark. Later on, the Lebesgue measure initially considered on the Borel σ-algebra will provide a standard example of a measure which is not complete. Passing to the completion is therefore a natural operation.

Proposition 2.6 (Completion of a measure). Let (X,A,μ) be a measure space. We set

A¯ := {A ∪ N : A ∈A,∃ ⁡M ∈A,N ⊂ M,μ(M) = 0 }.

For E = A ∪ N in A¯, we define

μ¯(E) := μ(A).

Then A¯ is a σ-algebra on X, the mapping μ¯ is a measure on A¯, the measure space (X,A¯,μ¯) is complete, and μ¯ extends μ.

Proof. Step 1. Well-definedness of the measure. We first check that μ¯ is well defined. Assume that

A ∪ N = A′∪ N′,

with A,A′ in A, N ⊂ M, N′ ⊂ M′, M,M′ in A, and

μ(M) = μ(M′) = 0.

Then

A ∖ A′ ⊂ M′

because every point of A ∖ A′ belongs to A ∪ N = A′∪ N′ and cannot belong to A′, hence belongs to N′ ⊂ M′. Therefore μ(A ∖ A′) = 0. Since

A = (A ∖ A′) ∪ (A ∩ A′)

is a disjoint union, we obtain μ(A) = μ(A ∩ A′) ≤ μ(A′). By symmetry, μ(A′) ≤ μ(A), hence μ(A) = μ(A′).

Step 2. The completed σ-algebra. We now prove that A¯ is a σ-algebra. We have X = X ∪∅, so X is in A¯. Let E = A ∪ N be in A¯, with N ⊂ M, M in A, and μ(M) = 0. Since N ⊂ M, we have

Ec = (A ∪ N)c = Ac ∩ Nc = (Ac ∖ M) ∪ (Ac ∩ (M ∖ N) ).

The set Ac ∖ M is in A, whereas Ac ∩ (M ∖ N) ⊂ M. Hence Ec is in A¯. Finally, if (Ei)i≥1 is a sequence in A¯ and

Ei = Ai ∪ Ni,Ni ⊂ Mi,μ(Mi) = 0,

then

⋃ i≥1Ei = ( ⋃ i≥1Ai ) ∪ (⋃ i≥1Ni ),

the set ⋃ ⁡ i≥1Ai is in A, and ⋃ ⁡ i≥1Ni ⊂⋃ i≥1Mi with

μ (⋃ i≥1Mi ) ≤∑ i≥1μ(Mi) = 0.

Therefore ⋃ ⁡ i≥1Ei is in A¯.

Step 3. Countable additivity. We now verify the measure property. Clearly,

μ¯(∅) = μ(∅) = 0.

Let (Ei)i≥1 be a sequence of pairwise disjoint elements of A¯, and write

Ei = Ai ∪ Ni,Ni ⊂ Mi,μ(Mi) = 0.

Since Ai ⊂ Ei, the sets Ai are pairwise disjoint. Moreover,

⋃ i≥1Ei = ( ⋃ i≥1Ai ) ∪ (⋃ i≥1Ni ),

and ⋃ ⁡ i≥1Ni is contained in the measurable set ⋃ ⁡ i≥1Mi of measure 0. Thus

μ¯ (⋃ i≥1Ei ) = μ (⋃ i≥1Ai ) = ∑ i≥1μ(Ai) = ∑ i≥1μ¯(Ei).

Step 4. Completeness. It remains to prove completeness. Let N ⊂ X be μ¯-negligible. Then there exists E in A¯ such that

N ⊂ E,μ¯(E) = 0.

Write E = A ∪ Z with A in A, Z ⊂ M, M in A, and μ(M) = 0. Since μ¯(E) = μ(A) = 0, the measurable set A ∪ M has measure 0 and contains E, hence also N. Therefore N = ∅∪ N belongs to A¯.

Step 5. Extension of the original measure. Finally, if A is in A, then A = A ∪∅ is in A¯ and

μ¯(A) = μ(A).

Thus μ¯ extends μ. □

We now record a few notions of regularity on topological spaces. We denote by B(X) the Borel σ-algebra of a topological space X.

Definition 2.7 (Local finiteness and finiteness). Let X be a topological space and let μ be a measure on B(X).

1.
The measure μ is said to be locally finite if every point of X admits an open neighbourhood U such that μ(U) < ∞.
2.
The measure μ is said to be inner regular on open sets if, for every open set U of X,
μ(U) = sup ⁡{μ(K): K ⊂ U,K compact}.
3.
The measure μ is said to be outer regular on Borel sets if, for every Borel set E of X,
μ(E) = inf ⁡{μ(U): E ⊂ U,U open}.

Remark. When X is an open subset of ℝN, local finiteness is equivalent to finiteness on compact sets. Indeed, local finiteness gives a finite subcover of every compact set by finite-measure neighbourhoods. Conversely, if compact sets have finite measure, every point has a closed ball contained in X, hence a finite-measure neighbourhood.

Definition 2.8 (Radon measures on Euclidean open sets). Let Ω be an open subset of ℝN. A positive Radon measure on Ω is a Borel measure on Ω which is locally finite.

Remark. In these notes, on an open subset of ℝN, a positive Radon measure means a locally finite Borel measure. The inner and outer regularity properties introduced above are the ones that many authors include in the definition of a Radon measure. In the present course we first isolate local finiteness, and later Theorem 14.2 will show that positive Radon measures on open subsets of ℝN also satisfy these regularity properties.

Remark. Once the Lebesgue measure has been constructed, it will provide a fundamental example of a positive Radon measure. Dirac masses are also examples. Later on, we will also meet the Riesz representation theorem, which identifies positive Radon measures with positive linear functionals on Cc(Ω).

2.4 First encounter with the Lebesgue measure

Another fundamental example of measure is given by the Lebesgue measure on ℝn, which we shall now consider. Let n in ℕ≥1 and let B(ℝn) be the Borel σ-algebra of ℝn.

Given B in B(ℝn) and x in ℝn, we define

x + B := {x + y : y ∈ B},

and x + B is again in B(ℝn) because the translation y↦x + y is a homeomorphism of ℝn.

Definition 2.9 (Translation-invariant measures). A measure μ on B(ℝn) is said to be translation invariant if

∀ ⁡B ∈B(ℝn),∀ ⁡x ∈ ℝn,μ(x + B) = μ(B).

The Borel Lebesgue measure λn on (ℝn,B(ℝn)) is characterized by the following result.

Theorem 2.10 (Existence and uniqueness of Lebesgue measure). There exists a unique measure λn on B(ℝn) such that

1.
λn is translation invariant,
2.
λn([0, 1]n) = 1, where
[0, 1]n = {(a 1,…,an) : 0 ≤ ai ≤ 1 for every i}.

We will later justify Theorem 2.10 in two different ways. The next chapter presents the classical construction from outer measures and Carathéodory’s extension theorem, which yields the Borel Lebesgue measure. Later on, in Section 14.3, we will recover the same Borel measure again from the Riesz representation theorem and then pass to its completion.

In particular, the following supplement indicates that the Lebesgue measure λ1 should be considered as an extension of the notion of length, λ2 as an extension of the notion of area, and λ3 as an extension of the notion of volume.

Theorem 2.11 (Lebesgue measure of rectangles). The Lebesgue measure λn of a cartesian product of intervals, open, closed, or half-open, bounded or unbounded, is the product of the lengths of its sides, with value + ∞ allowed.

This statement will follow from the construction in the next chapter. As an example, let us note that

λ1(ℚ) = 0

. Indeed, if

ℚ = {qk : k ≥ 1}

, then countable subadditivity gives

λ1(ℚ) ≤∑ k=1∞λ 1({qk}) = 0.

Example 2.12 (Dirichlet function). Since λ1(ℚ) = 0, the function 1ℚ is zero λ1-almost everywhere on ℝ. Indeed, outside the negligible set ℚ, it is identically equal to 0.

2.5 Comparison of measures

We record two basic ways of comparing positive measures on the same measurable space. These notions already appear in elementary examples and will become structural in the Lebesgue decomposition and Radon–Nikodym theorems.

Definition 2.13 (Absolute continuity of positive measures). Let μ and ν be positive measures on (X,A). We say that ν is absolutely continuous with respect to μ, and we write ν ≪ μ, if, for every E in A,

μ(E) = 0⟹ν(E) = 0.

Definition 2.14 (Mutual singularity of positive measures). Let μ and ν be positive measures on (X,A). We say that ν and μ are mutually singular, and we write ν ⊥ μ, if there exists S in A such that

ν(Sc) = 0,μ(S) = 0.

Such a set S is called a mutually singular set associated with the ordered pair (ν,μ). Thus ν is concentrated on S, while μ is concentrated on Sc.

Example 2.15 (Restricted measures on a partition). Let μ be a positive measure on (X,A) and let A be in A. Define two positive measures by

μA(E) := μ(E ∩ A),μAc(E) := μ(E ∩ Ac),

for every E in A. Then μA ≪ μ and μAc ≪ μ. Moreover, μA ⊥ μAc, and A is a mutually singular set associated with the ordered pair (μA,μAc).

Example 2.16 (Singular Dirac measures). Assume that x and y are two distinct points of X and that the singletons {x} and {y}belong to A. Then the Dirac measures δx and δy are mutually singular: the set {x} is a mutually singular set associated with the ordered pair (δx,δy). Moreover, δx is not absolutely continuous with respect to δy, because

δy({x}) = 0,δx({x}) = 1.

The following elementary form of absolute continuity will be used later, in particular in the Baire-category argument for set functions.

Lemma 2.17 (Finite absolute continuity lemma). Let (X,A,μ) be a finite measure space and let α be a finite positive measure such that α ≪ μ. Then for every 𝜀 > 0 there exists δ > 0 such that

μ(E) < δ⟹α(E) < 𝜀

for every E in A.

Proof. Assume by contradiction that the conclusion fails for some 𝜀 > 0. Then, for every n ≥ 1, there exists En in A such that

μ(En) < 2−n,α(E n) ≥ 𝜀.

Set

Fm := ⋃ n≥mEn,F := ⋂ m≥1Fm.

Then Fm decreases to F and

μ(Fm) ≤∑ n≥m2−n → 0as m → +∞.

Hence μ(F) = 0, and absolute continuity gives α(F) = 0. On the other hand, En ⊂ Fm for all n ≥ m, so α(Fm) ≥ 𝜀 for every m. By continuity from above for the finite measure α,

α(Fm) → α(F) = 0,

which is a contradiction. □

2.6 Signed measures

Although the integral will first be developed for positive measures, it is convenient to record here the basic structural facts on finite signed measures. They belong naturally to the measure-theoretic foundations and will later be used in the proof of Lebesgue decomposition, in the signed Radon–Nikodym theorem, in the Baire argument for set functions, and in the study of bounded Radon measures.

Definition 2.18 (Finite signed measures). Let (X,A) be a measurable space. A finite signed measure is a map ν : A → ℝ such that ν(∅) = 0 and, for every sequence (En)n≥1 of pairwise disjoint sets in A, the series ∑ ⁡ n=1∞ν(E n) converges in ℝ and

ν (⋃ n=1∞E n ) = ∑ n=1∞ν(E n).

2.7 Hahn decomposition

Definition 2.19 (Positive and negative sets for signed measures). Let ν be a finite signed measure on (X,A). A measurable set P is called positive for ν if

ν(E) ≥ 0

for every measurable set E ⊂ P. A measurable set N is called negative for ν if

ν(E) ≤ 0

for every measurable set E ⊂ N.

Lemma 2.20 (Stability of positive and negative sets). Let ν be a finite signed measure on (X,A). If A ∈A satisfies ν(A) > 0, then A contains a positive measurable subset P such that ν(P) > 0.

Proof. Set A0 := A. If A0 is positive, then we may take P = A0. Otherwise there is a measurable subset of A0 with strictly negative measure. Let m0 be the smallest positive integer such that some measurable C ⊂ A0 satisfies

ν(C) < − 1 m0,

and choose B0 ⊂ A0 with ν(B0) < −1∕m0.

Assume that Ak has been constructed. If Ak is positive, then we stop. Otherwise, let mk be the smallest positive integer such that some measurable C ⊂ Ak satisfies

ν(C) < − 1 mk,

choose Bk ⊂ Ak with ν(Bk) < −1∕mk, and set

Ak+1 := Ak ∖ Bk.

If the construction stops at rank k, then the last set Ak is positive. Moreover, only sets of negative measure have been removed, hence

ν(Ak) ≥ ν(A) > 0.

Thus P := Ak is suitable.

Assume now that the construction never stops. The sets Bk are pairwise disjoint. Since ν is finite-valued and countably additive, the series

∑ k=0∞ν(B k)

converges in ℝ. All its terms are negative, and therefore mk → +∞. Define

P := A ∖⋃ k=0∞B k = ⋂ k=0∞A k.

By countable additivity,

ν(P) = ν(A) −∑ k=0∞ν(B k) ≥ ν(A) > 0.

We claim that P is positive. Indeed, suppose that a measurable set C ⊂ P satisfies ν(C) < 0. Choose an integer m ≥ 1 such that

ν(C) < −1 m.

For k large enough we have mk > m. Since C ⊂ P ⊂ Ak and ν(C) < −1∕m, the integer m satisfies the defining property used in the construction of mk. Hence mk ≤ m, a contradiction. Thus P is positive, and the lemma is proved. □

Lemma 2.21 (Countable unions of positive and negative sets). Let ν be a finite signed measure on (X,A). A countable union of positive measurable sets is positive.

Proof. Let (Pn)n≥1 be positive measurable sets and set P := ⋃ ⁡ n≥1Pn. If E ⊂ P is measurable, decompose E into the disjoint union

E = ⋃ n=1∞E n,En := E ∩ (Pn ∖⋃ j<nPj) .

Since En ⊂ Pn, positivity of Pn gives ν(En) ≥ 0 for every n. Countable additivity gives

ν(E) = ∑ n=1∞ν(E n) ≥ 0.

Thus P is positive. □

Theorem 2.22 (Hahn decomposition theorem). Let ν be a finite signed measure on (X,A). There exist two measurable sets P and N such that

P ∩ N = ∅,P ∪ N = X,

and:

  • P is positive for ν,
  • N is negative for ν.

Any such pair (P,N) is called a Hahn decomposition of ν.

Proof. Step 1. The supremum of the masses of positive sets is finite. The empty set is positive, and therefore the family of positive measurable sets is nonempty. Let

s := sup ⁡{ν(P) : P is a positive measurable set}.

We have s ≥ 0. This supremum is finite in ℝ. Indeed, if the measures of positive sets were unbounded from above, we could choose positive sets (Pn)n≥1 with ν(Pn) > n. By Lemma 2.21, the set P∗ := ⋃ ⁡ n≥1Pn would be positive. Since Pn ⊂ P∗ and P∗ is positive, the set P∗∖ Pn is positive, and therefore

ν(P∗) = ν(Pn) + ν(P∗∖ Pn) ≥ ν(Pn) > n

for every n, which is impossible because ν(P∗) is a real number.

Step 2. Construction of a maximal positive set. Choose positive measurable sets (Pn)n≥1 such that

ν(Pn) > s −1 n.

Set

P := ⋃ n=1∞P n.

By Lemma 2.21, the set P is positive. Since P is positive, ν(P) ≤ s. On the other hand, for every n we have Pn ⊂ P and P ∖ Pn ⊂ P, hence

ν(P) = ν(Pn) + ν(P ∖ Pn) ≥ ν(Pn) > s −1 n.

Letting n → +∞, we obtain ν(P) = s.

Step 3. The complement is negative. Set N := X ∖ P. If N were not negative, there would exist a measurable set A ⊂ N with ν(A) > 0. By Lemma 2.20, the set A would contain a positive measurable subset Q with ν(Q) > 0. Then P ∪ Q would be positive by Lemma 2.21, and, since P ∩ Q = ∅,

ν(P ∪ Q) = ν(P) + ν(Q) > s,

contradicting the definition of s. Therefore N is negative, and (P,N) is a Hahn decomposition of ν. □

Proposition 2.23 (Comparison of Hahn decompositions). Let ν be a finite signed measure on (X,A). Let (P,N) and (P′,N′) be two Hahn decompositions of ν. Then, for every E in A,

ν(E ∩ P) = ν(E ∩ P′),ν(E ∩ N) = ν(E ∩ N′).

Moreover, if F is a measurable subset of P△P′ or of N△N′, then ν(F) = 0.

Proof. The set E ∩ P ∩ N′ is contained in the positive set P and in the negative set N′. Hence

ν(E ∩ P ∩ N′) ≥ 0andν(E ∩ P ∩ N′) ≤ 0,

and therefore

ν(E ∩ P ∩ N′) = 0.

Similarly,

ν(E ∩ N ∩ P′) = 0.

It follows that

ν(E ∩ P) = ν(E ∩ P ∩ P′) + ν(E ∩ P ∩ N′) = ν(E ∩ P ∩ P′),

and

ν(E ∩ P′) = ν(E ∩ P′∩ P) + ν(E ∩ P′∩ N) = ν(E ∩ P ∩ P′).

This proves

ν(E ∩ P) = ν(E ∩ P′).

The equality involving N and N′ is proved in the same way.

Let now F be a measurable subset of P△P′. Then F is the disjoint union of F ∩ P ∩ N′ and F ∩ N ∩ P′. Both sets have signed measure 0 by the preceding argument, hence ν(F) = 0. The proof for measurable subsets of N△N′ is identical. □

Remark 2.24 (Non-uniqueness of Hahn decompositions). A Hahn decomposition is not unique in general. For instance, if ν = 0, every measurable set P gives a Hahn decomposition (P,Pc). Proposition 2.23 is the uniqueness statement that is actually needed: two Hahn decompositions give the same positive and negative parts of the signed measure.

2.8 Jordan decomposition

Theorem 2.25 (Jordan decomposition theorem). Let ν be a finite signed measure on (X,A) and let (P,N) be a Hahn decomposition of ν. We define

ν+(E) := ν(E ∩ P),ν−(E) := −ν(E ∩ N),

for every E in A. Then ν+ and ν− are finite positive measures, they are mutually singular, and

ν = ν+ − ν−.

Moreover, the pair (ν+,ν−) is uniquely determined by these properties, and in particular it does not depend on the chosen Hahn decomposition.

Proof. Step 1. Construction of the two positive measures. We first check that ν+ and ν− are positive measures. If E ∈A, then E ∩ P ⊂ P and E ∩ N ⊂ N. Therefore

ν+(E) = ν(E ∩ P) ≥ 0,ν−(E) = −ν(E ∩ N) ≥ 0.

If (Ej)j≥1 is a sequence of pairwise disjoint measurable sets, then the sets Ej ∩ P are pairwise disjoint, and hence

ν+ (⋃ j=1∞E j) = ν (⋃ j=1∞(E j ∩ P)) = ∑ j=1∞ν(E j ∩ P) = ∑ j=1∞ν+(E j).

The same argument applied on N, with the sign changed, proves countable additivity of ν−. Moreover, ν+(X) = ν(P) and ν−(X) = −ν(N) are finite real numbers, so both positive measures are finite.

Step 2. Reconstruction and singularity. For every E ∈A, the decomposition

E = (E ∩ P) ∪ (E ∩ N)

is disjoint, and therefore

ν(E) = ν(E ∩ P) + ν(E ∩ N) = ν+(E) − ν−(E).

The measures ν+ and ν− are mutually singular because they are separated by P:

ν+(Pc) = ν+(N) = 0,ν−(P) = 0.

Step 3. Uniqueness. It remains to prove uniqueness. Assume that another pair of finite positive measures satisfies the same properties:

ν = η+ − η−,η+ ⊥ η−.

By the definition of mutual singularity, there exists a measurable set A such that

η+(Ac) = 0,η−(A) = 0.

Thus η+ is concentrated on A, while η− is concentrated on Ac. Consequently, if F ⊂ A is measurable, then

ν(F) = η+(F) − η−(F) = η+(F) ≥ 0,

and if F ⊂ Ac is measurable, then

ν(F) = η+(F) − η−(F) = −η−(F) ≤ 0.

Hence (A,Ac) is also a Hahn decomposition of ν. By Proposition 2.23, applied to the two Hahn decompositions (P,N) and (A,Ac), for every E in A we have

ν(E ∩ P) = ν(E ∩ A),ν(E ∩ N) = ν(E ∩ Ac).

We can now identify the two decompositions. Since η+(Ac) = 0 and η−(A) = 0, for every E in A we have

η+(E) = η+(E ∩ A) = ν(E ∩ A),η−(E) = η−(E ∩ Ac) = −ν(E ∩ Ac).

Using the comparison identities above, we obtain

η+(E) = ν(E ∩ P) = ν+(E),η−(E) = −ν(E ∩ N) = ν−(E).

Thus η+ = ν+ and η− = ν−. The Jordan decomposition is unique. □

2.9 Total variation

Definition 2.26 (Total variation measure and total variation mass). Let ν be a finite signed measure on (X,A) and let ν = ν+ − ν− be its Jordan decomposition. The total variation measure of ν is the positive measure

|ν| := ν+ + ν−.

The total variation mass of ν is the number

∥ν∥ := |ν|(X).

Proposition 2.27 (Partition formula for the total variation). Let ν be a finite signed measure on (X,A). For every E in A we have

|ν|(E) = sup ⁡ { ∑ k=1m|ν(E k)| : m ≥ 1,(Ek)1≤k≤m is a measurable partition of E }.

In particular, for every E in A we have |ν(E)|≤|ν|(E).

Proof. Let ν = ν+ − ν− be the Jordan decomposition. Let E be in A and let (Ek)1≤k≤m be a measurable partition of E. By additivity and the triangle inequality,

∑ k=1m|ν(E k)| ≤∑ k=1m (ν+(E k) + ν−(E k) ) = ν+(E) + ν−(E) = |ν|(E).

Taking the supremum over all partitions yields

sup ⁡ { ∑ k=1m|ν(E k)| }≤|ν|(E).

Conversely, we use the partition E = (E ∩ P) ∪ (E ∩ N) associated with a Hahn decomposition (P,N). Then

|ν(E ∩ P)| + |ν(E ∩ N)| = ν+(E) + ν−(E) = |ν|(E),

which gives the reverse inequality. □

Proposition 2.28 (Total variation norm). Let (X,A) be a measurable space. The set of finite signed measures on (X,A) is a real vector space, and the map

ν↦∥ν∥ := |ν|(X)

is a norm on this vector space.

Proof. The fact that finite signed measures form a real vector space follows directly from the definition.

Let ν be a finite signed measure. Since |ν| is a positive measure, we have

∥ν∥ = |ν|(X) ≥ 0.

If ∥ν∥ = 0, then for every E in A,

|ν(E)|≤|ν|(E) ≤|ν|(X) = 0.

Thus ν(E) = 0 for every E in A, and therefore ν = 0.

Let a be in ℝ. If a = 0, then ∥aν∥ = 0 = |a|∥ν∥. If a≠0, Proposition 2.27 gives

∥aν∥ = sup ⁡ { ∑ k=1m|aν(E k)| : m ≥ 1,(Ek)1≤k≤m is a measurable partition of X } = |a| sup ⁡ { ∑ k=1m|ν(E k)| : m ≥ 1,(Ek)1≤k≤m is a measurable partition of X } = |a|∥ν∥.

Finally, let ν and η be finite signed measures. For every finite measurable partition (Ek)1≤k≤m of X, we have

∑ k=1m|(ν + η)(E k)| ≤∑ k=1m|ν(E k)| + ∑ k=1m|η(E k)| ≤|ν|(X) + |η|(X).

Taking the supremum over all finite measurable partitions of X and using Proposition 2.27 gives

∥ν + η∥≤∥ν∥ + ∥η∥.

Thus ∥⋅∥ is a norm. □

We can therefore call ∥ν∥ = |ν|(X) the total variation norm of ν.

Definition 2.29 (Absolute continuity of finite signed measures). Let μ be a positive measure on (X,A) and let ν be a finite signed measure on (X,A). We say that ν is absolutely continuous with respect to μ, and we write ν ≪ μ, if the total variation measure satisfies

|ν|≪ μ.

Equivalently, if ν = ν+ − ν− is the Jordan decomposition, then ν ≪ μ means that both ν+ ≪ μ and ν− ≪ μ. This is also equivalent to saying that ν(E) = 0 for every μ-negligible set E, but the formulation through |ν| keeps track of both signs at once.
