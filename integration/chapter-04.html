Chapter 4
Measurable functions

Having defined measurable sets and measures, we now pass to measurable functions. The chapter recalls the role of preimages, gives practical criteria for measurability, and develops the stability properties that let us build large classes of measurable functions from simpler ones and from continuous functions.

4.1 Gentle reminder on the notion of preimage

Let us start with a few reminders and notations in the general case of set maps. Let f : X → Y be a map from a set X to a set Y . For any B ⊂ Y , we define the preimage (or reciprocal image) of B by f:

f−1(B) := {x ∈ X : f(x) ∈ B}.

Remember that this is simple notation and does not imply that f is invertible. Of course, we have f−1(Y ) = X, f−1(∅) = ∅, and recall the formulas, valid for any A,B ⊂ Y , where complements are taken in Y and X respectively:

f−1(A ∩ B) = f−1(A) ∩ f−1(B), f−1(A ∪ B) = f−1(A) ∪ f−1(B), f−1(A∁) = (f−1(A))∁.

If I is any set of indices, the first two formulas generalize to ∩i∈IAi and ∪i∈IAi, where Ai ⊂ Y for all i.

4.2 Definition of a measurable function

Definition 4.1 (Measurable maps). Let (X,AX) and (Y,AY ) be measurable spaces and let f : X → Y . We say that f is (AX,AY )-measurable (or simply measurable if there is no ambiguity on the σ-algebras involved) if for all B in AY we have f−1(B) in AX.

Let us look at some basic examples of measurable functions.

  • Let (X,AX) be a measurable space. Then Id: X → X, defined by Id(x) = x, is measurable.
  • If (X,AX) and (Y,AY ) are measurable spaces and y0 is in Y , then the constant map x↦y0 is measurable, because the preimage of any measurable set in Y is either X or ∅.

Proposition 4.2 (Measurability of indicator functions). Let (X,A) be a measurable space and let A ⊂ X. Then A is in A if and only if 1A: X → ℝ is (A,B(ℝ))-measurable.

Proof. Suppose first that A is in A. Let B in B(ℝ). Since 1A only takes the values 0 and 1, the set 1A−1(B) is equal to ∅, A, A∁, or X. In each case it belongs to A. Thus 1A is measurable.

Conversely, if 1A is measurable, then

A = 1A−1({1}).

Since {1} is closed in ℝ, it is Borel, hence A is in A. □

4.3 A maximal σ-algebra on the target and a related criterion

The following proposition associates with an arbitrary map f : X → Y the largest target σ-algebra for which f is measurable. This is the final σ-algebra on Y induced by f and AX. It is useful for proving the following generator criterion.

Proposition 4.3 (Measurable sets defined by level conditions). Let (X,AX) and (Y,AY ) be two measurable spaces. Let f : X → Y be a map, which is not necessarily assumed to be measurable. We define

f∗AX := {B ⊂ Y : f−1(B) ∈A X},

which is a subset of P(Y ). Then

1.
f∗AX is a σ-algebra on Y ,
2.
moreover, a map f : X → Y is (AX,AY )-measurable if and only if AY ⊂ f∗AX,
3.
and finally, f∗AX is the largest σ-algebra S on Y such that f is measurable from (X,AX) to (Y,S).

Proof. We first prove 1). Since f−1(Y ) = X and X is in AX, we have Y in f∗AX. If B is in f∗AX, then

f−1(B∁) = (f−1(B))∁,

and the right-hand side is in AX. Hence B∁ is in f∗AX. Finally, if (Bn)n≥1 is a sequence of elements of f∗AX, then

f−1 ( ⋃ n≥1Bn ) = ⋃ n≥1f−1(B n),

and the right-hand side belongs to AX. Therefore ∪n≥1Bn is in f∗AX. We have proved that f∗AX is a σ-algebra on Y .

Property 2) is just a reformulation of the definition of measurability: saying that f is (AX,AY )-measurable means exactly that for every B in AY , the preimage f−1(B) belongs to AX, i.e. that every B in AY belongs to f∗AX.

We finally prove 3). By 1), f∗AX is a σ-algebra on Y , and by 2) the inclusion f∗AX ⊂ f∗AX shows that f is measurable from (X,AX) to (Y,f∗AX). Conversely, if S is a σ-algebra on Y such that f is measurable from (X,AX) to (Y,S), then 2) gives S ⊂ f∗AX. Thus f∗AX is the largest such σ-algebra. □

Proposition 4.4 (Criteria for measurable functions). Let (X,AX) be a measurable space, let Y be a set, let S be a collection of subsets of Y , and let AY := σ(S). Then a function f : X → Y is (AX,AY )-measurable if and only if

∀ ⁡B ∈ S,f−1(B) ∈A X.

Proof. Only the reciprocal implication requires a proof. We have S ⊂ f∗AX by hypothesis, so, since f∗AX is a σ-algebra on Y , we deduce that AY ⊂ f∗AX. Thus f is (AX,AY )-measurable. □

4.4 Measurability versus continuity

When topological spaces are involved, the Borel σ-algebras provide a natural bridge between continuity and measurability.

Definition 4.5 (Borel measurable maps). Let (X,τX) and (Y,τY ) be topological spaces and let BX, BY be the Borel σ-algebras associated with τX and τY respectively. We say that f : X → Y is a Borel function if f is (BX,BY )-measurable.

Theorem 4.6 (Borel measurability of continuous maps). Let (X,τX) and (Y,τY ) be topological spaces and let BX, BY be the Borel σ-algebras associated with τX and τY respectively. If f : X → Y is continuous then f is (BX,BY )-measurable.

! The converse implication is false in general. For instance, 1]0,1[: ℝ → ℝ is Borel measurable but discontinuous at 0 and 1.

Proof. By Proposition 4.4, it is enough to check the measurability of the preimages of the open subsets of Y . Let U be an open subset of Y . Since f is continuous, we have f−1(U) in τX ⊂BX. Thus f is (BX,BY )-measurable. □

4.5 Stability of measurable functions

The following result proves that the composition of two measurable functions gives a measurable function.

Proposition 4.7 (Composition of measurable maps). Let (X,AX), (Y,AY ), and (Z,AZ) be measurable spaces. If f : X → Y and g: Y → Z are measurable, then the composition

g ∘ f : X → Z

is measurable.

Proof. Let C in AZ. Since g is measurable, g−1(C) is in AY . Since f is measurable, we deduce that

(g ∘ f)−1(C) = f−1(g−1(C))

belongs to AX. Hence g ∘ f is measurable. □

Proposition 4.8 (Vector-valued measurability criterion). Let (X,A) be a measurable space. We endow each ℝk, k ≥ 1, with its Borel σ-algebra B(ℝk). Let n ∈ ℕ≥1 and let

f = (f1,…,fn): X → ℝn,x↦(f 1(x),…,fn(x)),

be a map. Then f is measurable if and only if every fi: X → ℝ is measurable.

Proof. For any 1 ≤ i ≤ n, let πi: ℝn → ℝ be the projection onto the i-th coordinate. The map πi is continuous and therefore Borel. So, if f is measurable, then fi = πi ∘ f is (A,B(ℝ))-measurable.

Conversely, assume that each fi is measurable. If Rn denotes the family of open rectangles of ℝn, then B(ℝn) = σ(R n), where the rectangles are

D((xi)i, (yi)i) := {(z1,…,zn) ∈ ℝn: ∀ ⁡i,x i < zi < yi}.

For such a rectangle we have

f−1(D((x i)i, (yi)i)) = ⋂ k=1nf k−1(]x k,yk[),

which belongs to A. Proposition 4.4 therefore gives the measurability of f. □

Proposition 4.9 (Stability by continuous functional calculus). Let (X,A) be a measurable space and let u,v: X → ℝ be two measurable maps, where ℝ is provided with its Borel σ-algebra. Let ϕ: ℝ2 → ℝ be Borel measurable, in particular continuous. Then the map

h: X → ℝ,x↦ϕ(u(x),v(x))

is measurable.

Proof. Let F : X → ℝ2 be defined by

F(x) := (u(x),v(x)).

Since u and v are measurable, Proposition 4.8 shows that F is measurable. Since ϕ is Borel, Proposition 4.7 implies that

h = ϕ ∘ F

is measurable. □

We can now state the following theorem, which is constantly used in practice. We recall that, by definition, for a sequence of real numbers (an)n,

limsup ⁡ nan := lim ⁡ n→+∞ sup ⁡ k≥nak and  liminf ⁡ nan := lim ⁡ n→+∞ inf ⁡ k≥nak.

The same definitions apply to functions; then the previous formulas are applied pointwise.

Theorem 4.10 (Stability of measurable functions under limits). Let (X,A) be a measurable space. Let ℝ and ℝ¯ be given their respective Borel σ-algebras.

1.
If f : X → ℝ is measurable, then |f| is also measurable.
2.
If f,g: X → ℝ are measurable, then the maps
f + g,f × g, max ⁡(f,g), min ⁡(f,g)

are measurable.

3.
If fk: X →ℝ¯ is the general term of a sequence (fk)k≥1 of measurable functions, then the following maps from X to ℝ¯:
inf ⁡ kfk, sup ⁡ kfk,limsup ⁡kfk,liminf ⁡kfk

are measurable.

4.
If (fk)k≥1 is a sequence of measurable functions from X to ℝ¯ and if fk converges pointwise to a function f : X →ℝ¯, then f is measurable.

Proof. For 1), we apply Proposition 4.9 with u = v = f and

ϕ(x,y) = |x|.

The function ϕ is continuous on ℝ2, hence |f| is measurable.

For 2), we apply Proposition 4.9 with the continuous functions

ϕ1(x,y) = x + y,ϕ2(x,y) = xy,ϕ3(x,y) = max ⁡(x,y),ϕ4(x,y) = min ⁡(x,y).

This gives the measurability of f + g, f × g, max ⁡(f,g), and min ⁡(f,g).

For 3), we use Proposition 4.4. The family {[−∞,a[: a ∈ ℝ} generates B(ℝ¯): indeed, [−∞,a] = ⋂ ⁡ m≥1[−∞,a + 1∕m[, while ]a, +∞] = [−∞,a]c and ]a,b[= [−∞,b[∩[−∞,a]c. Thus it is enough to consider these generating intervals. Let

g(x) := sup ⁡ k≥1fk(x)andh(x) := inf ⁡ k≥1fk(x).

For every a in ℝ, we have

g−1([−∞,a[) = ⋂ k≥1fk−1([−∞,a[), h−1([−∞,a[) = ⋃ k≥1fk−1([−∞,a[).

The right-hand sides are measurable, so g and h are measurable.

For each n ≥ 1, let

gn := sup ⁡ k≥nfkandhn := inf ⁡ k≥nfk.

By the first part of 3), applied to the tails (fk)k≥n, each gn and each hn is measurable. Since

limsup ⁡ kfk = inf ⁡ n≥1gnand liminf ⁡ kfk = sup ⁡ n≥1hn,

another application of the same argument shows that limsup ⁡ kfk and liminf ⁡ kfk are measurable.

This proves 3). If lim ⁡ kfk(x) exists for all x in X, then it coincides pointwise with both limsup ⁡ kfk and liminf ⁡ kfk. Hence the limit function is measurable, which proves 4). □
