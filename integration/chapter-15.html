Chapter 15
Lebesgue spaces Lp(μ)

We complete the measure-theoretic core with the scale of Lebesgue spaces Lp. After the basic definitions, the chapter develops completeness, density, and separability, and then moves to several standard applications such as convolution, duality, and weak convergence. We now consider the more general case of the Lebesgue spaces Lp of all measurable functions whose absolute value raised to the p-th power has finite integral. Below μ is a measure over a measurable space (Ω,A). Unless explicitly stated otherwise, the first definitions and abstract properties are given in this general framework. Later, for density, duality, and weak convergence, we will specialize to positive Radon measures on open subsets of ℝN, and in the section on convolution and mollifiers we will further specialize to the Lebesgue measure.

15.1 First definitions and properties

Definition 15.1 (Lebesgue spaces Lp). Let 1 ≤ p < ∞. We define

Lp(Ω,μ) := {u : Ω → ℝ measurable  : ∥u∥ Lp(Ω,μ) := (∫ Ω|u|pdμ)1∕p < +∞},

and

L∞(Ω,μ) := {u : Ω → ℝ measurable  : ∥u∥ L∞(Ω,μ) := esssupx∈Ω|u(x)| < +∞},

where

esssupx∈Ω|u(x)| := inf ⁡{C ∈ ℝ : |u(x)|≤ Cμ-a.e. in Ω}.

There are two points to keep in mind after this definition.

First, the sequence spaces ℓp are examples of Lp spaces. Indeed, if Ω = ℕ and if μ is the counting measure on ℕ, then integration is summation and the condition above becomes

∑ k∈ℕ|u(k)|p < +∞.

Second, one has to distinguish functions from equivalence classes of functions. On Lp(Ω,μ) itself, the map

u↦∥u∥Lp(Ω,μ)

is only a seminorm: it can vanish for a function which is not identically zero, but only zero almost everywhere. Therefore we identify functions which are equal almost everywhere, exactly as in the construction of L1.

More precisely, for measurable functions u,v : Ω → [−∞, +∞], we write u ∼ v when

u(x) = v(x)for μ-a.e. x ∈Ω.

This is an equivalence relation. The space Lp(Ω,μ) is defined as the quotient of Lp(Ω,μ) by this relation. If u ∈Lp(Ω,μ), we denote by [u] its equivalence class.

From now on, we use the standard convention of writing u instead of [u]. This convention is harmless: by Lemma 8.10, if ∥u∥Lp(Ω,μ) = 0, then u = 0 μ-a.e. Thus the following definition depends only on the equivalence class and not on the chosen representative.

Definition 15.2 (Norms in Lp). Let u ∈ Lp(Ω,μ), we denote

∥u∥p := (∫ Ω|u|pdμ)1∕p if 1 ≤ p < ∞, ∥u∥∞ := esssupx∈Ω|u(x)|if p = ∞.

Example 15.3 (Power singularities in Lp). We consider the Lebesgue measure on B(0, 1) ⊂ ℝN and, for α > 0, the function

uα(x) := |x|−α.

Let 1 ≤ p < ∞. By the polar-coordinate formula,

∫ B(0,1)|uα(x)|pdx = ∫ B(0,1)|x|−αpdx = |𝕊N−1|∫ 01rN−1−αpdr.

The last one-dimensional integral is finite if and only if

N − 1 − αp > −1,

that is, if and only if αp < N. Thus

uα ∈ Lp(B(0, 1))if and only ifαp < N.

For p = ∞, the same function is not in L∞(B(0, 1)), since it is unbounded near the origin.

Due to this identification, the Lebesgue spaces Lp(Ω,μ) are normed spaces. Before proving this property, we state two important inequalities which will be instrumental in the sequel.

Proposition 15.4 (Hölder’s inequality). Let 1 ≤ p ≤∞ and p′ ≥ 1 its conjugate exponent defined by 1∕p + 1∕p′ = 1 (by convention p′ = 1 if p = ∞, and p′ = ∞ if p = 1). If u ∈ Lp(Ω,μ) and v ∈ Lp′(Ω,μ) then uv ∈ L1(Ω,μ) and

∥uv∥1 ≤∥u∥p∥v∥p′.

Proof. Since the logarithm is concave on ℝ+∗, for a,b > 0 and 1 ≤ p,p′ < ∞ with 1∕p + 1∕p′ = 1, we have

log ⁡(ab) = log ⁡(a) + log ⁡(b) = 1 p log ⁡(ap) + 1 p′ log ⁡(bp′ ) ≤ log ⁡ (1 pap + 1 p′bp′ ).

Taking the exponential we obtain Young’s inequality:

ab ≤ 1 pap + 1 p′bp′ .

Using this with a = λu and b = λ−1v and integrating over Ω yields

∫ Ω|uv|dμ ≤ 1 pλp∥u∥ pp + 1 p′λ−p′ ∥v∥p′p′ .

The last term is minimized by choosing λ = ∥v∥p′1∕p∥u∥ p(1−p)∕p.

If p = ∞ or p′ = ∞, the inequality is immediate. □

Remark 15.5 (Finite-measure embeddings). From Hölder’s inequality, it follows that if μ(Ω) < ∞ and 1 ≤ q ≤ p ≤∞ then

L∞(Ω,μ) ⊂ Lp(Ω,μ) ⊂ Lq(Ω,μ) ⊂ L1(Ω,μ).

However, if μ(Ω) = ∞, nothing can be said in general.

Proposition 15.6 (Minkowski inequality). For 1 ≤ p ≤∞, and for any u, v ∈ Lp(Ω,μ), we have

∥u + v∥p ≤∥u∥p + ∥v∥p.

Proof. We start with the case where p = ∞. By definition of the essential supremum, |u(x)|≤∥u∥∞ and |v(x)|≤∥v∥∞ for μ-a.e. x ∈Ω, hence

|u(x) + v(x)|≤|u(x)| + |v(x)|≤∥u∥∞ + ∥v∥∞,

for μ-a.e. in Ω. Using again the definition of the essential supremum of u + v, we get

∥u + v∥∞ ≤∥u∥∞ + ∥v∥∞.

Similarly, for p = 1, we have

∥u + v∥1 = ∫ Ω|u + v|dμ ≤∫ Ω(|u| + |v|)dμ ≤∥u∥1 + ∥v∥1.

For 1 < p < ∞,

∥u + v∥pp = ∫ Ω|u + v|pdμ = ∫ Ω|u + v||u + v|p−1dμ ≤∫ Ω|u||u + v|p−1dμ + ∫ Ω|v||u + v|p−1dμ ≤ (∥u∥p + ∥v∥p) (∫ Ω(|u + v|p−1)p∕(p−1)) (p−1)∕p

by Hölder’s inequality. Then it is sufficient to observe that the last quantity is equal to

(∥u∥p + ∥v∥p)∥u + v∥pp−1,

and to simplify the inequality by ∥u + v∥pp−1. □

We are now in a position to state that the Lebesgue spaces are normed spaces:

Proposition 15.7 (Normed structure of Lp). For 1 ≤ p ≤∞, the map u ∈ Lp(Ω,μ)↦∥u∥ p defines a norm over Lp(Ω,μ).

Proof. We already have mentioned that if ∥u∥p = 0, then u = 0 μ-a.e. in Ω, and thus u = 0 in Lp(Ω,μ). Clearly, ∥λu∥p = |λ|∥u∥p for every λ ∈ ℝ and u ∈ Lp(Ω,μ). Finally the triangle inequality is a consequence of the Minkowski inequality. □

Observe that it follows from Theorem 11.18 that if (fn) is a sequence bounded both in L1(X,μ) and in Lp(Ω,μ) for some 1 < p < ∞ then the sequence (fn) is equi-integrable.

15.2 Completeness

We saw in Proposition 15.7 that the Lebesgue spaces Lp(Ω,μ) are normed spaces. We will prove now that they are actually Banach spaces as a consequence of the following completeness result.

Theorem 15.8 (Riesz–Fischer theorem for Lp). For 1 ≤ p ≤∞, the space Lp(Ω,μ) is complete.

Proof. It is enough to prove that any normally converging series in Lp(Ω,μ) is converging in Lp(Ω,μ) (see Proposition 16.24). Let (un)n ⊂ Lp(Ω; μ) be such that ∑ ⁡ n=1∞∥u n∥p < ∞. Then the sequence of partial sums

vn := ∑ k=1n|u k|

is increasing, and from the Minkowski inequality, for any n ∈ ℕ,

∫ Ωvnpdμ = ∥v n∥pp ≤ (∑ k=1∞∥u k∥p) p < ∞, (15.1)

if p < ∞, while

vn(x) ≤∑ k=1∞∥u k∥∞ (15.2)

for μ-a.e. x ∈Ω if p = ∞. We deduce from the monotone convergence Theorem that (vn) converges μ-a.e. in Ω to the function ∑ ⁡ k=1∞|u k| which, by (15.1) and (15.2), belongs to Lp(Ω,μ). In particular, we deduce that the series ∑ ⁡ k=1∞|u k(x)| converges for μ-a.e. x ∈Ω, and from the completeness of ℝ, using the converse part of Proposition 16.24, that the series ∑ ⁡ k=1∞u k(x) converges as well. Moreover,

∑ k=1∞u k ∈ Lp(Ω,μ),

and for n ≥ m, we have

∥∑ k=1nu k −∑ k=1mu k∥ p = ∥∑ k=m+1nu k∥ p ≤∑ k=m+1n ∥u k∥ p

where we used again the Minkowski inequality. Letting n → +∞, we infer that

∥∑ k=1∞u k −∑ k=1mu k∥ p ≤∑ k=m+1∞ ∥u k∥ p

and since ∑ ⁡ n=1∞∥u n∥p < ∞, then ∑ ⁡ k=m+1∞ ∥u k∥ p → 0 as m →∞, and the conclusion follows. □

15.3 Density

Theorem 15.9 (Density of simple functions). For any 1 ≤ p ≤∞ the space of all measurable simple functions is dense in Lp(Ω,μ).

Proof. Let u in Lp(Ω,μ). Decomposing u = u+ − u−, we can assume without loss of generality that u ≥ 0. Let (sn) be the sequence of simple functions constructed as in the proof of Theorem 6.6. We distinguish two cases.

  • If p = ∞, then for any n ≥∥u∥∞, we have |sn(x) − u(x)|≤ 2−n for μ-a.e. x ∈Ω, and thus ∥sn − u∥∞ ≤ 2−n → 0 as n → +∞.

  • If 1 ≤ p < ∞, since sn(x) → u(x) as n → +∞ for μ-a.e. x ∈Ω, we get that |u(x) − sn(x)|p → 0 as n → +∞ for μ-a.e. x ∈Ω and

    |u(x) − sn(x)|p ≤ 2pu(x)p

    for μ-a.e. x ∈Ω. Hence, by the dominated convergence Theorem ∥u − sn∥p → 0 as n → +∞.

□

From now on, we assume that Ω is an open subset of ℝN, with N ≥ 1, and that μ is a positive Radon measure.

Theorem 15.10 (Density of compactly supported continuous functions). For any 1 ≤ p < ∞ the space Cc(Ω) is dense in Lp(Ω,μ).

Proof. Let u in Lp(Ω,μ) and let

Kn := {x ∈Ω : dist(x,Ωc) ≥ 1∕n and ∥x∥ ℝN ≤ n}.

Then (Kn) is an increasing sequence of compact sets such that ∪nKn = Ω. Let 𝜀 > 0. By the dominated convergence Theorem, for n large enough, we have

∥u −1Knu∥Lp(Ω,μ) < 𝜀 2.

Fix such an n and set

un := 1Knu.

The restricted measure μn := μ⌞Kn is finite because μ is Radon and Kn is compact. By Theorem 15.9, applied to the finite measure space (Kn,B(Kn),μn), it is enough to approximate un in Lp(K n,μn) by continuous functions with compact support in Ω. By linearity, it therefore suffices to approximate characteristic functions of Borel subsets of Kn.

Let E ⊂ Kn be a Borel set. Choose δ > 0. By Theorem 14.2, there exist a compact set K and an open set V such that

K ⊂ E ⊂ V andμ(V ∖ K) < δ.

By Urysohn’s lemma (Lemma 16.41 in the appendix), there exists a function v ∈Cc(V ; [0, 1]) such that v = 1 on K. Then

|v −1E|p ≤1 V ∖K

on Ω, and therefore

∥v −1E∥Lp(Ω,μ)p ≤ μ(V ∖ K) < δ.

Choosing δ small enough, we approximate un arbitrarily well in Lp(Ω,μ) by elements of Cc(Ω). Since

∥u − un∥Lp(Ω,μ) < 𝜀 2,

this proves that Cc(Ω) is dense in Lp(Ω,μ). □

15.4 Separability

Recalling the definition of separability from Definition 16.37, we have the following two results regarding the separability of the spaces Lp, which distinguish the case where p is finite from the case p = ∞.

Corollary 15.11 (Separability of finite-exponent Lp spaces). For any 1 ≤ p < ∞ the space Lp(Ω,μ) is separable.

Proof. With the notation of the proof of Theorem 15.10, for every n in ℕ∗, define

Xn := {u ∈Cc(Ω) : supp(u) ⊂ Kn}.

Since every compact subset of Ω is contained in Kn for n large enough, we have

Cc(Ω) = ⋃ n=1∞X n.

Fix now n ∈ ℕ∗. The restriction map u↦u|Kn identifies Xn with a subspace of C(Kn). By Proposition 16.39, the space C(Kn) is separable for the uniform norm, hence Xn is also separable for the uniform norm. Moreover, if u,v ∈ Xn, then

∥u − v∥Lp(Ω,μ)p = ∫ Kn|u − v|pdμ ≤ μ(K n) sup ⁡ x∈Kn|u(x) − v(x)|p.

Therefore uniform convergence on Kn implies convergence in Lp(Ω,μ) on Xn, so Xn is separable for the topology induced by Lp(Ω,μ). Since Cc(Ω) is a countable union of separable subsets of the metric space Lp(Ω,μ), it is itself separable for the Lp topology. The conclusion follows from Theorem 15.10. □

The space L∞(Ω,μ) is more specific to the Radon measure μ. Indeed, if μ is a Dirac mass, then the space L∞(Ω,μ) can be identified to ℝ which is therefore separable. However, this property fails in general.

Theorem 15.12 (Nonseparability of Linfty for Lebesgue measure). If μ = λN is the Lebesgue measure, then L∞(Ω,λ N) is not separable.

Proof. If x ∈Ω and R > 0 are such that B(x,R) ⊂Ω, then the family {1B(x,r) : 0 < r < R} is uncountable and if 0 < r≠r′ < R, then

∥1B(x,r) −1B(x,r′)∥∞ = 1.

The conclusion follows from the non-separability criterion (Proposition 16.40). □

15.5 Convolution

In this section and in the next one, the ambient space is ℝN endowed with the Lebesgue measure λN. For simplicity, we write Lp(ℝN) simply as Lp when no confusion is possible.

Definition 15.13 (Convolution). Let u and v ∈Cc(ℝN), the convolution product u ∗ v is defined by

(u ∗ v)(x) := ∫ ℝNu(x − y)v(y)dy

for all x ∈ ℝN.

The next lemma asserts that u ∗ v belongs to Cc(ℝN). If one factor is smoother, one can expect more regularity on the convolution product. We recall that for any open set U ⊂ ℝN,

D(U) := Cc∞(U) := {u ∈C∞(U) : supp(u) is a compact subset of U}.

Lemma 15.14 (Support of a convolution). If u,v ∈Cc(ℝN) then u ∗ v ∈Cc(ℝN) and

supp(u ∗ v) ⊂supp(u) + supp(v)¯.

Proof. For every x ∈ ℝN, the function y↦u(x − y)v(y) is integrable. Since u is uniformly continuous and v has compact support, the dominated convergence Theorem shows that the function x↦(u ∗ v)(x) is continuous. Moreover, if x∉supp(u) + supp(v)¯, then x − y∉supp(u) for every y in supp(v), hence

u(x − y)v(y) = 0

for every y ∈ ℝN. Therefore (u ∗ v)(x) = 0, which proves the announced support inclusion. Since the right-hand side is compact, we conclude that u ∗ v ∈Cc(ℝN). □

Lemma 15.15 (Convolution is well-defined almost everywhere). If u ∈ L1(ℝN) and v ∈Cc∞(ℝN), then u ∗ v ∈C∞(ℝN) and for any multi-index α ∈ ℕN,

∂α(u ∗ v) = u ∗ (∂αv).

If moreover u = 0 a.e. in ℝN ∖ K for some compact set K ⊂ ℝN, then

supp(u ∗ v) ⊂ K + supp(v),

so that u ∗ v ∈Cc∞(ℝN).

Proof. It suffices to consider the case |α| = 1, the general case then follows by induction. Writing

(u ∗ v)(x) = ∫ ℝNu(y)v(x − y)dy,

we infer that

(u ∗ v)(x + hα) − (u ∗ v)(x) h = ∫ ℝNu(y)v(x + hα − y) − v(x − y) h dy.

By the mean value theorem,

|v(x + hα − y) − v(x − y) h | ≤∥∂αv∥ ∞

for all y ∈ ℝN and all h≠0. Since u ∈ L1(ℝN), the dominated convergence Theorem yields

∂α(u ∗ v)(x) = ∫ ℝNu(y)∂αv(x − y)dy = (u ∗ (∂αv))(x).

This proves that u ∗ v is of class C∞.

Assume now that u = 0 a.e. in ℝN ∖ K with K compact, and let x∉K + supp(v). If y ∈ K, then x − y∉supp(v), hence v(x − y) = 0. If y∉K, then u(y) = 0 for a.e. such y. Therefore u(y)v(x − y) = 0 for a.e. y ∈ ℝN, which gives (u ∗ v)(x) = 0. Thus

supp(u ∗ v) ⊂ K + supp(v).

Since the right-hand side is compact, u ∗ v belongs to Cc∞(ℝN). □

Lemma 15.16 (Young convolution inequality). For every 1 ≤ p ≤∞,

∥u ∗ v∥p ≤∥u∥p∥v∥1. (15.3)

Proof. Thanks to Fubini’s Theorem

∫ ℝN|(u ∗ v)(x)|dx = ∫ ℝN |∫ ℝNu(x − y)v(y)dy|dx ≤∫ ℝN ∫ ℝN|u(x − y)||v(y)|dydx = ∫ ℝN (∫ ℝN|u(x − y)|dx)|v(y)|dy = ∥u∥1∥v∥1,

which completes the case p = 1.

If now 1 < p < ∞, thanks to Hölder’s inequality and Fubini’s Theorem, we get

∫ ℝN|(u ∗ v)(x)|pdx = ∫ ℝN |∫ ℝNu(x − y)v(y)dy|pdx ≤∫ ℝN | (∫ ℝN|u(x − y)|p|v(y)|dy)1∕p (∫ ℝN|v(y)|dy)1−1∕p| pdx = ∥v∥1p−1 ∫ ℝN ∫ ℝN|u(x − y)|p|v(y)|dydx = ∥u∥pp∥v∥ 1p.

Finally, if p = ∞, we simply write

|(u ∗ v)(x)|≤∫ ℝN|u(x − y)||v(y)|dy ≤∥u∥∞∥v∥1

for all x ∈ ℝN. □

Corollary 15.17 (Extension of convolution to Lp × L1). For 1 ≤ p < ∞, the convolution product (u,v)↦u ∗ v from Cc(ℝN) ×C c(ℝN) to Cc(ℝN) extends uniquely into a continuous bilinear map from Lp(ℝN) × L1(ℝN) to Lp(ℝN). For p = ∞, the formula

(u ∗ v)(x) := ∫ ℝNu(x − y)v(y)dy

defines a continuous bilinear map from L∞(ℝN) × L1(ℝN) to L∞(ℝN). In all cases one has

∥u ∗ v∥p ≤∥u∥p∥v∥1.

Proof. For 1 ≤ p < ∞, the existence and uniqueness of the continuous extension follow from the density of Cc(ℝN) in Lp(ℝN) (see Theorem 15.10) together with the estimate (15.3) proved in Lemma 15.16.

For p = ∞, let u ∈ L∞(ℝN) and v ∈ L1(ℝN). For every x ∈ ℝN, the function y↦u(x − y)v(y) belongs to L1(ℝN). The value of the integral does not depend on the chosen representative of u, because translations preserve Lebesgue-negligible sets. Moreover

|(u ∗ v)(x)|≤∥u∥∞∥v∥1.

Hence u ∗ v is well defined and belongs to L∞(ℝN), with

∥u ∗ v∥∞ ≤∥u∥∞∥v∥1.

The bilinearity is immediate from the definition. □

Corollary 15.18 (Extension of convolution with compactly supported smooth functions). Moreover, if u ∈ Lp(ℝN) is such that u = 0 a.e. in ℝN ∖ K, for some compact set K ⊂ ℝN, and if v ∈Cc∞(ℝN), then u ∗ v ∈Cc∞(ℝN) and supp(u ∗ v) ⊂ K + supp(v).

Proof. Since K is compact, it has finite Lebesgue measure. Therefore u ∈ L1(ℝN). The conclusion now follows from Lemma 15.15. □

Definition 15.19 (Mollifiers). Let ρ ∈Cc∞(ℝN; [0, +∞)) be such that supp(ρ) ⊂ B(0, 1) and ∫ ℝNρ(x)dx = 1. For all n ∈ ℕ, we set ρn(x) := nNρ(nx). We say that the sequence (ρn)n∈ℕ is a sequence of mollifiers.

We observe that any sequence of mollifiers (ρn)n∈ℕ satisfies ∫ ℝNρn(x)dx = 1 and supp(ρn) ⊂ B(0, 1 n), for all n.

Lemma 15.20 (Uniform approximation by mollifiers). If u ∈Cc(ℝN), then u ∗ ρn converges uniformly to u as n → +∞.

Proof. Assume that u ∈Cc(ℝN). Then

|(u ∗ ρn)(x) − u(x)| = |∫ ℝN(u(x − y) − u(x))ρn(y)dy| ≤∫ B(0, 1 n)|u(x − y) − u(x)|ρn(y)dy ≤ sup ⁡{|u(z1) − u(z2)| : z1,z2 ∈ ℝN,|z 1 − z2|≤ 1∕n}→ 0as n → +∞

since u is uniformly continuous. Hence u ∗ ρn converges uniformly to u. □

Lemma 15.21 (Lp approximation by mollifiers). If u ∈ Lp(ℝN) for 1 ≤ p < ∞, then u ∗ ρn → u in Lp(ℝN) as n → +∞.

Proof. We first deal with the case where u ∈Cc(ℝN). Then, we use Hölder’s inequality with

fx(y) := (u(x − y) − u(x))(ρn(y))1 p

and g(y) := (ρn(y)) 1 p′, we get

|(u ∗ ρn)(x) − u(x)| = |∫ ℝNfx(y)g(y)dy| ≤∥fx∥p∥g∥p′.

But

∥fx∥p = (∫ ℝN|u(x − y) − u(x)|pρ n(y)dy)1 p  and ∥g∥p′ = (∫ ℝNρn(y)dy) 1 p′ = 1,

so that by Fubini’s Theorem, we get

∫ ℝN|(u ∗ ρn)(x) − u(x)|pdx ≤∫ ℝN ∫ ℝN|u(x − y) − u(x)|pρ n(y)dydx = ∫ B(0, 1 n) (∫ ℝN|u(x − y) − u(x)|pdx)ρ n(y)dy ≤ sup ⁡ y∈B(0, 1 n)∥τyu − u∥pp,

where τyu(x) := u(x − y) is the translation of u by y. On B(0, 1) + supp(u) the uniform convergence implies the convergence in Lp(ℝN), hence sup ⁡ y∈B(0, 1 n)∥τyu − u∥pp and thus ∥u ∗ ρn − u∥p converge to 0 as n → +∞.

The general case u ∈ Lp(ℝN) follows from the density of Cc(ℝN) in Lp(ℝN) (Theorem 15.10). More precisely, let 𝜀 > 0. Choose u~ ∈Cc(ℝN) such that

∥u −u~∥p < 𝜀.

By the compact-support case proved above, there exists n0 such that

∥u~ ∗ ρn −u~∥p < 𝜀

for every n ≥ n0. Then, for n ≥ n0,

∥u ∗ ρn − u∥p ≤∥(u −u~) ∗ ρn∥p + ∥u~ ∗ ρn −u~∥p + ∥u~ − u∥p ≤∥u −u~∥p∥ρn∥1 + ∥u~ ∗ ρn −u~∥p + ∥u~ − u∥p < 3𝜀,

where we used (15.3) and the fact that ∥ρn∥1 = 1. This proves that ∥u ∗ ρn − u∥p → 0 as n → +∞. □

Remark 15.22 (Continuity of translations in Lp). Let us observe that proceeding as in the proof above we can prove that for any 1 ≤ p < ∞, for any u ∈ Lp(ℝN), sup ⁡ y∈B(0,δ)∥τyu − u∥p goes to 0 as δ → 0.

Corollary 15.23 (Density of smooth compactly supported functions). For every open set Ω ⊂ ℝN and every 1 ≤ p < ∞, the space Cc∞(Ω) is dense in Lp(Ω).

Proof. From Theorem 15.10, for every u ∈ Lp(Ω) and every 𝜀 > 0, there exist v ∈Cc(Ω) such that

(∫ Ω|u − v|pdx)1∕p < 𝜀 2.

Extend v by zero outside Ω and denote by v~ this extension. Then v~ ∈Cc(ℝN) and supp(v~) ⊂Ω. By Lemma 15.20, we can choose n0 ∈ ℕ large enough so that for all n ≥ n0,

(∫ ℝN|v~ − (v~ ∗ ρn)|pdx)1∕p < 𝜀 2.

By Corollary 15.18, we have

supp(v~ ∗ ρn) ⊂supp(v~) + supp(ρn)¯ ⊂supp(v~) + B(0, 1∕n)¯.

Hence, for

n > max ⁡ {n0, 1 dist(supp(v~), ℝN ∖Ω) } ,

we have supp(v~ ∗ ρn) ⊂Ω, so that v~ ∗ ρn, viewed as a function on Ω, belongs to Cc∞(Ω) and

(∫ Ω|u − (v~ ∗ ρn)|pdx)1∕p < 𝜀.
□

15.6 Duality in the Lebesgue spaces

In the present chapter, μ is a positive Radon measure on an open subset Ω of ℝN.

15.6.1 Uniform convexity and smoothness of the Lp spaces

Proposition 15.24 (Uniform convexity of Lp). For every 1 < p < ∞, the space Lp(Ω,μ) is uniformly convex.

The proof is essentially based on the strict convexity of the map s↦sp. More precisely we will rely on the following scalar lemma.

Lemma 15.25 (Key lemma for Lp duality). For any 𝜀 > 0, there exists δ > 0 such that for any s,t in ℝ with |s|≤ 1, |t|≤ 1 and |s − t|≥ 2𝜀, then

|s + t 2 | p ≤ (1 − δ)|s|p + |t|p 2 .

Proof. Let 𝜀 > 0. We first reduce the proof to the normalized case. Let s,t in ℝ be such that |s|≤ 1, |t|≤ 1, and |s − t|≥ 2𝜀. Set

A := (|s|p + |t|p 2 ) 1∕p.

Since |s − t| > 0, at least one of the numbers s and t is nonzero, hence A > 0. Moreover A ≤ 1. Define

σ := s A and τ := t A.

Then

|σ|p + |τ|p 2 = 1 and |σ − τ| = |s − t| A ≥|s − t|≥ 2𝜀.

Therefore it is enough to prove the lemma under the additional normalization

|s|p + |t|p 2 = 1.

Consider the set

E𝜀 := {(a,b) ∈ ℝ2 : |a|p + |b|p 2 = 1 and |a − b|≥ 2𝜀}.

It is a closed and bounded subset of ℝ2, hence it is compact. The function

F(a,b) := 1 − |a + b 2 | p

is continuous on E𝜀. It is thus enough to show that F is everywhere positive on E𝜀.

Assume by contradiction that F(a,b) = 0 for some (a,b) in E𝜀. Then

1 = |a + b 2 | ≤|a| + |b| 2 ≤ (|a|p + |b|p 2 ) 1∕p = 1.

Therefore both inequalities are equalities. Since p > 1, the map r↦rp is strictly convex on [0,∞), so equality in the second inequality implies |a| = |b|. Together with the normalization, this gives |a| = |b| = 1. Equality in the triangle inequality now implies that a and b have the same argument, hence a = b. This contradicts the condition |a − b|≥ 2𝜀. We have thus proved that F > 0 on E𝜀.

By compactness, the minimum

δ := min ⁡ (a,b)∈E𝜀F(a,b)

is well defined and satisfies δ > 0. Returning to the original pair (s,t), we obtain

|s + t 2 | p = Ap |σ + τ 2 | p ≤ (1 − δ)Ap = (1 − δ)|s|p + |t|p 2 ,

which is the desired estimate. □

Nevertheless, one needs to pass from pointwise inequalities to uniform integral inequalities.

Proof. Let 𝜀 > 0. It suffices to prove that there exists δ > 0 such that for any u,v in Lp(Ω,μ) with ∥u∥Lp(Ω,μ) ≤ 1, ∥v∥Lp(Ω,μ) ≤ 1 and ∥u − v∥Lp(Ω,μ) ≥ 2𝜀, then

∥u + v 2 ∥ Lp(Ω,μ) ≤ 1 − δ.

Let us define

A := {x ∈Ω : |u(x) − v(x)|p > 𝜀p 2 (|u(x)|p + |v(x)|p)} .

Let us define r(x) := max ⁡(|u(x)|,|v(x)|). By definition of A, r(x) > 0 for any x ∈ A, and

|u(x) r(x) −v(x) r(x) | ≥ 𝜀 21 p .

Thanks to Lemma 15.25 we deduce the existence of δ > 0 such that

|u(x) + v(x) 2 | p ≤ (1 − δ) (|u(x)|p + |v(x)|p 2 )

for any x ∈ A. On the other hand, for any x ∈Ω ∖ A, by convexity of the map s↦|s|p,

|u(x) + v(x) 2 | p ≤|u(x)|p + |v(x)|p 2 .

Integrating over the corresponding domains and setting

I := ∫ Ω|u(x)|p + |v(x)|p 2 dμ −∫ Ω |u(x) + v(x) 2 | pdμ,

we obtain

I ≥∫ A|u(x)|p + |v(x)|p 2 dμ −∫ A |u(x) + v(x) 2 | pdμ ≥∫ A|u(x)|p + |v(x)|p 2 dμ − (1 − δ) ∫ A|u(x)|p + |v(x)|p 2 dμ ≥ δ 2 max ⁡(∥u∥Lp(A,μ)p,∥v∥ Lp(A,μ)p).

Since ∥u∥Lp(Ω,μ) ≤ 1 and ∥v∥Lp(Ω,μ) ≤ 1, the quantity I is less than

1 − ∥u + v 2 ∥ Lp(Ω,μ)p.

On the other hand, by definition of A,

(∫ Ω∖A|u − v|pdμ)1∕p ≤ 𝜀 21∕p (∫ Ω∖A|u|pdμ + ∫ Ω∖A|v|pdμ)1∕p ≤ 𝜀.

As a consequence,

∥u − v∥Lp(A,μ) ≥∥u − v∥Lp(Ω,μ) −∥u − v∥Lp(Ω∖A,μ) ≥ 𝜀,

so that, using the triangle inequality, we get

max ⁡(∥u∥Lp(A,μ),∥v∥Lp(A,μ)) ≥ 𝜀 2.

As a consequence,

1 − ∥u + v 2 ∥ Lp(Ω,μ)p ≥ δ 2(𝜀 2)p

so that

∥u + v 2 ∥ Lp(Ω,μ) ≤ (1 −δ 2(𝜀 2)p) 1∕p ≤ 1 − δ′,

for δ′ = δ 2p(𝜀 2)p and the conclusion follows. □

Proposition 15.26 (Duality map for Lp). For every 1 < p < ∞, the space Lp(Ω,μ) is smooth and for any u in Lp(Ω,μ) ∖ 0 and any v in Lp(Ω,μ),

D∥⋅∥p(u)(v) = ∥u∥p1−p ∫ Ω|u|p−2uvdμ.

Proof. Note that u↦∥u∥Lp(Ω,μ) is the composition of u↦∥u∥Lp(Ω,μ)p and the map g : s↦s1∕p. Hence, it is enough to prove that for any u in Lp(Ω,μ) ∖ 0 and for any v in Lp(Ω,μ), the function

𝜀↦∫ Ω|u + 𝜀v|pdμ

admits a derivative at 0. For μ-a.e. x in Ω,

lim ⁡ 𝜀→0|u(x) + 𝜀v(x)|p −|u(x)|p 𝜀 = p|u(x)|p−2u(x)v(x).

Moreover, for every x in Ω and every 𝜀 with 0 < |𝜀| < 1, the mean value theorem gives some 𝜃𝜀(x) between 0 and 𝜀 such that

|u(x) + 𝜀v(x)|p −|u(x)|p 𝜀 = p|u(x) + 𝜃𝜀(x)v(x)|p−2(u(x) + 𝜃 𝜀(x)v(x))v(x).

Therefore

||u(x) + 𝜀v(x)|p −|u(x)|p 𝜀 | ≤ p|u(x) + 𝜃𝜀(x)v(x)|p−1|v(x)| ≤ Cp (|u(x)|p−1|v(x)| + |v(x)|p ),

where Cp > 0 only depends on p, because |a + b|p−1 ≤ C p(|a|p−1 + |b|p−1) for all a,b in ℝ. The right-hand side belongs to L1(Ω,μ) by Hölder’s inequality. Hence the dominated convergence theorem yields

lim ⁡ 𝜀→0∥u + 𝜀v∥Lp(Ω,μ)p −∥u∥ Lp(Ω,μ)p 𝜀 = p∫ Ω|u|p−2uvdμ.

By the chain rule formula, we obtain that

D(g ∘∥⋅∥Lpp)(u).v = Dg(∥u∥ Lpp). (D∥⋅∥ Lpp)(u).v ) = g′(∥u∥ Lpp) (D∥⋅∥ Lpp)(u).v ) = ∥u∥Lp(Ω,μ)1−p ∫ Ω|u|p−2uvdμ. □

Remark 15.27 (Duality map and equality cases). For μ = λN, the previous results fail for p = 1 or ∞, i.e., neither L1(Ω,λ N) nor L∞(Ω,λ N) are uniformly convex nor smooth.

15.6.2 Duality in the Lebesgue spaces

We now use the smoothness result above together with the factorization theorem stated in the appendix.

Theorem 15.28 (Lp duality theorem). For 1 < p < ∞, the dual of the space Lp(Ω,μ) is isometrically isomorphic to Lp′(Ω,μ), where

p′ := p p − 1.

More precisely, for any f in (Lp(Ω,μ))′, there exists a unique v in Lp′(Ω,μ) such that

f(u) = ∫ Ωuvdμ

for all u in Lp(Ω,μ), and

∥f∥(Lp(Ω,μ))′ = ∥v∥Lp′(Ω,μ).

Proof. Step 1. Local signed measures on compact exhaustions. If f = 0, the conclusion is immediate with v = 0. Assume now that f ∈ (Lp(Ω,μ))′∖{0}. Thanks to Theorem 16.52, there exists a unique w ∈ Lp(Ω,μ) with ∥w∥Lp(Ω,μ) = 1 such that for all u ∈ Lp(Ω,μ),

f(u) = ∥f∥(Lp(Ω,μ))′D∥⋅∥(w)(u).

Using Proposition 15.26, we obtain

f(u) = ∥f∥(Lp(Ω,μ))′∥w∥p1−p ∫ Ωu|w|p−2wdμ = ∫ Ωuvdμ,

with

v := ∥f∥(Lp(Ω,μ))′∥w∥p1−p|w|p−2w.

Since w ∈ Lp(Ω,μ) with ∥w∥Lp(Ω,μ) = 1, we have that v ∈ Lp′(Ω,μ) and

∥v∥Lp′(Ω,μ) = ∥f∥(Lp(Ω,μ))′.

It remains to prove uniqueness. Let v in Lp′(Ω,μ) be such that

∫ Ωuvdμ = 0

for all u ∈ Lp(Ω,μ). We choose

w := |v|p′−1sgn(v).

where sgn(t) = 1 if t > 0, sgn(t) = −1 if t < 0, and sgn(0) = 0. Since

|w|p = |v|(p′−1)p = |v|p′ ,

the function w belongs to Lp(Ω,μ). Therefore

0 = ∫ Ωwvdμ = ∫ Ω|v|p′ dμ,

which implies v = 0 almost everywhere. Thus the representing function is unique. Since the function constructed above already satisfies

∥v∥Lp′(Ω,μ) = ∥f∥(Lp(Ω,μ))′,

the proof is complete. □

15.7 Weak convergence in the Lebesgue spaces Lp

We now return to weak convergence, this time in the genuine Banach-space sense. For 1 < p < ∞, Theorem 15.28 identifies the dual of Lp(Ω,μ) with Lp′(Ω,μ). This should be distinguished from the earlier convergence against C0(Ω) test functions introduced in Definition 14.14, which came from the embedding of L1(Ω,μ) into M(Ω). We first consider the case 1 < p < ∞.

Definition 15.29 (Weak convergence in Lp). Let 1 < p < ∞, we say that a sequence (un) ⊂ Lp(Ω,μ) converges weakly to u in Lp(Ω,μ) if for any v in Lp′(Ω,μ),

∫ Ωunvdμ →∫ Ωuvdμas n → +∞.

Since 1 < p′ < ∞, the separability result proved above shows that Lp′(Ω,μ) is separable. Applying the sequential Banach–Alaoglu theorem from the appendix (Theorem 16.58) to X = Lp′(Ω,μ) and using Theorem 15.28 with the exponent p′ to identify Lp(Ω,μ) with (Lp′(Ω,μ))′, we deduce that every bounded sequence in Lp(Ω,μ) admits a subsequence which converges weakly in the sense of Definition 15.29.

Theorem 15.30 (L1 duality theorem). The dual of the space L1(Ω,μ) is isometrically isomorphic to L∞(Ω,μ). More precisely, for any f ∈ (L1(Ω,μ))′, there exists a unique v ∈ L∞(Ω,μ) such that

f(u) = ∫ Ωuvdμ, (15.4)

for all u ∈ L1(Ω,μ), and

∥f∥(L1(Ω,μ))′ = ∥v∥L∞(Ω,μ).

Proof. Step 1. Local Radon–Nikodym representations. If f = 0, the conclusion is immediate with v = 0. Let f ∈ (L1(Ω,μ))′ and, for n ≥ 1, set

Kn := {x ∈Ω : dist(x,Ωc) ≥ 1∕n and ∥x∥ ℝN ≤ n}.

Then each Kn is compact, (Kn)n≥1 is increasing, ∪n≥1Kn = Ω, and μ(Kn) < ∞ because μ is a positive Radon measure.

For every n ≥ 1, let

An := {E ∈A : E ⊂ Kn}

and define

νn(E) := f(1E)

for every E ∈An. Since μ(E) ≤ μ(Kn) < ∞, the function 1E belongs to L1(Ω,μ), so νn is well defined. It is immediate that νn is a finite signed measure on (Kn,An). Moreover, if μ(E) = 0, then 1E = 0 in L1(Ω,μ), hence νn(E) = 0. Thus νn is absolutely continuous with respect to the restriction of μ to An.

Step 2. Local Radon–Nikodym densities and uniform bounds. By Corollary 12.5, there exists gn ∈ L1(K n,μ) such that

νn(E) = ∫ Egndμ

for every E ∈An. Step 2. Uniform L∞ bound on the local densities. We claim that

∥gn∥L∞(Kn,μ) ≤∥f∥(L1(Ω,μ))′.

Assume on the contrary that there exist 𝜀 > 0 and a measurable set A ⊂ Kn with μ(A) > 0 such that

|gn| > ∥f∥(L1(Ω,μ))′ + 𝜀

almost everywhere on A. Set

u := 1Asgn(gn).

Then u ∈ L1(Ω,μ) and

|f(u)| = |∫ Agnsgn(gn)dμ| = ∫ A|gn|dμ > (∥f∥(L1(Ω,μ))′ + 𝜀)μ(A),

whereas

|f(u)|≤∥f∥(L1(Ω,μ))′∥u∥L1(Ω,μ) = ∥f∥(L1(Ω,μ))′μ(A).

This contradiction proves the claim.

Step 3. Compatibility and construction of the global density.

Step 3. Gluing the local densities. If E ∈An, then

∫ Egn+1dμ = f(1E) = ∫ Egndμ.

By the uniqueness statement in the Radon–Nikodym theorem, gn+1 = gn almost everywhere on Kn. We now define a measurable function v on Ω by

v = g1 on K1,v = gn on Kn ∖ Kn−1 for n ≥ 2.

From the uniform L∞ bound above, we infer that

∥v∥L∞(Ω,μ) ≤∥f∥(L1(Ω,μ))′.

Step 4. Representation of the functional.

Step 4. Representation first for compactly supported functions, then for all L1 functions. Let now u in L1(Ω,μ) be supported in some Kn. If u is a simple function, say

u = ∑ j=1ma j1Ej

with Ej ∈An, then

f(u) = ∑ j=1ma jf(1Ej) = ∑ j=1ma j ∫ Ejgndμ = ∫ Ωuvdμ.

Since simple functions are dense in L1(K n,μ), the same identity holds for every u ∈ L1(Ω,μ) supported in Kn.

For a general u ∈ L1(Ω,μ), we set

un := u1Kn.

Then un → u in L1(Ω,μ) as n → +∞ by the dominated convergence theorem. Since each un is supported in Kn, we have

f(un) = ∫ Ωunvdμ.

Passing to the limit and using v ∈ L∞(Ω,μ), we obtain

f(u) = ∫ Ωuvdμ

for every u ∈ L1(Ω,μ). This proves the existence of a representing function v.

Step 5. Uniqueness and norm identity.

Step 5. Uniqueness of the representing function. To prove uniqueness, let v1,v2 ∈ L∞(Ω,μ) be such that

∫ Ωuv1dμ = ∫ Ωuv2dμ

for every u ∈ L1(Ω,μ). If

A := {x ∈Ω : v1(x)≠v2(x)}

had positive measure, there would exist n ≥ 1 such that μ(A ∩ Kn) > 0. Taking

u := 1A∩Knsgn(v1 − v2),

we would get

0 = ∫ Ωu(v1 − v2)dμ = ∫ A∩Kn|v1 − v2|dμ > 0,

a contradiction. Hence v1 = v2 almost everywhere.

Step 6. Norm identity. Finally, we already know that

∥v∥L∞(Ω,μ) ≤∥f∥(L1(Ω,μ))′.

Conversely, let 𝜀 > 0 and set

A𝜀 := {x ∈Ω : |v(x)| > ∥v∥L∞(Ω,μ) − 𝜀}.

By the definition of the essential supremum, μ(A𝜀) > 0. Since Ω = ∪n≥1Kn, there exists n ≥ 1 such that μ(A𝜀 ∩ Kn) > 0. Taking

u := 1A𝜀∩Knsgn(v),

we get

∥f∥(L1(Ω,μ))′μ(A𝜀 ∩ Kn) ≥|f(u)| = ∫ A𝜀∩Kn|v|dμ ≥ (∥v∥L∞(Ω,μ) − 𝜀)μ(A𝜀 ∩ Kn).

Hence

∥f∥(L1(Ω,μ))′ ≥∥v∥L∞(Ω,μ) − 𝜀.

Letting 𝜀 → 0, we conclude that

∥f∥(L1(Ω,μ))′ ≥∥v∥L∞(Ω,μ).

Therefore

∥f∥(L1(Ω,μ))′ = ∥v∥L∞(Ω,μ).
□

Thanks to Theorem 15.30, we can now define weak convergence in L1(Ω,μ) in the usual Banach-space sense.

Definition 15.31 (Weak convergence in L1). We say that a sequence (un)n in L1(Ω,μ) converges weakly to u in L1(Ω,μ) if for every v in L∞(Ω,μ),

∫ Ωunvdμ →∫ Ωuvdμ as n →∞.

Since C0(Ω) ⊂ L∞(Ω,μ), weak convergence in L1(Ω,μ) implies convergence against C0(Ω) test functions in the sense of Definition 14.14.

Theorem 15.32 (Dunford–Pettis theorem: weak convergence implies equi-integrability). Assume that Ω is an open subset of ℝN such that μ(Ω) < ∞. Let (un) be a sequence in L1(Ω,μ), and let u be in L1(Ω,μ). If

un ⇀ u

weakly in L1(Ω,μ), then the sequence (un) is equi-integrable.

Proof. Step 1. Pointwise convergence of the associated signed measures. For every n ≥ 1, define a finite signed measure νn on B(Ω) by

νn(E) := ∫ Eundμ.

For every Borel set E ⊂Ω, the characteristic function 1E belongs to L∞(Ω,μ). The weak convergence of un to u in L1(Ω,μ) gives

νn(E) →∫ Eudμas n → +∞

for every E in B(Ω). Moreover,

νn ≪ μ

for every n ≥ 1.

Step 2. Uniform absolute continuity of the signed measures. Let 𝜀 > 0. Lemma 12.4, applied with 𝜀∕6 in place of 𝜀, gives δ > 0 such that

μ(B) < δ⟹ sup ⁡ n≥1 |∫ Bundμ| ≤ 𝜀 2

for every Borel set B ⊂Ω.

Step 3. Passage from signed estimates to estimates of absolute values. Let E be a Borel set such that μ(E) < δ. For every n ≥ 1, set

En+ := E ∩{u n ≥ 0},En− := E ∩{u n < 0}.

Then μ(En+) < δ and μ(En−) < δ. Hence

∫ E|un|dμ = ∫ En+undμ −∫ En−undμ ≤ |∫ En+undμ| + |∫ En−undμ| ≤ 𝜀.

Taking the supremum in n proves that (un) is equi-integrable. □

Theorem 15.33 (Dunford–Pettis theorem: weak compactness in finite measure). Assume that Ω is an open subset of ℝN such that μ(Ω) < ∞. Let (un) be a bounded and equi-integrable sequence in L1(Ω,μ). Then there exist a subsequence (unk) and a function u in L1(Ω,μ) such that

unk ⇀ u

weakly in L1(Ω,μ).

Proof. Step 1. Diagonal extraction on a countable generating algebra. Let E0 be the algebra of all finite unions of sets of the form

Ω∩]a1,b1] ×⋯×]aN,bN],

where a1,…,aN,b1,…,bN are rational numbers with ai < bi for every i. The algebra E0 is countable and generates B(Ω). Set

M := sup ⁡ n≥1∥un∥L1(Ω,μ) < +∞.

For every A in E0 and every n ≥ 1, we have

|∫ Aundμ| ≤∥un∥L1(Ω,μ) ≤ M.

Thus, for each fixed A in E0, the sequence of real numbers (∫ Aundμ)n≥1 is bounded. By a diagonal extraction on the countable family E0, we can choose a subsequence (unk)k≥1 of (un) such that for every A in E0, the numerical sequence

(∫ Aunkdμ)k≥1

converges.

Step 2. Convergence of the integrals on every Borel set. We fix a Borel set E ⊂Ω and prove that

(∫ Eunkdμ)k≥1

converges. Let 𝜀 > 0. By equi-integrability, there exists δ > 0 such that

μ(B) < δ⟹ sup ⁡ k≥1 ∫ B|unk|dμ ≤ 𝜀

for every Borel set B. By Corollary 3.11, there exists A in E0 such that

μ(E△A) < δ.

Then, for all k,ℓ ≥ 1,

|∫ Eunkdμ −∫ Eunℓdμ| ≤ |∫ Aunkdμ −∫ Aunℓdμ| + ∫ E△A|unk|dμ + ∫ E△A|unℓ|dμ ≤ |∫ Aunkdμ −∫ Aunℓdμ| + 2𝜀.

The first term tends to 0 as k,ℓ → +∞, by the choice of the subsequence. Thus the sequence of integrals over E is Cauchy, and therefore converges.

Step 3. Construction of the limit signed measure. For every Borel set E ⊂Ω, define

λ(E) := lim ⁡ k→∞∫ Eunkdμ.

The measure is finite-valued. Indeed, with the constant M introduced in Step 1, we have

|λ(E)|≤limsup ⁡k→∞∫ E|unk|dμ ≤ M

for every Borel set E ⊂Ω. The set function λ is finitely additive because each map

E↦∫ Eunkdμ

is finitely additive. We prove that λ is countably additive. Let (Ej)j≥1 be a sequence of pairwise disjoint Borel sets, and set

E := ⋃ j=1∞E j,Rm := E ∖⋃ j=1mE j.

Then (Rm) is decreasing and ∩m≥1Rm = ∅. Since R1 ⊂Ω and μ(Ω) < ∞, the continuity from above statement, namely item 2 of Theorem 2.3, gives

μ(Rm) → 0as m → +∞.

Given 𝜀 > 0, equi-integrability gives δ > 0 such that every Borel set B with μ(B) < δ satisfies

sup ⁡ k≥1 ∫ B|unk|dμ ≤ 𝜀.

Since μ(Rm) → 0, there exists an integer m0 such that μ(Rm) < δ for every m ≥ m0. Therefore

sup ⁡ k≥1 ∫ Rm|unk|dμ ≤ 𝜀

for every m ≥ m0. For such an m, finite additivity gives

|λ(E) −∑ j=1mλ(E j)| = |λ(Rm)| = lim ⁡ k→∞ |∫ Rmunkdμ| ≤ sup ⁡ k≥1 ∫ Rm|unk|dμ ≤ 𝜀.

Hence

λ(E) = ∑ j=1∞λ(E j).

Thus λ is a finite signed Borel measure on Ω.

If μ(E) = 0, then equi-integrability gives

sup ⁡ k≥1 ∫ E|unk|dμ = 0,

hence λ(E) = 0. Therefore

λ ≪ μ.

Step 4. Identification by Radon–Nikodym. By Corollary 12.5, there exists u in L1(Ω,μ) such that

λ(E) = ∫ Eudμ

for every Borel set E ⊂Ω.

Step 5. Weak convergence of the extracted subsequence. Let v be in L∞(Ω,μ). We choose a measurable representative, still denoted by v, such that

|v(x)|≤∥v∥L∞(Ω,μ)

for μ-almost every x in Ω. By Theorem 15.9, there exists a sequence (sm)m≥1 of bounded simple measurable functions such that

|sm(x) − v(x)|≤ 2−m

for μ-almost every x in Ω. For every m ≥ 1 and every k ≥ 1, we have

|∫ Ω(unk − u)vdμ| ≤ |∫ Ω(unk − u)smdμ| + ∫ Ω|unk − u||v − sm|dμ ≤ |∫ Ω(unk − u)smdμ| + 2−m (∥u nk∥L1(Ω,μ) + ∥u∥L1(Ω,μ)) .

Since (un) is bounded in L1(Ω,μ), the second term is bounded above by

2−m (sup ⁡ n≥1∥un∥L1(Ω,μ) + ∥u∥L1(Ω,μ)) .

For fixed m, the function sm is a finite linear combination of characteristic functions of Borel sets. By the definition of λ, we therefore have

∫ Ωunksmdμ →∫ Ωusmdμas k → +∞.

We first let k → +∞, and then let m → +∞. This proves that

∫ Ωunkvdμ →∫ Ωuvdμas k → +∞

for every v in L∞(Ω,μ). Hence unk ⇀ u weakly in L1(Ω,μ). □

Remark. On infinite-measure spaces, equi-integrability alone is not enough for the compactness conclusion of Theorem 15.33. We also need the same spatial tail condition as in Definition 11.14: mass must not escape to infinity. In the present Euclidean Radon setting, this condition is naturally written as compact tightness. For every 𝜀 > 0, there should exist a compact set K𝜀 ⊂Ω such that

sup ⁡ n≥1 ∫ Ω∖K𝜀|un|dμ < 𝜀.

Equivalently, for any standard compact exhaustion (Kj)j≥1 of Ω which eventually contains every compact subset of Ω, the condition reads

lim ⁡ j→+∞ sup ⁡ n≥1 ∫ Ω∖Kj|un|dμ = 0.

For example, if Ω≠ℝN, one may take

Kj := {x ∈Ω : |x|≤ j and d(x, ℝN ∖Ω) ≥ 1∕j},

and if Ω = ℝN, one may take Kj = B¯(0,j). This is exactly the compact-set form of the uniform tail condition used in the σ-finite Vitali theorems.

Let us stress that a bounded sequence of L1(Ω,μ) functions may converge against C0(Ω) test functions to a measure which is not given by an element of L1(Ω,μ), as in the case of approximations to the identity.
