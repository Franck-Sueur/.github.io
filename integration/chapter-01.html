Chapter 1
σ-algebras

We introduce the collections of subsets that will serve as measurable sets throughout the notes. The chapter starts from the abstract definition, then explains how σ-algebras are generated, how Borel σ-algebras arise from topology, and why the completed real line will be useful for extended-valued functions.

1.1 First definitions

This is the first fundamental notion in measure theory. The elements of a σ-algebra are precisely the subsets of a set that will be declared measurable. A measure will later assign sizes only to the sets in such a collection.

In the following, if X is a set, we denote by P(X) its power set, that is, the set of all subsets of X, the empty set ∅ and the set X being included. If A ⊂ X, we denote by A∁ := X ∖ A its complement in X.

Definition 1.1 (σ-algebras). Let X be a set. A collection A ⊂P(X) is a σ-algebra on X if the following properties are satisfied:

1.
X ∈A,
2.
if A ∈A then A∁ ∈A,
3.
for every family (Ai)i∈I of elements of A indexed by a countable set I, we have ⋃ ⁡ i∈IAi ∈A.

Definition 1.2 (Measurable spaces). Let X be a set and let A be a σ-algebra on X. The pair (X,A) is called a measurable space.

Remark 1.3 (Countable and uncountable sets). Recall that a set E is countable if it is finite or if there exists a bijection from ℕ onto E. Equivalently, E injects into ℕ. Otherwise, E is said to be uncountable. Every subset of ℕ is countable. Finite products of countable sets, countable unions of countable sets, and the set of rational numbers ℚ are countable. On the other hand, Cantor’s theorem shows that the set of real numbers ℝ is uncountable. Consequently, the set ℝ ∖ ℚ of irrational numbers is uncountable. Finally, note that if E is a countable infinite set, then there exists a bijection φ: ℕ → E, so that the elements of E can be enumerated as E = {e1,e2,…,en,…}.

Let us give two examples of σ-algebras available for any set X:

  • the set P(X) is a σ-algebra on X,
  • the set {∅,X} is also a σ-algebra on X.

1.2 Main properties

Here are a few properties easily derived from the definition.

Lemma 1.4 (Elementary properties of σ-algebras). Let X be a set and A a σ-algebra on X. We have the following:

(a)
The empty set ∅ is in A,
(b)
any countable intersection of elements of A is still an element of A,
(c)
if A,B ∈A then A ∖ B ∈A.

Proof. To prove (a), combine axioms 1) and 2). For (b), if (Ai)i∈I is a countable family in A, then De Morgan’s formula gives

⋂ i∈IAi = (⋃ i∈IAi∁)∁,

and axioms 2) and 3) apply. For (c), note that A ∖ B = A ∩ B∁ and use (b) and axiom 2). □

The following result states that any intersection of σ-algebras is a σ-algebra.

Lemma 1.5 (Intersections of σ-algebras). Let X be a set. Let I≠∅ be any set of indices and let (Ai)i∈I be a family of σ-algebras on X, then the intersection

⋂ i∈IAi := {A ⊂ X : ∀ ⁡i ∈ I,A ∈Ai},

is a σ-algebra on X.

Proof. The set X belongs to every Ai, hence to the intersection. If A belongs to the intersection, then A belongs to every Ai, and therefore A∁ belongs to every Ai. Finally, if (An)n≥1 is a sequence of elements of the intersection, then each An belongs to every Ai, so ⋃ ⁡ n≥1An belongs to every Ai. Thus the intersection is a σ-algebra. □

In particular, this result allows us to prove the following consequence.

Lemma 1.6 (Generated σ-algebra). Let X be a set and let E ⊂P(X). Let S denote the set of all σ-algebras on X containing E. We set

σ(E) := ⋂ B∈SB.

Then σ(E) is the smallest σ-algebra on X containing E.

The σ-algebra σ(E) is called the σ-algebra generated by E on X. To say that σ(E) is the smallest σ-algebra on X containing E means that σ(E) is a σ-algebra on X, that E ⊂ σ(E), and that every σ-algebra A on X containing E satisfies σ(E) ⊂A.

Proof. We observe that S≠∅ because P(X) ∈S. By the previous lemma, σ(E) is a σ-algebra on X. Moreover, for every B in S, we have E ⊂B. Therefore E ⊂ σ(E). Thus σ(E) is a σ-algebra on X and contains E.

Furthermore, if A is another σ-algebra on X containing E, then A ∈S. Since σ(E) is the intersection of all elements of S, we have σ(E) ⊂A. □

1.3 σ-algebra associated with a topological space

It is important not to mix the axioms defining the notion of σ-algebra with those defining the notion of topology, especially since the following definition canonically associates a σ-algebra with any topology.

Definition 1.7 (Borel σ-algebra). Let (X,τ) be a topological space (i.e. τ forms the collection of open sets of X). The Borel σ-algebra of X relative to the topology τ is

B(X) := σ(τ).

An element of B(X) is a Borel set of X (relative to τ). When the topology is clear from the context, we suppress it from the notation.

The following properties are easy to obtain.

Proposition 1.8 (Elementary properties of Borel σ-algebras). Let (X,τ) be a topological space, and let B be the associated Borel σ-algebra. We have the following properties.

(i)
Any closed subset of X is an element of B,
(ii)
Any countable union of closed subsets of X is an element of B,
(iii)
Any countable intersection of open sets of X is an element of B.

Proof. If F is closed, then Fc is open and therefore belongs to τ ⊂B. Since B is stable by complements, F belongs to B. Countable unions of closed sets then belong to B by countable stability. Finally, if (Un)n≥1 is a sequence of open sets, then

⋂ n=1∞U n = (⋃ n=1∞U nc) c,

and the right-hand side is Borel. □

In the special case of the Euclidean space ℝn, for n ≥ 1, let Dn be the family of open blocks

D((xi)i, (yi)i) := {(z1,z2,…,zn) ∈ ℝn: ∀ ⁡i,x i < zi < yi},

where the pairs ((xi)i, (yi)i) vary among the n-tuples of real numbers satisfying xi < yi for 1 ≤ i ≤ n. Then

B(ℝn) = σ(D n).

Indeed, the subfamily of blocks with rational endpoints is countable and forms a basis of the Euclidean topology: for every open set U and every x in U, there is a rational block D such that x is in D ⊂ U. Hence every open set is the union of the rational blocks contained in it, and this is a countable union. Since every block is open, this proves that the open sets generate exactly σ(Dn). In particular, in the case n = 1, the Borel σ-algebra of ℝ is σ(I), where I is the family of open intervals of ℝ. Recall that the usual absolute value |⋅| equips ℝ with a metric topology that we call the standard topology of ℝ. If we fix any norm ∥⋅∥ on ℝn, then ℝn is endowed with the associated metric topology. This topology is independent of the chosen norm, since all norms are equivalent on the same finite-dimensional space. We call it the standard topology of ℝn.

1.4 A few words on the completed real line

In what follows, we will have to consider functions that can take on infinite values (think, for example, of the function x↦1∕x, which is integrable on ]0, 1] and tends to + ∞ as x → 0+). We define

ℝ¯ = ℝ ∪{−∞, +∞},

and generalized “intervals”:

]a, +∞] =]a, +∞[∪{+∞},[−∞,b[=] −∞,b[∪{−∞},
[a, +∞] = [a, +∞[∪{+∞},[−∞,b] =] −∞,b] ∪{−∞},

for all a,b ∈ ℝ. We endow ℝ¯ with the topology generated by the basis consisting of the intervals

]a,b[,[−∞,b[,]a, +∞],

with a,b in ℝ and a < b. Equivalently, it is enough to use rational endpoints; this gives a countable basis. This topology is called the standard topology of ℝ¯. If G denotes the family consisting of the open intervals of ℝ and the intervals ]a, +∞] and [−∞,b[, for all a,b in ℝ, then

B(ℝ¯) = σ(G).

Indeed, the topology is generated by G, and the rational-endpoint subfamily shows that every open subset of ℝ¯ is a countable union of elements of G.

Next chapter introduces the concept of a measure on a measurable space. Such measures can take infinite values, i.e. values in [0, +∞] ⊂ℝ¯. To do this, we set out some conventions for calculations in [0,∞]: for a ∈ ℝ≥0,

a + ∞ := ∞,∞ + a := ∞.

Also,

a ×∞ := ∞,∞× a := ∞for a > 0,

whereas

0 ×∞ := 0,∞× 0 := 0.

With these conventions, the algebraic identities used below for nonnegative extended quantities remain valid on [0,∞]. Another convenient consequence of “adding ∞” to [0,∞[ is that any increasing sequence in [0,∞] converges. We can even extend the usual properties, as follows.

Proposition 1.9 (Increasing limits in {0 ≤ x ≤∞}). If (an)n≥1 and (bn)n≥1 are two increasing sequences in [0,∞] with limits ℓa,ℓb in [0,∞] respectively, then the sequences (an + bn)n≥1 and (anbn)n≥1 converge in [0, +∞] and

lim ⁡ n→∞(an + bn) = ℓa + ℓb, lim ⁡ n→∞(anbn) = ℓa × ℓb.

Proof. The sequence (an + bn)n≥1 is increasing and has limit ℓa + ℓb. If both limits are finite, this is the usual rule for limits in ℝ. If one limit is + ∞, the conclusion follows from monotonicity and the definition of convergence to + ∞.

For the product, the sequence (anbn)n≥1 is increasing. If ℓa and ℓb are finite, the usual real-valued rule applies. If, for instance, ℓa = +∞ and ℓb > 0, choose c > 0 and n0 such that bn ≥ c for n ≥ n0; then anbn ≥ can tends to + ∞. The case ℓb = +∞ and ℓa > 0 is symmetric. Finally, if ℓb = 0, then bn = 0 for every n because (bn) is increasing and nonnegative; hence anbn = 0 for every n. The case ℓa = 0 is symmetric. This proves the formula in all cases, with the convention 0 ×∞ = 0. □
