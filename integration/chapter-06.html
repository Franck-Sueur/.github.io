Chapter 6
Lebesgue integral of positive measurable functions

We now extend the integral from simple functions to arbitrary positive measurable functions by approximation from below. The chapter establishes the fundamental properties of this definition, explains its behavior on negligible sets, and proves the approximation principle by simple functions that will drive the convergence theorems.

6.1 Definition

We will now define the integral of positive measurable functions from the definition of the integral of simple positive measurable functions.

Definition 6.1 (Positive integral). Let (X,A,μ) be a measure space. Let E ∈A. Let f : X → [0,∞] be a measurable function (let [0,∞] be endowed with its Borel σ-algebra). The Lebesgue integral of f on E is defined as:

∫ Efdμ := sup ⁡ s∈S ∫ Esdμ,

where the set S is defined as the set of all simple positive measurable functions s: X → ℝ≥0 such that s(x) ≤ f(x) for all x ∈ X. The set S is nonempty, since it contains the zero function, and the supremum is taken in [0, +∞].

Proposition 6.2 (Compatibility with simple functions). Let (X,A,μ) be a measure space, let E be in A, and let s: X → ℝ≥0 be a simple measurable function. Then the definition of ∫ Esdμ as a supremum over simple minorants agrees with the simple-function integral of Chapter 5.

Proof. Let Is denote the simple-function integral of s on E. Since s is one of its own simple minorants, the supremum definition gives

∫ Esdμ ≥ Is.

Conversely, let t be a simple positive measurable function such that t ≤ s on X. Then s − t is a simple positive measurable function. By the additivity of the simple-function integral,

Is = It + Is−t ≥ It.

Taking the supremum over all such t gives ∫ Esdμ ≤ Is. Hence the two definitions agree. □

6.2 Main properties

The definition above satisfies several basic properties, familiar for instance from the Riemann integral, as established below. Let us start with some comparison properties.

Theorem 6.3 (First properties of the positive integral). Let (X,A,μ) be a measure space. Let f,g: X → [0,∞] be measurable functions, and let E ∈A. We have:

1.
if f(x) ≤ g(x) for all x in E, then
∫ Efdμ ≤∫ Egdμ,
2.
if A ∈A and A ⊂ E then
∫ Afdμ ≤∫ Efdμ.

Proof.

1.
Let s be a simple positive measurable function such that s ≤ f on X. Then s1E ≤ g on X, and s1E is again simple, positive, and measurable. Since s and s1E coincide on E, we have
∫ Esdμ = ∫ Es1Edμ ≤∫ Egdμ.

We conclude by taking the supremum over all such s.

2.
Let s be a simple positive measurable function such that s ≤ f on X, and let
s = ∑ i=1rα i1Ai

be its canonical decomposition. Since A ⊂ E, we have Ai ∩ A ⊂ Ai ∩ E for every i, hence

μ(Ai ∩ A) ≤ μ(Ai ∩ E).

Therefore

∫ Asdμ = ∑ i=1rα iμ(Ai ∩ A) ≤∑ i=1rα iμ(Ai ∩ E) = ∫ Esdμ ≤∫ Efdμ.

We conclude by taking the supremum over all such s.

□

Theorem 6.4 (Additivity and monotonicity of the positive integral). Let (X,A,μ) be a measure space. Let f,g: X → [0,∞] be measurable functions, and let E ∈A. We have:

1.
∫ Efdμ = ∫ X(f ×1E)dμ, where again 0 ⋅∞ = 0,
2.
if μ(E) = 0 then ∫ Efdμ = 0,
3.
if there exist parts E0 ⊂ X and E1 ∈A such that
E0 ⊂ E1,μ(E1) = 0,(∀ ⁡x ∈ E ∖ E0,f(x) = 0)

then

∫ Efdμ = 0.
4.
for all c ≥ 0, we have
∫ E(c ⋅ f)dμ = c(∫ Efdμ).

Proof.

1.
We first prove that
∫ Efdμ ≤∫ X(f1E)dμ.

Let s be a simple positive measurable function such that s ≤ f on X. Then s1E is a simple positive measurable function by Corollary 5.10, and

s1E ≤ f1E

on X. Moreover, by the definition of the integral of a simple function,

∫ Esdμ = ∫ Xs1Edμ.

Therefore

∫ Esdμ ≤∫ X(f1E)dμ.

By taking the supremum over all such s, we obtain the desired inequality.

Conversely, let t be a simple positive measurable function such that

t ≤ f1E

on X. Then t ≤ f on X and, since t ≥ 0 while f1E = 0 on X ∖ E, we also have t = t1E. In particular, t vanishes on X ∖ E, and the definition of the integral of a simple function gives

∫ Xtdμ = ∫ Etdμ ≤∫ Efdμ.

By taking the supremum over all such t, we deduce that

∫ X(f1E)dμ ≤∫ Efdμ.

This proves 1).

Step 2.
The case where μ(E) = 0. Let s be a simple positive measurable function such that s(x) ≤ f(x) for all x in X. Then the definition of the integral of a simple function gives
∫ Esdμ = 0

because μ(E) = 0. We conclude by taking the supremum over all such s.

2.
Let s be a simple positive measurable function such that s ≤ f on X, and let
s = ∑ i=1rα i1Ai

be its canonical decomposition. If αi > 0 and x is in Ai ∩ E, then s(x) > 0. Since s ≤ f, we have f(x) > 0, and therefore x cannot belong to E ∖ E0. Hence

Ai ∩ E ⊂ E0 ⊂ E1

for every i such that αi > 0. Since μ(E1) = 0, this implies

μ(Ai ∩ E) = 0

whenever αi > 0. Therefore

∫ Esdμ = ∑ i=1rα iμ(Ai ∩ E) = 0.

We conclude by taking the supremum over all such s.

Step 4.
Positive homogeneity. If c = 0, the result is immediate. Assume now that c > 0. We first note that if
u = ∑ i=1rγ i1Gi

is the canonical decomposition of a simple positive measurable function, then

cu = ∑ i=1r(cγ i)1Gi,

and therefore

∫ Ecudμ = c∫ Eudμ.

Let s be a simple positive measurable function such that s ≤ f on X. Then cs is a simple positive measurable function such that

cs ≤ cf

on X. By the observation above, we have

∫ Ecsdμ = c∫ Esdμ.

Taking the supremum over all such s yields

c∫ Efdμ ≤∫ E(cf)dμ.

Conversely, let t be a simple positive measurable function such that t ≤ cf on X. Then

1 ct ≤ f

on X, and 1 ct is again a simple positive measurable function. Applying the observation above with u = 1 ct, we obtain

∫ Etdμ = c∫ E1 ctdμ ≤ c∫ Efdμ.

Taking the supremum over all such t gives

∫ E(cf)dμ ≤ c∫ Efdμ.

This concludes the proof.

□

6.3 Functions vanishing almost everywhere

The notion of negligible set was introduced in Section 2.3. When measurable functions are involved, it is convenient to use the following language.

Definition 6.5 (Almost-everywhere vanishing). Let (X,A,μ) be a measure space and let f : X →ℝ¯ be a measurable function. We say that f is zero μ-almost everywhere if there exists a μ-negligible set E0 ⊂ X such that f(x) = 0 for all x ∈ X ∖ E0.

Using this vocabulary, we can deduce from item 3) of Theorem 6.4 that the integral over X of a positive measurable function which is zero almost everywhere is equal to 0.

6.4 Approximation property

We also want the integral thus constructed to be linear (that is to say, “the integral of f + g is the sum of the integral of f and of the integral of g”). We will see in the following chapter that this point is not easy to establish and requires an important result: the monotone convergence theorem, as well as the following result which specifies the idea according to which we can approach positive measurable functions by simple measurable functions.

Theorem 6.6 (Approximation by simple functions). Let (X,A) be a measurable space and let f : X → [0,∞]. We equip [0,∞] with the Borel σ-algebra. Then f is measurable if and only if there exists a sequence (sn)n≥1 of simple measurable functions sn: X → ℝ≥0 such that

1.
for all n in ℕ≥1 and for all x in X,
0 ≤ sn(x) ≤ sn+1(x) ≤ f(x),
2.
for all x in X,
lim ⁡ n→∞sn(x) = f(x).

Proof. We first prove the reciprocal implication. Assume that there exists a sequence (sn)n≥1 with the stated properties. For each x in X, the sequence (sn(x))n≥1 is increasing in [0,∞] and converges to f(x). Hence

f = limsup ⁡ n→∞sn = liminf ⁡ n→∞sn.

Theorem 4.10 therefore implies that f is measurable.

We now prove the direct implication. Assume that f is measurable. For each n in ℕ≥1, we define

ϕn := (∑ k=0n2n−1 k 2n ⋅1 [ k 2n,k+1 2n [) + n ⋅1[n,∞].

Each ϕn: [0,∞] → ℝ takes only finitely many values, hence is simple. Moreover, all the intervals which appear in this decomposition are Borel subsets of [0,∞] for the topology introduced on the completed half-line, so Proposition 5.9 shows that ϕn is measurable. We then set

sn := ϕn ∘ f : X → ℝ.

By Proposition 4.7, each sn is measurable, and since ϕn has finite image, sn is simple.

Let y in [0,∞]. If 0 ≤ y < n, then

ϕn(y) = ⌊2ny⌋ 2n ,

so that

0 ≤ y − ϕn(y) < 1 2n.

If y ≥ n, then ϕn(y) = n ≤ y. Thus

0 ≤ ϕn(y) ≤ y

for every y in [0,∞]. We also claim that

ϕn(y) ≤ ϕn+1(y)

for every y in [0,∞]. If 0 ≤ y < n, then

ϕn(y) = ⌊2ny⌋ 2n ≤⌊2n+1y⌋ 2n+1 = ϕn+1(y).

If y ≥ n, then ϕn(y) = n, whereas ϕn+1(y) ≥ n by construction. Hence the claim follows.

By applying these inequalities to y = f(x), we obtain

0 ≤ sn(x) ≤ sn+1(x) ≤ f(x)

for all n in ℕ≥1 and all x in X.

Finally, let x in X. If f(x) < ∞, then for all n > f(x) we have

0 ≤ f(x) − sn(x) < 1 2n,

so sn(x) → f(x) as n → +∞. If f(x) = +∞, then sn(x) = n for all n, hence sn(x) → +∞ as n → +∞. Thus

lim ⁡ n→∞sn(x) = f(x)

for every x in X. This concludes the proof. □
