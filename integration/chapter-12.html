Chapter 12
Absolute continuity, Lebesgue decomposition and the Radon–Nikodym theorem

The comparison notions needed in this chapter were introduced in Section 2.5. We use the notation ν ≪ μ for absolute continuity and ν ⊥ μ for mutual singularity, as in Definitions 2.13 and 2.14. In the singular case, a set S such that ν(Sc) = 0 and μ(S) = 0 is called a mutually singular set associated with the ordered pair (ν,μ).

We now decompose a positive measure into an absolutely continuous part and a singular part with respect to a fixed reference measure.

12.1 Lebesgue decomposition

Theorem 12.1 (Lebesgue decomposition theorem). Let (X,A) be a measurable space and let μ and ν be finite positive measures on (X,A). Then there exist unique finite positive measures νa and νs such that

ν = νa + νs,νa ≪ μ,νs ⊥ μ.

Moreover, there exists a measurable function f : X → [0,∞) such that

νa(E) = ∫ Efdμ

for every E in A. The function f is unique up to equality μ-almost everywhere.

Proof. Step 1. Uniqueness of the decomposition. Assume that

ν = α + σ = β + τ,

where α and β are finite positive measures absolutely continuous with respect to μ, and σ and τ are finite positive measures singular with respect to μ. Choose a mutually singular set S associated with (σ,μ) and a mutually singular set T associated with (τ,μ), so that

μ(S) = 0,σ(Sc) = 0,μ(T) = 0,τ(Tc) = 0.

Set

C := X ∖ (S ∪ T).

Since μ(S ∪ T) = 0, absolute continuity gives

α(S ∪ T) = β(S ∪ T) = 0.

Moreover σ(C) = τ(C) = 0. Therefore, for every E in A,

α(E) = α(E ∩ C) = ν(E ∩ C) = β(E ∩ C) = β(E).

Thus α = β, and then also σ = τ.

Step 2. Uniqueness of the density. Assume that f and h are nonnegative measurable functions such that

∫ Efdμ = ∫ Ehdμ

for every E in A. For m ≥ 1, set

Am := {f ≥ h + 1 m }.

Then

0 = ∫ Am(f − h)dμ ≥ 1 mμ(Am),

and hence μ(Am) = 0. Since

{f > h} = ⋃ m=1∞A m,

we get μ({f > h}) = 0. By symmetry, μ({h > f}) = 0. Thus f = h μ-almost everywhere.

Step 3. Existence of the density and of the absolutely continuous part. Consider the family of candidate densities

C := {g: X → [0,∞] measurable : ∫ Egdμ ≤ ν(E) for every E ∈A }.

The function 0 belongs to C. Moreover, if g and h belong to C, then max ⁡(g,h) also belongs to C, because for every E in A,

∫ E max ⁡(g,h)dμ = ∫ E∩{g≥h}gdμ + ∫ E∩{h>g}hdμ ≤ ν(E ∩{g ≥ h}) + ν(E ∩{h > g}) = ν(E).

In particular, every g in C satisfies

∫ Xgdμ ≤ ν(X) < ∞.

We may therefore define

m := sup ⁡ { ∫ Xgdμ : g ∈C }.

Choose a sequence (gn)n≥1 in C such that

∫ Xgndμ → mas n → +∞.

For every n ≥ 1, set

fn := max ⁡(g1,… ⁡,gn).

Then fn belongs to C, the sequence (fn) is increasing, and

∫ Xfndμ ≥∫ Xgndμ.

Hence

∫ Xfndμ → mas n → +∞.

Define

f := lim ⁡ n→+∞fn.

By the monotone convergence theorem, for every E in A,

∫ Efdμ = lim ⁡ n→+∞∫ Efndμ ≤ ν(E).

Thus f belongs to C and

∫ Xfdμ = m.

Since ∫ Xfdμ < ∞, the set {f = +∞} is μ-negligible. Changing f on this negligible set, we may assume that f takes values in [0,∞).

Define

νa(E) := ∫ Efdμ,νs(E) := ν(E) − νa(E),

for every E in A. Then νa and νs are finite positive measures, and νa ≪ μ.

Step 4. Existence of a mutually singular set for the singular part. It remains to prove that νs ⊥ μ. For every integer n ≥ 1, consider the finite signed measure

ηn := νs −1 nμ,

and choose a Hahn decomposition (Pn,Nn) for ηn. We claim that

μ(Pn) = 0

for every n ≥ 1. Indeed, if μ(Pn) > 0, then Pn is positive for ηn, so for every E in A,

νs(E ∩ Pn) = ηn(E ∩ Pn) + 1 nμ(E ∩ Pn) ≥ 1 nμ(E ∩ Pn).

Therefore

∫ E (f + 1 n1Pn )dμ = ∫ Efdμ + 1 nμ(E ∩ Pn) ≤∫ Efdμ + νs(E ∩ Pn) ≤ ν(E)

for every E in A. Hence f + n−11 Pn belongs to C. But

∫ X (f + 1 n1Pn )dμ = m + 1 nμ(Pn) > m,

which contradicts the definition of m. Thus μ(Pn) = 0.

Set

S := ⋃ n=1∞P n.

Then μ(S) = 0. If E ⊂ Sc is measurable, then E ⊂ Nn for every n ≥ 1, hence

ηn(E) = νs(E) −1 nμ(E) ≤ 0.

Thus

νs(E) ≤ 1 nμ(E)

for every n ≥ 1. Letting n → +∞, we obtain νs(E) = 0. In particular, νs(Sc) = 0. Since μ(S) = 0, the set S is a mutually singular set associated with the ordered pair (νs,μ). Thus νs ⊥ μ. □

12.2 Radon–Nikodym theorem for positive measures

The previous theorem immediately gives the positive Radon–Nikodym theorem when the singular part is absent.

Corollary 12.2 (Finite Radon–Nikodym theorem for positive measures). Let (X,A) be a measurable space and let μ and ν be finite positive measures on (X,A). If ν ≪ μ, then there exists a measurable function f : X → [0,∞) such that

ν(E) = ∫ Efdμ

for every E in A. Moreover, f is uniquely defined μ-almost everywhere. We write f = dν dμ.

Proof. We apply the previous theorem and write

ν = νa + νs,νa(E) = ∫ Efdμ,

with νa ≪ μ and νs ⊥ μ. Since νs ≤ ν and ν ≪ μ, we also have νs ≪ μ. Choose S in A such that

μ(S) = 0,νs(Sc) = 0.

Then νs(S) = 0 by absolute continuity, so

νs(X) = νs(S) + νs(Sc) = 0.

Hence νs = 0 and ν = νa. The uniqueness of f follows from the uniqueness statement in the previous theorem. □

Theorem 12.3 (Radon–Nikodym theorem for positive sigma-finite measures). Let (X,A) be a measurable space and let μ and ν be σ-finite positive measures on (X,A). If ν ≪ μ, then there exists a measurable function f : X → [0,∞) such that

ν(E) = ∫ Efdμ

for every E in A. The function f is uniquely defined μ-almost everywhere.

Proof. Since μ and ν are σ-finite, there exists an increasing sequence (Xk) in A such that X = ∪k≥1Xk and μ(Xk) < ∞ and ν(Xk) < ∞ for every k. We apply the finite case on each Xk to obtain a density fk such that

ν(E ∩ Xk) = ∫ E∩Xkfkdμ.

By uniqueness of the Radon–Nikodym derivative on Xk, the restrictions of fk+1 and fk coincide μ-almost everywhere on Xk. We define f by setting f = f1 on X1 and f = fk on Xk ∖ Xk−1 for k ≥ 2. Then f is measurable and satisfies the desired identity on every Xk, hence on X by σ-additivity. □

12.3 A Baire lemma for signed measures

For finite signed measures, absolute continuity was defined in Definition 2.29 through the total variation measure. The next lemma is a Baire-category uniform absolute-continuity statement for sequences of finite signed measures. It will be used later in the proof of Theorem 15.32.

Lemma 12.4 (Baire lemma for finite signed measures). Let (X,A,μ) be a finite measure space. Let (νn)n≥1 be a sequence of finite signed measures on (X,A) such that

νn ≪ μ

for every n ≥ 1. Assume that for every E in A, the sequence (νn(E))n≥1 converges. Then for every 𝜀 > 0, there exists δ > 0 such that

μ(E) < δ⟹ sup ⁡ n≥1|νn(E)|≤ 3𝜀

for every E in A.

Proof. Let 𝜀 > 0.

Step 1. Closed sets in the Nikodym metric space. We work on the complete metric space (A~,ρ) from Corollary 8.20. For every integer N ≥ 1, define

FN := {[A] ∈A~ : |νp(A) − νq(A)|≤ 𝜀 for all p,q ≥ N }.

Each FN is closed in A~. Indeed, for fixed p,q, the map

[A]↦νp(A) − νq(A)

is continuous with respect to ρ. To see this, if A and B are measurable, then

|νp(A) − νp(B)| = |νp(A ∖ B) − νp(B ∖ A)|≤|νp|(A△B),

and |νp|≪ μ by Definition 2.29. Lemma 2.17 applied to |νp| gives the desired continuity.

Step 2. Application of Baire’s theorem. By assumption, the sequence (νn(A))n≥1 converges, hence is Cauchy, for every [A] in A~. Therefore

A~ = ⋃ N=1∞F N.

Theorem 16.17 gives an integer N0 ≥ 1, a class [A0] in A~, and a radius r > 0 such that

Bρ([A0],r) ⊂ FN0.

Step 3. Uniform Cauchy estimate on small sets. Let E be measurable with μ(E) < r. Then

ρ([A0 ∪ E], [A0]) = μ(E ∖ A0) ≤ μ(E) < r

and

ρ([A0 ∖ E], [A0]) = μ(E ∩ A0) ≤ μ(E) < r.

Thus [A0 ∪ E] and [A0 ∖ E] both belong to FN0. For every p,q ≥ N0,

|νp(E) − νq(E)| = |νp(A0 ∪ E) − νp(A0 ∖ E) − νq(A0 ∪ E) + νq(A0 ∖ E)| ≤|νp(A0 ∪ E) − νq(A0 ∪ E)| + |νp(A0 ∖ E) − νq(A0 ∖ E)| ≤ 2𝜀.

Step 4. Inclusion of the finitely many first measures. The finitely many measures |ν1|,…,|νN0| are absolutely continuous with respect to μ. Hence Lemma 2.17 gives a number δ in ]0,r[ such that

μ(E) < δ⟹|νn(E)|≤ 𝜀

for every n ∈{1,…,N0}. If n ≥ N0 and μ(E) < δ, then

|νn(E)|≤|νn(E) − νN0(E)| + |νN0(E)|≤ 2𝜀 + 𝜀 = 3𝜀.

The same estimate already holds for 1 ≤ n ≤ N0. This proves the lemma. □

12.4 Signed Radon–Nikodym theorem

We now deduce a signed version from the positive Radon–Nikodym theorem and the Jordan decomposition theorem. We use Definition 2.29: a finite signed measure ν is absolutely continuous with respect to μ when |ν|≪ μ.

Corollary 12.5 (Signed Radon–Nikodym theorem). Let μ be a σ-finite positive measure and let ν be a finite signed measure such that ν ≪ μ. Then there exists a function g in L1(X,μ) such that

ν(E) = ∫ Egdμ

for every E in A. Moreover, if ν = ν+ − ν− is the Jordan decomposition, then

ν+(E) = ∫ Eg+dμ,ν−(E) = ∫ Eg−dμ,|ν|(E) = ∫ E|g|dμ.

Proof. By the Jordan decomposition theorem (Theorem 2.25), we may write

ν = ν+ − ν−,

where ν+ and ν− are finite positive measures. Since ν ≪ μ, the measures ν± are also absolutely continuous with respect to μ by Definition 2.29. Applying Theorem 12.3 to ν+ and ν−, we obtain nonnegative measurable functions p and q such that

ν+(E) = ∫ Epdμ,ν−(E) = ∫ Eqdμ

for every E in A. Since ν+(X) + ν−(X) < +∞, the functions p and q belong to L1(X,μ). Moreover, ν+ ⊥ ν−; choosing a singularity set and using the two representations shows that pq = 0 μ-almost everywhere. Set

g := p − q.

Then g+ = p and g− = q μ-almost everywhere. The final identities follow from the definition |ν| = ν+ + ν− of the total variation measure. □

Example 12.6 (A measure with density and atom). Let X = [−1, 1], let μ be the restriction of the Lebesgue measure to [−1, 1], and define the finite positive measure ν by

ν(E) := ∫ Ex2dμ(x) + δ 0(E)

for every Borel set E ⊂ [−1, 1]. Then

νa(E) = ∫ Ex2dμ(x),ν s(E) = δ0(E)

gives the Lebesgue decomposition of ν with respect to μ. Indeed, νa ≪ μ, whereas νs ⊥ μ because it is concentrated on the μ-negligible set {0}. The Radon–Nikodym derivative of the absolutely continuous part is

dνa dμ (x) = x2.
